## 1. 问题设定与实证约束

### 1.1 任务

给定条件 x = 一张图像 + 一句自然语言编辑指令 + 一组冻结多模态基础模型的中间表征,预测空间软掩膜场 y ∈ [0,1]^{H×W},表示指令所指的编辑区域。推理时无 GT、无逐样本人工干预。

### 1.2 输出的层次生成结构

训练数据的 GT 场由两层生成过程产生:先选「家族」z(离散:椭圆衰减 / 线性渐变 / 条带等参数化几何原语家族,或语义轮廓家族 = 贴物体边界的掩膜,或全域常量),再由家族特定的低维连续参数(中心/轴/方向/衰减率,或物体形状)渲染出场。家族标签 z 与生成参数 ω 在训练侧可得;测试时只有 x。

### 1.3 条件的分解结构

指令的名词部分决定「哪个物体」——冻结模型的词-区域相似度场已证携带此信号(词特异性 p<1e-7),但整体覆盖粗糙:零训练直接用它 IoU 0.45,低于不看图像的中心先验基线 0.51。指令的其余部分(方位词/范围词/编辑动词)决定家族选择与衰减参数——低维、语言可解析。

### 1.4 已确立的实证约束(六条,任何方案必须逐条相容)

1. **D 的表达力**:存在固定可微低维解码器 D: R^71 → 场(基函数展开 + 图像引导上采样)。逐样本优化(知道 GT)可达 IoU 0.97,覆盖全部家族含语义轮廓。
2. **回归 x↦w\* 判死**:有效条件数中位 8×10^5(扰动放大 10^6 倍)、oracle 目标高度非凸多盆地(86% 样本仅一次重启命中最优盆地)、w\* 逐维变异系数全部 >1(条件均值退化为近常数向量)。两次实证塌缩(参数回归 / 查询池化回归)均产出「系统性过覆盖的平凡形状」。
3. **监督必须在输出场空间**(穿过冻结 D 或直接对场);εI 正则的凸投影层可把非凸拟合替换为唯一解的凸问题(代价:上界略降,量待定)。
4. **端到端高维场直出**(无低维结构)历史上也塌缩过一次。
5. **任务先验陷阱**:GT 场大面积且偏画幅中心(面积中位 0.41),「铺大掩膜吃重叠分」是低损陷阱,两次塌缩都塌向它;零参数中心先验是必须并排的强基线。
6. **冻结模型 attention 无指令条件空间信号**(已证);语言侧生成的推理文本:物体名词可信、几何描述不可信。

### 1.5 求

一个**统一的学习框架**——单一模型、单一(或紧密耦合的)学习目标,让家族选择、低维几何参数、语义轮廓、条件注入在框架内自然涌现,而不是显式分支 + 路由 + 多头缝合的工程拼装。

### 2.1 机制一句话 + 统一性论证

**机制一句话**:把 GT 场经 εI 正则的规范化算子唯一地「影射」到冻结解码器 D 的 71 维输入流形上,得到规范码 u(训练期确定性可得、扰动放大实测有界);把两层生成结构原样建成层次潜变量 θ=(z,u),用**单一条件似然目标**训练摊销后验网络 q(z,u|x);推理时从 q 采样 (z,u)、穿过冻结 D 渲染场——家族选择就是层次潜变量的离散层被采样,不存在任何路由。

**单一学习目标(完整写出)**:

$$
\mathcal{L}(\psi,\omega) = \mathbb{E}_{(x,y,z)\sim\text{data}}\Big[-\log q_\psi\big(z \mid c_\omega(x)\big) - \log q_\psi\big(u \mid z, c_\omega(x)\big)\Big],\qquad u = \mathrm{whiten}\big(C_\varepsilon(y; x_{\text{img}})\big)
$$

层次潜变量联合负对数似然 −log q(z,u|x),按链式法则**精确分解**为离散层(交叉熵)与连续层(条件 flow matching;FMPE 证明其为 proper scoring 的分布估计而非条件均值回归)。这不是两个损失的拼接——同一联合似然的两个因子,由**同一个 transformer** 在同一 token 序列上计算(Simformer 的组织方式);条件编码器 c_ω 只被这个 NLL 端到端训练(sbi reloaded / DINGO-BNS 标准工作流:嵌入表示自动学成后验充分统计量,无需独立对齐损失)。

**为什么不是缝合**:
- 规范化算子 C_ε 是确定性预处理(唯一解或确定性算法输出),零可训参数——之于本框架如 tokenizer 之于语言模型。
- z 不触发任何分支:以 conditioning token 进入共享 flow(全参数共享),家族差异表现为 u 空间条件分布的模态结构(hierarchical NSBI:q(z|x)·q(w|z,x) 共享同一嵌入、同一 NLL,家族选择以离散边缘的形式涌现)。
- 语义轮廓不设第二种头:其「参数」就是它在 D 输入流形上的规范影射坐标,与几何家族同住 R^71。
- 删掉任何一项,框架失去一个命名功能(CE:层次可辨识;FM:推理期采样;C_ε:潜码良态),而非「性能掉一点」——紧耦合判据。
- 本修订稿主方案内**无任何可选训练组件**:训练目标自始至终只有上式一个。

### 2.2 规范化算子 C_ε 与白化(训练期,唯一消费 GT 的地方)

**主分支(D 对 w 非线性——约束 2 的多盆地证据暗示这是现实分支)**:

$$
C_\varepsilon(y; x_{\text{img}}) = \mathrm{GN}_T\Big(w_0;\ \min_{w}\ \|D_I(w) - y\|_2^2 + \varepsilon\|w - w_0\|_2^2\Big)
$$

即从**整臂常量**初始化 w_0 出发、固定 T 步 Gauss-Newton(或 L-BFGS)、固定步长调度的确定性求解器输出。唯一性来源有二:(a) 算法确定性——全体样本走同一初始化、同一路径,这是 HyperDiffusion「共享初始化把多盆地对齐为可比单盆地」的做法推到极端;(b) εI-proximal 项对局部景观强凸化。y↦u 是单值确定性映射;扰动放大因子不再宣称解析上界,改为 **E0b 第一天实测上报**(预注册上限见 §2.6)。

**线性特例(仅当 E0a 线性性检验通过)**:闭式 ridge 解 u = (D_IᵀD_I + εI)⁻¹D_Iᵀy,y↦u 线性,扰动放大因子显式上界 1/(2√ε)——把约束 2 的 8×10^5 条件数换成一个可调旋钮。此分支的全部解析主张**仅在该检验通过后写入 REPORT**。

**白化(动机修订)**:u 按整臂常量协方差白化后作 flow 目标。动机只有一个:改善 FM 训练的条件数(优化学)。**不主张**它对齐场空间度量——场空间度量对齐的正确对象是逐图 Gram 阵 D_IᵀD_I,逐图量违反「归一化只能用整臂常量」纪律,故弃用。由此如实承认:u 空间 NLL 与场空间度量之间存在**残余错配**,其后果由 E0c(重建上界)与 E1(场空间主判据)兜底监控;这是本方案相对方案 B「损失度量显式穿 U_I」让出的一步,写入 §6 分歧清单。

**理论定位**:约束 2 的「多盆地、CV>1、条件均值退化为近常数」是参数化对称/近共线轨道上取均值的教科书症状(Equivariant Architectures for Learning in Deep Weight Spaces 提供审稿人级引用);出路三条(商对称、对齐轨道、换良态坐标系)中,C_ε 同时做了后两条:共享初始化对齐轨道 + εI 钦定代表元(Shap-E 用学习式 encoder 达成同一目的;我们用确定性算子,免训练;mNIF/CORAL 证明良态坐标系里连回归都能活——我们仍不回归,见下)。

### 2.3 训练计算图

```
y ∈ [0,1]^{H×W}, z ∈ {1..K}(训练侧观测), x = (图像, 指令, 冻结表征)

u  = whiten(C_ε(y; x_img))                    ∈ R^71    [确定性算子,零可训参数]
c  = c_ω(x):  词-区域相似度场 S ∈ R^{16×16×N} → 网格 token
              指令 token 嵌入(冻结文本编码器输出)
              冻结 VLM 中层 patch 特征
              → 6 层 cross-attention 条件编码器 → 条件 token 序列 c
              (cross-attention 注入,Attention Beats Concatenation 实测最优)

损失两项(同一 transformer T_ψ,同一 backward):
  L_z  = CE( head_z(T_ψ(c)), z )                             [离散层似然]
  L_u  = || v_ψ(u_t, t, emb(z), c) − (u − u_0) ||²           [连续层 FM 似然]
         u_0 ~ N(0,I), t ~ U[0,1], u_t = (1−t)u_0 + t·u
  L = L_z + L_u
```

z 在训练侧是**观测变量**(家族标签可得),不需要 ReinMax/Gumbel 一类离散梯度机器——CE 就是它的精确似然项;这是本设定送给层次潜变量派的最大红利。

### 2.4 推理计算图(无 GT、无逐样本干预)

```
1. c = c_ω(x)
2. ẑ = argmax_z q(z|c)                        [mode-seeking,预注册;禁止跨 z 平均]
3. 采 K=32 个 u^(k):从 N(0,I) 积分 ODE(~25 步,71 维小网络,开销可忽略)
4. 对每个 u^(k) 用 CNF 精确评估 log q(u^(k)|ẑ,c)(FMPE:密度可精确评估)
5. u* = argmax_k log q(·)  (预注册 A/B 规则:R1 max-density;R2 top-50% 密度样本的场空间 medoid)
6. ŷ = D(unwhiten(u*)),另输出 K 个样本的场空间方差作不确定性图
```

**关键纪律**:跨家族取期望场 = 重新发明均值塌缩(hier-latent 与 field-generative 两路调研共同警告),故第 2 步 argmax、第 5 步 mode-seeking 全部预注册,R1/R2 双规则并行落盘防事后挑选;二者分歧大本身就是家族歧义高的信号,如实报告为不确定性输出。

### 2.6 家族结构、相似度场角色与最小验证实验(预注册)

**家族 = 层次潜变量的离散层**,不是开关:K 个家族共享全部网络参数,推理路径对所有家族逐字相同(§2.4 六行伪码无一个 if)。几何原语与语义轮廓同居 R^71(约束 1 已证 D 覆盖轮廓到 0.97,轮廓家族的「形状参数」就是其规范影射坐标;高频边界由 D 的图像引导上采样承担)。涌现可验证性:训练后线性探针从 u 读家族标签与生成参数,报 per-family 互信息与恢复 R²(HNC-CAD 方法论)。风险诚实标注:Spatial Functa 的硬负结果(全局低维 modulation 装不下复杂空间结构)是轮廓家族头号威胁,E0c 直接测;若确实装不下,升级路径为给 u 增补少量空间 latent token(Locality-Aware GINR / AROMA 配方,仍是同一 NLL 下同一序列,不引入第二目标或路由)。

**相似度场 = 条件,仅此一种**:不当初始化(其系统性覆盖偏差会写进传输几何)、不当能量项(推理期能量引导是约束 5 复发通道);当条件则网络可按上下文降权——名词信号真实而覆盖粗糙,恰是「条件携带 which、后验分布负责 where 精确形状」的分工。DiffEdit 双 prompt 差分列入零训练基线排(与中心先验并排)。

**数据**:S 训练 split(≈7 万),S-val 评测;eval100 类金标永不进训练,仅按 RoPE 思路留作事后校准。**模型**:c_ω + T_ψ ≈ 15M 参数(6 层、d=384),批 256,单卡 2–4 小时。

**Step 0(第 0 天,零训练探针)**:NPE-PF——(PCA 压缩的 x 摘要, z, u) 数千对塞进 TabPFN 上下文,in-context 后验采样 → 穿 D 渲染。单向门:soft-IoU > 0.51 则「后验化破塌缩」获快速正证据;否则视为不确定(压缩丢信息的假阴性风险),照常进 E1,不据此判死。

| **E0b** 规范码稳定性(第 1 天) | y 加 1%/5% 场幅扰动,测 ‖Δu‖/‖δy‖ 放大因子;ε 扫描 {1e-3,1e-2,1e-1} | 中位 ≤ 50(对照 8×10^5) | 全部 ε 档均超限 → 「规范化可驯服病态」假设证伪,方案降级重审 |

| **E3** 反塌缩(三列缺一不可) | corr(预测面积, GT 面积);预测面积 std / GT std;TARP 覆盖最大偏离 | ≥ 0.3;≥ 0.5;≤ 0.1 | 任两列不过 → 塌缩复发,方案在约束 5 上失败 |

E5 是本方案的科学核心对照:同数据同表征同潜码,唯一差别是分布估计 vs 条件均值回归——直接检验约束 2 的死因诊断。

### 2.7 需求与主要风险(按杀伤力排序)

需求:7 万样本处 NPE 标准预算区间;特征预计算一次性;主训单卡数小时;推理每图 = 1 次条件编码 + 32×25 步 71 维 ODE + 32 次 D 渲染,秒级。可选廉价增强:GT 生成管线是已知模拟器,可无限采 (z,w,y) 做 flow 的无条件预训练(学 u 流形)再条件化微调——缺 x 配对故只当先验正则。

1. **规范化在轮廓家族的表达赤字**(Spatial Functa 同型;最可能触发):E0c 第一天量化;升级路径(学习残差编码器 → 空间 latent token)已备,不破坏单一目标。
2. **非线性主分支的稳定性**:算法规范化的唯一性是「确定性 + 强凸化」的经验保证而非全局定理;E0b 实测把它变成数字。若 E0b 挂,方案身份(规范化)动摇——这正是评审指出「A 最可能的失败方式是被迫演化成 B 的次优版本」的裂缝,如实承认,由 E0 第一天裁决。
3. **一图一 GT 的「伪多峰」**:若条件 c 太强以致逐 x 近单峰,flow 退化为带噪回归——不致命,但 E5 解释力变弱,REPORT 如实改口。
4. **训练/部署指令分布移位**:RoPE 式事后校准消费金标小集;治不了训练期塌缩,TARP 在训练分布内先把关。
5. **家族标签噪声直灌 q(z|x)**:低置信标注按数据纪律排除 + 标签平滑;z 层错误向 u 层传播,由 E2 新增损伤列量化。
6. **校准通过 ≠ 有信息**:TARP 永远与 IoU、锐度并排读,单列不作数。

### 2.8 延伸路线(明示:非本方案承诺,启用即另立实验)

- E2E-FT 式场空间微调(穿冻结 D,保留 FM 项与采样随机性):启用后「单一似然」主张失效,须以新编号实验预注册,且警惕单峰化(Lotus/E2E-FT 的「确定化更好」只在近单峰任务成立)。
- CMPE 蒸馏至 1–2 步采样:推理成本非首期瓶颈(秒级),仅当生产化需要。

**一句话押注**:把病态从「学一个不可学的逆映射」移到「选一个 ε 与一条确定性算法路径」,把塌缩从「人眼发现」移到「TARP 机械检出」,把家族路由从「工程分支」移到「层次似然的离散因子」——如果 E1 的 0.56 都到不了,该死的是层次潜变量路线本身,而不是它的某个工程细节。

### 3.1 机制一句话 + 统一性论证

**机制一句话**:在冻结解码器 D 的图像引导上采样算子 $U_I$ 之前的粗场空间 $c\in\mathbb{R}^{h\times w}$(约 32×32)上,训练一个以冻结 VLM 表征为条件的 x0-参数化 flow matching 模型 $p_\phi(c\mid x)$;家族选择就是这个条件分布的模式结构,采样即软路由,渲染 $\hat y=\mathrm{clip}(U_I\hat c,0,1)$ 由冻结线性算子完成。

**单一学习目标(完整写出)**:

$$
\mathcal{L}(\phi)=\mathbb{E}_{(x,y)\sim\mathcal{D},\ t\sim\mathcal{U}[0,1],\ c_0\sim\mathcal{N}(0,I)}\Big[\big(\hat c_\phi(c_t,t;\,S,V,E_T)-c^*\big)^{\!\top}\Lambda\,\big(\hat c_\phi(c_t,t;\,S,V,E_T)-c^*\big)\Big]
$$

- $c^*=(A_I^\top A_I+\varepsilon I)^{-1}A_I^\top y$ —— GT 场的**规范粗场坐标**,约束 3 所述 εI 凸投影的闭式解($A_I$ = U_I 本体或其固定引导线性化,见 §3.2;对 $y$ 线性、唯一解、条件数由 $\varepsilon$ 显式封顶、谱可直接进 REPORT);
- $c_t=(1-t)c_0+t\,c^*$ —— 直线插值路径(rectified flow / flow matching,DepthFM);
- $\hat c_\phi$ —— x0-参数化去噪网络(Lotus 消融:噪声预测参数化对稠密场有害);
- $\Lambda=\lambda I+(1-\lambda)\,A_I^\top A_I/\|A_I\|_2^2$ —— **固定二次型度量**:误差同时按粗场度量与「穿过冻结 $A_I$ 渲染回全分辨率场」的度量计。$A_I$ 线性,故这不是第二个损失项,只是同一 FM 回归的任务对齐度量。

**为什么是单一框架而非缝合**:
1. **只有一个可学习网络、一个标量损失、一个生成变量 c**。没有家族分类头、参数回归头、轮廓分支、路由器。
2. $A_I$ 与 $c^*$ 投影都是**冻结闭式算子**,属于任务的「观测模型/渲染物理」——地位同 Marigold 的冻结 VAE 解码器但更强:线性、无重建歧义、无需预训练权重。Shap-E 需先训 encoder 定义规范潜码,我们不需要——规范坐标由凸投影闭式给出,「两阶段耦合松」的风险(INFD 花大量篇幅修的问题)构造性消失。
3. 家族选择、几何参数、语义轮廓、条件注入,四者全是 $p_\phi(c\mid x)$ 一个条件分布的内部结构:家族=模式,几何参数=模式内连续变化,轮廓=粗场+$A_I$ 的边界吸附,条件注入=去噪器输入。与 Pix2Seq-D「一对多映射交给条件分布的多模式而非架构分支」同一哲学。
4. CFG 所需条件 dropout 是条件的数据增广,不引入第二目标。

### 3.2 预处理与显式假设(离线一次,全部冻结/闭式)

**显式假设 H1(本轮升格)**:$U_I$ 对信号线性。JBU 类固定引导上采样满足;若实现含 signal-guide 协方差项(guided filter 类)则仅近似线性。**Gate 0 的 G0a 第一天检验**(叠加残差);超限则构造固定引导线性化 $A_I$:引导核仅由图像与冻结引导特征构成、对信号严格线性,后续 $c^*$、$\Lambda$、渲染统一用 $A_I$,线性化的重建代价并入 G0b 一起实测——不存在检验盲区。

对每个训练样本 $(I,T,y)$:

| 张量 | 定义 | 形状 | 来源 |
|---|---|---|---|
| $c^*$ | $(A_I^\top A_I+\varepsilon I)^{-1}A_I^\top y$,稀疏 CG 求解 | 32×32 | 闭式凸投影(约束 3) |
| $S$ | 词-区域相似度场堆:top-$C_s$ 名词 + 整句池化,重采样到 32×32 | 32×32×$C_s$($C_s\approx4$) | 冻结 VLM 特征余弦(p<1e-7 信号) |
| $V$ | 冻结 VLM 视觉 patch 特征,线性投影到 $d_v$ 通道 | 32×32×$d_v$ | 冻结特征(非 attention) |
| $E_T$ | 指令的冻结文本侧 token 嵌入 | $L\times d_t$ | 冻结模型 |

值域纪律:$c^*$ 的整臂实测值域必须落盘声明(本项目 s 缓存消费契约),消费侧断言后才进训练。

### 3.3 训练与推理计算图

**训练**:

```
c0 ~ N(0,I)  ──┐
c* (闭式投影) ──┴─→ c_t = (1−t)c0 + t·c*
                        │
[c_t ‖ S ‖ V] ──concat──→ conv stem → DiT blocks ──→ ĉ ∈ R^{32×32}
                              ↑ AdaLN(t)   ↑ cross-attn(K,V = E_T)
loss = (ĉ − c*)ᵀ Λ (ĉ − c*)        ← 单一标量,反传只进 ĉ_φ
```

空间对齐条件($S,V$)走 concat(Marigold 机制);序列条件($E_T$)走每块 cross-attention(系统对比结论:attention 全面优于 concat 与 hypernetwork,且 hypernet 式「条件→参数」正是被判死的 x↦w 形态)。训练以 $p=0.1$ 独立丢弃 $E_T$ 与 $S$,得免费无条件分支供 CFG 与负控制。网络 ~30M(DiT-S 级)。

**推理(无 GT、无逐样本干预)**:

```
for k = 1..K (K=16, batch 并行):
    c⁽ᵏ⁾: 从 N(0,I) 出发, N=8 步 Euler 积分 dc/dt = (ĉ_φ(c_t,t;cond) − c_t)/(1−t)
          (CFG: ĉ ← ĉ_∅ + g·(ĉ_cond − ĉ_∅),g 按预注册规则选定,见 §3.6)
render:  ŷ⁽ᵏ⁾ = clip(A_I c⁽ᵏ⁾, 0, 1)
select:  R1(主规则): K 样本两两 soft-IoU → 凝聚聚类(τ=0.6) → 最大簇 medoid
         R2(对照规则): CNF 精确 log-density(Hutchinson 散度沿 ODE,~2×NFE) → max-density
         双规则输出均落盘;主表用 R1;R1/R2 分歧率入诊断列(分歧高 = 歧义高)
         歧义信号 = 1 − |最大簇|/K
```

**关键推理纪律**:绝不取 K 样本的期望场——期望 = 重新引入均值塌缩;必须 mode-seeking。总成本 128 NFE 的 30M 模型 on 32×32(R2 启用时 ~2×),单图 <0.2 s。

### 3.4 对六条实证约束的逐条相容性

**约束 1**:借用 D 的颈部。任何 $D(z,w)$ 输出都可写成 $A_I(\text{某粗场})$,自由粗场空间 ⊇ D 的 71 维流形,表达力上界不低于经 εI 投影的 D;Gate 0 把「上界略降,量待定」变成可测数字。采样 c 轻微离流形由训练分布约束;备选一步闭式岭投影,仍是前向。

**约束 2 —— 三重绕开(无条件,不依赖任何「若线性」赌注)**:
1. **换坐标系,病态构造性消失**:病态属于非线性参数化 w,不属于场本身。$c^*$ 对 $y$ 线性(H1 经 G0a 检验或经 $A_I$ 构造性保证),条件数 $\le(\sigma_{\max}^2+\varepsilon)/(\sigma_{\min}^2+\varepsilon)$ 由 $\varepsilon$ 封顶,谱直接进 REPORT。多盆地是「逐样本独立非凸优化未对齐参数化」的产物(HyperDiffusion;权重空间置换对称性理论说明 x↦w\* 根本不是单值函数)——凸投影的规范代表元把整条盆地选择问题删除。
2. **换目标,均值塌缩消失**:家族混合使 $p(c|x)$ 多峰;FM 学完整条件分布,采样落入单一模式而非模式间平均(Ambiguous-MedSeg 直接实证)。
3. **不存在参数空间监督**:全链路无任何以 w 或其变体为目标的项。

**约束 3 —— 字面执行**:损失度量 $\Lambda$ 的 $(1-\lambda)$ 分量就是穿过冻结 $A_I$ 的全分辨率场空间 MSE;$c$ 本身是场(粗分辨率);εI 凸投影升格为框架的规范编码器。

**约束 4 —— 生成式与当年回归直出的本质区别,四点 + 内置证伪臂**:(1) L2 一次性直出的全局最优是 $\mathbb E[y|x]$,多峰下必然是跨家族模糊并集——正是两次塌缩形态;FM 最优解是传输到完整条件分布,「平均场」在训练分布中密度趋零,生成它是高损行为。(2) 一次病态映射 → 多步局部良态映射(DPF / Functional Diffusion 实证:场空间迭代去噪可行,塌缩根因是回归的条件均值坍缩)。(3) 1024 维粗场 vs 全分辨率直出的数万维。(4) **臂 C**(同架构同条件的一次性 L2 回归)内置——若它同样不塌,任务近单峰、生成机器非必需,如实降级;若它复现过覆盖而 FM 不复现,「生成式目标是收益来源」得到受控证明。

**约束 5 —— 不复发**:恒定大掩膜模型无法把概率质量传输到 GT 面积统计上,FM 损失高。四道防线并入预注册:(a) 采样面积分布 vs GT 面积分布的 $W_1$ 一等诊断;(b) 中心先验强制并排、配对 Δ+p;(c) mode-seeking 推理杜绝并集输出;(d) **本轮新增** c 空间 TARP 覆盖检验(#9)。不做确定化蒸馏(单步确定化只在近单峰任务成立),固定 $N\ge8$ 步并预注册步数-多样性曲线。

**约束 6**:条件三通道全部绕开冻结模型 attention 权重——$S$ 是特征余弦(特征几何性质),$V$ 是特征本身,$E_T$ 是嵌入;cross-attention 是**新训**模块。方位/范围/编辑动词不经语言生成路径解析(不让模型「说出」几何),以嵌入形式被去噪器在场监督下端到端消费(InstructDiffusion 证明的免路由注入通道)。

### 3.5 家族统一表达与相似度场角色

**家族 = $p_\phi(c|x)$ 的模式,不是架构对象**。表示统一:椭圆衰减、渐变、条带、常量、语义轮廓在 c 空间里同为一张 32×32 实值场;几何家族是低秩光滑模式,轮廓家族是「粗 blob + 由 $A_I$ 吸附回物体边界的细节」(约束 1 已证该结构覆盖轮廓到 0.97)。选择统一:采样一条 ODE 轨迹 = 隐式选一次家族,无 argmax、无路由、无直通估计。**家族标签只做诊断,不进模型**:(a) Gate 0 分家族重建上界;(b) 评测分家族 IoU;(c) K 样本集家族命中率(最近 $c^*$ 邻诊断分类)。家族平衡重采样是数据配平(预注册开关臂),不是路由。失败退路(诚实预告):若轮廓家族在粗场分辨率下模式分离不足,备选是局部 latent token 集合(Locality-Aware GINR / AROMA),仍无路由。

**相似度场 = 条件(concat 通道),仅此一种**:不作传输源($S$ 的覆盖偏差会焊进传输起点,且渐变/条带/全域家族无物体支撑,$S$ 对它们无定义);不作能量项/打分器(推向过覆盖模式,复活约束 5)。作条件的正面理由:「信不信 $S$、信哪个通道」由 cross-attention 里的指令逐家族决定,粗糙由场监督自动折价。配套负控制预注册:打乱 $S$ 通道、置零 $S$、错图 $S$ 三条。基线排:中心先验 + DiffEdit 双条件差分(若挂有扩散编辑底模,可选不阻塞)。

### 3.6 最小验证实验(预注册,判据全部 AUC-free)

**数据**:S-train 全量(≈7 万)训练;S-val 评测;金标小集永不进训练。可视化遵守项目纪律。

**Gate 0(先于一切训练,半天)**:

### 3.7 需求与主要风险(诚实排序)

需求:离线抽 $S,V,E_T$ 一次前向(数小时);$c^*$ 稀疏 CG 批量(分钟级);训练 ~30M DiT-S,batch 256,单卡 2–5 小时(Marigold 74k 样本同量级正面先例);推理单图 <0.2 s。

1. **少数家族模式丢失**(最大):家族不平衡下 FM 覆盖不足,#6/#7 首当其冲;缓解:平衡重采样开关臂 + batch 出现率诊断;仍失败则对稀有家族的主张收缩。
2. **粗场颈部对语义轮廓的上界**:全押 Gate 0,失败成本半天。
3. **mode-seeking 选错模式**:R1/R2 双规则 + medoid-vs-oracle 差距列量化;差距大则选择问题另立课题(场空间轻量校验器是新增组件,须另立实验)。
4. **CFG 扭曲分布**:已由预注册选择规则锁死自由度;若三档全不过 #3,如实报告条件性与面积统计不可兼得。
5. **训练/部署指令分布移位**:金标小集只做事后评测;如实标注适用域。
6. **FM 欠拟合 vs 回归臂**:若 C 臂更稳,按 #2 预注册降级——良态 $c^*$ 坐标系是本方案可独立存活的贡献(它单独废掉 8×10^5 条件数的病态目标)。
7. 采样 c 离流形:岭投影补步已备,预期影响小。

**程序/序列派** —— 场编译为短混合 token 序列,单一 next-token 软 CE 目标

### 4.1 机制一句话 + 统一性论证

**机制一句话**:把每张 GT 场编译成一段「场程序」——`[家族 token][规范化参数槽 token…][支撑指针 token…]` 的短混合序列(≤20 token),由一个从零训练的小型条件解码器以**单一 next-token 软交叉熵目标**学习 x ↦ p(程序|x),推理时贪心解码出程序、交给固定可微解释器渲染成场;模型从头到尾只做一件事:给定条件,写出生成这张场的那句程序。

设训练样本 (x, y, z, ω):固定无参数**编译器** C(z,ω,y;x)→s;固定零可训参数可微**解释器** I(s;x)→ŷ;条件编码 E_φ(冻结特征 + 极小可训投影)。

**单一学习目标(修订后,完整写出)**:

$$
\mathcal{L}(\theta,\phi) = \mathbb{E}_{(x,y,z,\omega)}\Big[-\sum_{t=1}^{|s|}\ \sum_{k\in\mathcal{V}}\ q^{\text{field}}_t(k)\ \log p_\theta\big(k \mid s_{<t},\, E_\phi(x)\big)\Big]
$$

其中 $q^{\text{field}}_t$ 是**场空间距离核化的 HL-Gauss 软目标**:对参数槽 token,质量按「候选箱与 GT 箱的渲染场距离」的高斯核归一化分配(核宽为整臂常量,设计期用 E0 校准一次);家族 token 与指针 token 为(近)one-hot。此即 Stop Regressing 的软直方图 CE,但平滑核不取参数域欧氏距离而取场域距离——token 监督由此在二阶意义下携带场度量。**没有第二项、没有相位调度、没有松弛机器。**

**为什么是单一框架而非缝合**:一个网络、一个词表、一个 softmax、一个损失流、一个解码循环。

| 问题设定的四件事 | 在 FPD 里对应 |
|---|---|
| 家族选择 | 序列**第一个 token** 的分类 |
| 低维几何参数 | 其后的**参数槽 token**(共享箱词表,槽位语义由位置/类型嵌入区分) |
| 语义轮廓 | **指针 token**(对图像自产段落的选择,与参数槽同在一个 softmax 里,pointer-generator 单一 softmax) |
| 条件注入 | 解码器每层对 E_φ(x) 的 cross-attention(Attention Beats Concatenation) |

不同家族「槽位数不同」由固定文法自动机在解码时做词表掩码(非法家族×参数组合概率为零)——定位为**输出空间的定义**(如 tokenizer 词表),非架构分支:所有家族过同一组权重、吃同一个损失(VisProg 语法约束解码思想;IconShop「命令 token 决定其后槽位」实证)。该定位的涌现性由 S6 消融**实测裁决**而非口头辩护(§4.6)。

### 4.2 程序文法、词表与解释器

**文法与词表(约 110 token + K 个动态指针)**:

```
程序 := [FAMILY] SLOTS(family) [EOS]
椭圆衰减:  [F_ell]  cx cy  log a  log(b/a)  φ∈[0,π)  log γ  amp   (每槽 2 token:粗箱 B0..B31 + 细箱 R0..R31)
线性渐变:  [F_lin]  方向角  截距  过渡宽  log γ  amp
条带:      [F_strip] 方向角  中线  半宽  log γ  amp
全域常量:  [F_const] amp
语义轮廓:  [F_ctr]  ptr_seg_i … ptr_seg_j [SEL_END]  羽化宽  amp
```

- **规范化坐标系**:参数用各家族**生成参数本身**(训练侧可得),并做对称性商化(椭圆 a≥b、φ∈[0,π);条带方向半圆化)——多盆地的主要来源(参数化对称轨道)在编译期商掉(Equivariant Architectures 诊断;HyperDiffusion 教训)。参数域先去相关、log 域、再量化——不做「逐维对强相关信号简单分箱」(FAST 实证该做法完全失败)。
- **数值走结构化箱 token,永不走十进制数字串**(LLM4SVG 幻觉证据与修复路径)。粗+细两级 32 箱 ≈ 1024 级;**箱宽按场空间校准**:相邻箱渲染场 soft-IoU 差 ≤ 0.02(设计期 E0 一次性验证);软目标核宽同源校准。
- **语义轮廓 = 指针选择**:离线在冻结 DINO 类 patch 亲和上跑迭代 Ncut,每图 K≈24 段(部件+整体双粒度)(LaVG);编译器把 GT 掩膜贪心匹配为段子集(面积降序排列保证唯一可解码,IconShop);输出是 softmax over [词表 ∪ K 段] 的 pointer-generator 单一 softmax——轮廓由此成为「参数是离散选择的又一个家族」。
- 序列 ≤20 token、无 RLE、每家族槽位数固定——序列域不存在「大块掩膜→短序列→低损」捷径(Text4Seg 风险条的针对性规避)。

**解释器 I(修订后统一规格;固定、零可训参数、全家族同一管线)**:

```
1) 家族粗场 g ∈ R^{32×32}:
   几何家族:解析式在 32×32 网格上渲染(闭式、对连续参数可微)
   轮廓家族:选中段软掩膜概率 OR(patch 级)
             → (I−αW+μI)f = y 形式的凸标签传播(W=冻结特征亲和,闭式唯一解;
                羽化宽 token 控制 μ)→ 32×32 粗场          [LPOSS;即约束 3 期望的 εI 凸投影实例]
   全域常量:常量场
2) 统一上采样:ŷ = clip(U_I g, 0, 1)
   U_I 复用冻结 D 的图像引导上采样支路(与方案 B 同一算子;C 只做前向,不需要线性性假设)
```

### 4.3 训练/推理计算图与六约束相容性

**训练**:

```
图像 ──冻结视觉塔──> patch 特征 F ∈ R^{16×16×C} ─┐
指令 ──冻结文本编码──> 词嵌入序列 T ∈ R^{L×C}     ├─ 极小投影(可训) ──> 条件 token 集 E_φ(x)
词-区域相似度场(逐名词,先零参亲和平滑          │   (256 patch tok + L 文本 tok + K 段 tok)
  [ProxyCLIP]) ──concat 进 F 通道────────────────┘
段描述子(逐段池化相似度+几何统计)[LaVG 晚交互] ──> K 个段 token

GT (z, ω, y) ──编译器 C──> 目标序列 s(教师强制)
解码器(6–8 层, d=384, ~15M 参数, 因果自注意 + cross-attn 到 E_φ(x))
损失 = 场距离核软 CE(逐 token)                    ← 唯一损失,无第二项
监控(零梯度):每 2k step 对固定 512 验证子集贪心解码渲染,报 soft-IoU 曲线入 config/
              (仅监控;checkpoint 按预注册 step 数定,不看该曲线)
数据增广:水平翻转等程序一致变换(图像翻转 ⇔ 参数槽同步变换)
```

**推理**:`x → E_φ → 贪心解码(文法掩码,≤20 步)→ 程序 ŝ → I → 场 ŷ`。逐步 argmax 是 mode-seeking:采样即选盆地,绝不取期望(GIVT/MAR 采样纪律)。成本毫秒级。诊断用 oracle-of-8(推理期采 8 条程序,纯诊断)。

**六约束相容性**:

| 约束 | 相容机制(修订后) |
|---|---|
| **1** | 解释器 I 是 D 的程序化推广:各家族解析基 + D 的同一图像引导上采样支路;表达力按家族由 E0 回环认证;轮廓传播层即 εI 凸投影实例(LPOSS,唯一解)。 |
| **2** | 四重绕开:(a) 换目标——从不接触逐样本优化的 w\*,目标是训练侧可得的规范生成参数 ω(8×10^5 条件数是 R^71 基系数参数化的属性,不是任务的属性);(b) 商对称——编译期规范化消掉对称轨道(86% 需重启的多盆地正是未对齐参数化的产物);(c) 换损失形态——残余多峰由 token 级软 CE 建为完整条件分布,分类免疫条件均值塌缩(Stop Regressing 跨域证据),AR 分解使每步都是「已提交前缀条件下的低维良态分类」(PolyFormer);(d) 塌缩不可表示——序列必须先提交家族才能发参数,「椭圆程序与渐变程序的平均」不在输出空间里。 |
| **3** | 修订后三层执行:(a) 软 CE 的平滑核定义在场空间距离上,token 监督在二阶意义下即场度量监督;(b) E0 回环证书量化「程序空间 = 场空间的 ε-等距重参数化」(约束 3 反对的是 w-MSE 那种 8×10^5 条件数的度量畸变,而非「非像素空间」本身);(c) 轮廓传播层内建 εI 凸投影。**如实声明**:这是「认证重参数化」而非字面场空间损失,残余风险是 CE 对远距箱错误的场距离不敏感(核只在近邻二阶逼近),由零梯度监控列与 S 判据兜底;评审保留意见见 §6。 |
| **4** | 输出恒为 ≤20 token 低维结构化序列,场只由固定解释器产生。 |
| **5** | 修订后**全训练无任何重叠类目标**(fatal 修复的直接后果):MLE 教师强制对着固定 GT 程序序列,不存在「扩大预测面积换重叠分」的梯度通道;文法无 RLE、无长度捷径;结构免疫主张现与自身结构一致。程序空间化身的陷阱(学成边缘分布输出众数程序)由**双基线**拦截:像素中心先验 + **x 遮蔽孪生解码器**(同架构、条件置空训练,即「程序空间的中心先验」,比像素版更强),外加面积有符号误差、家族边缘 TV、面积分布 W1 三个反塌缩指标。 |
| **6** | 全程不读冻结模型任何 attention 权重,条件只消费特征几何(patch 特征、文本嵌入、词-区域相似度场;Talk2DINO 与 2605.13122 证实空间信号住在特征可分性/特征几何)。参数 token 化不重蹈约束 6 的三点:(1) 监督源是 GT 生成参数(场的编译产物),非语言模型生成的几何描述,解码器从零训练无可幻觉语言先验;(2) 数值是结构化箱 token 非 BPE 数字串,LLM4SVG 幻觉机制在词表层面消除;(3) E0 回环认证 + 零梯度场监控使 token 化失真在场 IoU 上现形,不会静默积累。名词经相似度场(p<1e-7 可信通道)进入;方位/范围/动词经冻结文本嵌入进入,其到几何的映射完全由场侧认证的监督学出。 |

### 4.4 家族统一表达

家族是**程序的第一个词**——离散潜变量在输出序列里的物化,不是架构开关。(a) 权重统一:所有家族过同一解码器、同一 softmax,槽位语义由类型嵌入承载,文法自动机只做解码期词表掩码(其「仅是输出空间定义」的属性由 S6 实测认证);(b) 参数化统一:轮廓降格为「参数是段指针的家族」——形状来自图像自产支撑(纯视觉、可离线,LaVG 的 where⊥which 分解),语言只做选择;段边界是图像的,不是损失能推大的,天然免疫铺大陷阱;(c) 涌现而非路由:家族竞争表现为第一 token 后验 p(z|x),可直接读出、可校准、可做负控制——比隐式模式结构更可诊断。多原语组合只需文法允许命令拼接(IconShop),框架零改动。

### 4.5 粗相似度场角色:条件(且只是条件)

双通道注入:(i) 逐名词 16×16 相似度场,零参数亲和平滑(ProxyCLIP)后 concat 进 patch 条件 token 通道;(ii) 逐段池化相似度进段 token——段支撑上的积分吸收其像素级粗糙(LaVG 晚交互),正是指针头选段所需的「哪个物体」证据。排除另两种角色:不作初始化(零训练 IoU 0.45 输给中心先验 0.51,它是特征不是答案);不作能量项(推理期能量优化违反「无逐样本干预」红线,且重叠类能量给约束 5 陷阱开门)。

### 4.6 最小验证实验(预注册)

**E0:编译-解释回环上界(零训练,1–2 天,先于一切训练)**。对 S-val 源全体:s = C(y)、ŷ = I(s),报 soft-IoU / hard-IoU / grid 边界 F1(匹配 GT 面积 top-k;可视化守有效格色标纪律);同场完成箱宽与软目标核宽的场空间校准。

| 判据 | 通过 | 证伪动作 |
|---|---|---|
| 几何家族回环 soft-IoU 均值 | ≥ 0.92 | < 0.92 细化箱;细化一轮后仍 < 0.85 ⇒ **编码方案证伪** |
| 轮廓家族回环(oracle 段选择)soft-IoU | ≥ 0.80 | < 0.70 ⇒ 触发预注册后备:轮廓槽换 32-token 学习式掩膜码本(HiMTok);**明示**:启用即引入受训组件,「解释器零可训参数」主张失效,须另立实验 |

### 4.7 需求与主要风险(按杀伤力排序)

需求:70k 训练样本(带家族标签+生成参数;低置信标注按数据纪律剔除);离线冻结特征与段缓存 ≈ 2–3 GPU 时;~15M 解码器,10k 子集 1–2 小时、全量 4–8 小时,单卡内;推理毫秒级。小样本可训性:从零小 transformer + 短序列 + 冻结条件编码 + 软标签 CE + 程序一致增广,处于 MeshGPT / StrokeNUWA 已验证量级;不微调任何大模型词表(LLM4SVG 需 580k SFT 的路径刻意避开)。

1. **轮廓段支撑天花板**(最大):Ncut 段粒度未必对齐编辑意图、漏检物体不可达(LaVG 失效条);对照约束 1 的 0.97,E0 门槛 0.80(还是 oracle 段选择)是开局认下的表达力税。缓解:双粒度段 + E0 先行认证 + 预注册 HiMTok 后备(代价与主张降格已明示)。
2. **残余多峰下贪心选错模式**:真歧义指令(「天空」=顶部条带或渐变)贪心只取一个;oracle-of-8 诊断列量化。
3. **敏感参数量化损失**(衰减率 γ):log 域粗细两级箱 + E0 箱宽校准前置拦截(FAST 警告)。
4. **约束 3 的「认证重参数化」解释残留争议**:CE 对远距箱错误的场距离不敏感是结构性残余;零梯度监控列与 S 判据兜底;评审保留意见如实记入 §6,若 E1 通过而场监控曲线与 CE 曲线明显脱钩,须回头重审此解释。
5. **训练-部署分布移位**:fresh 类小集只评测不训练;移位显著时事后校准而非重训。
6. **暴露偏差**:序列 ≤20、词表 ~110,风险量级小(AiT 已知问题),不预置缓解,E1 失败归因时排查。
7. **编译器标注噪声传导**:CE 直接继承 GT 参数噪声;修订后无场空间损失项可部分自纠(原 λ 项的这个副作用随修复失去),是所有监督式路线的共同税中本案承担较重的一份,如实声明。

## 6. 评审 panel 意见与未消解分歧

### 6.1 三 lens 裁定(v1 打分,原样呈现)

- **优雅 lens(best=B,B 8.5 > A 8 > C 6.5)**:只问统一是构造出来的还是叙述出来的。B 的统一是构造性的——生成变量放在生成过程颈部,五家族天然同质,「涌现而非路由」执行到极限(连离散对象都不存在),失分点(聚类选模式、CFG 旋钮)全在目标函数之外。A 层次似然数学自洽且最忠实于已知生成结构,E5 与 TARP 是全场最好的科学仪器,但白化辩护有瑕疵、可选组件长尾侵蚀纯度、71 维承载轮廓是最陡赌注。C 的「平均程序不可表示」是全场最强单点洞见,但 v1 的 λ 项踩红线、松弛机器击穿单一目标、文法掩码是移进词表的显式分支——赢在局部巧思,输在整体形态。
- **实证相容 lens(best=B,B 8.5 > A 8 > C 6.5)**:裁定标准是对约束 2/5 的规避必须原理性、无条件、自带证伪仪表。B 全部做到(c\* 对 y 线性、谱可报告;约束 3 字面执行;面积 W1 仪表;臂 C 杀伤性对照内建)。A 同样原理性但头牌机制以「D 线性」为前提,而约束 2 的非凸多盆地恰暗示该前提可疑;主相位监督落在白化 u 空间,离约束 3 字面差一步。C 概念上最新颖(真生成坐标 + 对称商化),但 v1 的 λ 项亲手重开重叠目标通道、soft-token 期望重引参数均值——「宣称结构免疫却埋着未自知的违规项」。
- **可证伪 lens(best=B,B 8.5 > A 7.5 > C 6)**:B 的 Gate 0 建立在不需要赌的假设上、判据 #2 把「任务近单峰」预注册为可接受结局、良态 c\* 坐标系任何结局下独立存活;对六约束与项目红线零冲突。A 的闭式分支押在与约束 2 证据自相矛盾的赌注上、退路含糊(v1);C 的 λ 项踩「IoU 禁当优化目标」红线且拆掉后主监督滞留程序空间,属结构性硬伤(v1)。

### 6.3 未消解分歧(如实呈现,不强行裁决)

1. **A 的独立身份问题**:实证相容/可证伪认为,D 非线性的现实分支下 C_ε 滑向 B 的颈部构造,A 变成「背着 71 维瓶颈的 B」;优雅认为层次似然对两层生成结构的显式建模本身就是独立价值(z 的精确 CE 因子、u 的可探针性)。**裁决器**:E0a/E0b 第一天出数;若算法规范化稳定(E0b ≤50)且 E2 家族涌现达标,A 的独立价值成立。
2. **B 与约束 4 的距离**:1024 维粗场是三案中离「高维直出塌缩」最近的配置;其无罪辩护(死因是回归的条件均值坍缩而非场空间本身)是论证而非事实。**裁决器**:臂 C 受控对照 + #3 面积 W1 + #7 模式召回 + #9 TARP 四重仪表;失败会以预注册数字显形而非静默。
3. **「一图一 GT 伪多峰」——生成机器是否必要**:若条件够强使逐 x 近单峰,A 的 flow 与 B 的 FM 都退化为带噪回归,「家族=模式涌现」的叙事溶解为良态坐标系里的回归。A 之 E5 与 B 之臂 C/#8 是同一问题的两次独立测量;两案均预注册了体面降级(良态坐标 + 回归),但降级后「统一框架」主张缩水。此为三案共同的、只能由数据回答的开放问题。
4. **C 的文法掩码是否算路由**:优雅认为是「伪装成词表的 if-else」边界案例;本稿把它变成 S6 可测命题(自由解码非法率),但「家族结构是施加还是涌现」的哲学分歧未全消——S6 通过只证明文法非支撑结构,不证明家族结构会在无文法先验下自发形成。
5. **C 修复后的约束 3 合规**:「认证 ε-等距重参数化 + 场距离核软 CE」是否满足「监督**必须**放在输出场空间」——可证伪 lens 的保留意见预计维持(CE 对远距箱的场距离不敏感是结构性残余);支持方论点是约束 3 反对的是 w-MSE 那种度量畸变而非非像素空间本身。留给实现审阅裁决。
6. **模式选择规则**:max-density(原则性,A 的 R1/B 的 R2)vs 聚类 medoid(稳健性,B 的 R1)——两案均双规则并行落盘,分歧率数据裁决,不预设立场。
7. **轮廓家族承载,三案三押注**:A 押 71 维全局码(E0c 0.75 门)、B 押粗场+U_I 边界吸附(G0b 0.88 门)、C 押 Ncut 段支撑(E0 0.80 oracle 门)。三道门全部在训练前、总成本 <4 天,建议三门并行跑完再定主力投入——这是三案并存的最大实际收益。
8. **评审总倾向**:三 lens 一致 best=B(唯一无条件线性化、约束 3 字面执行、证伪设计最诚实);A 稳定第二(科学仪器最好,身份风险待 E0 裁决);C 第三(fatal 已修,但轮廓天花板与约束 3 争议使其更适合作为快推理/强可解释的对照路线而非主力)。
