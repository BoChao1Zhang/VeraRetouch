## 1. 这个实验在回答什么问题

### 1.1 可证伪的问题

> 固定一组 14 维图像基底 φ 与一根标量场 `s = 3·tanh(q/3)`，`q = w₀ + α·(w_dir·φ)`。
> **只允许沿 s 做一维读出**（即最终掩膜是 `m(p) = r(s(p))`，r 是一元函数），
> 逐掩膜自由挑选 (w₀, α, w_dir) 与 r 的参数，能不能把线性渐变 / 径向椭圆 / **薄环** / 束状楔形 / 真实语义掩膜画出来（soft-IoU 判据）？
> 特别地：**薄环**只能靠沿 s 的「非单调」读出画出，还是单调读出也够？
> 再特别地：那个能画出薄环的读出 r，**是不是落在渲染器自己那根受约束的 s 轴能实现的读出集合里**？

三条可证伪判定（预注册在 `PLAN §1.5` 判据表，当前 L209–L214）：

- 线性 / 径向的单调档 <0.97 ⇒ **实现有 bug 或基底选错**，设计不往下走（PLAN L218）。
- 环形拿不到「带通 ≥0.90 vs 单调 ≤0.40」这一对 ⇒ **「s 是第四根坐标轴（寻址坐标）」这条 novelty 主张与整个 5D 方案重估**（PLAN L218）。
- 语义族 <0.75 ⇒ 语义基维度不够（k=6→8）或文本基共线（PLAN L213）。

### 1.2 它在技术路线里的位置：为什么先做纯离线拟合

整条路线是：VLM 读出 → s 场 → 渲染器（N 个 4D 高斯 + 全局仿射）→ 烘焙成 LUT。
E2 只测其中一环：**「s 的生产端」的表达力**。之所以要在训练任何模型之前先做，有四个理由：

1. **它问的是「可表达性」而不是「可学习性」**。逐掩膜用 L-BFGS 从 8–12 个起点独立拟合，
   得到的是这个假设类**近似的最好情况**。如果最好情况都画不出目标掩膜，
   那么任何 amortized 的读出器（VLM / attention 读出 / 小网络）都不可能画出来——
   离线拟合是在线系统的**上界**。反过来不成立：E2 通过**不**证明在线系统能产出这些系数，
   那是 RO 臂与 MB-2..5 的事。这条限定必须随结论一起写。
2. **它把混淆因子清干净**。端到端跑一遍再看失败，失败可能来自读出器、s 缓存的域错配、渲染器、优化器中的任何一个
   （仓库 `CLAUDE.md`「s 缓存消费契约」记录了三次此类踩坑，其中一种是**静默**的）。
   离线拟合里只剩「基底 + 沿 s 的读出形状」两件事。
3. **成本比**。全量第一回合 4,344 次拟合，36 workers、CPU、**3,938 s**（`config/fit.json .wall_seconds`）；
   数据准备（含 CLIP 特征）单卡 **350 s**（`config/prep.json .wall_seconds`）。
   而它把关的决策（5D 方案是否继续）值 GPU-周。
4. **它直接产出论文里的一张图**。PLAN L211 原话：「这对数字 =「高斯轴买到了什么」的量化证据，**单独成图**」。

## 2. 掩膜基底：`s(p) = Φ(I,p)·w` 里每个符号是什么

### 2.1 形状与符号

记单张图像 `I`（H×W），像素 `p`，像素总数 `P = H·W`。

```
φ(I, p) = [ 1 ; x, y, P₂(x), P₂(y), x·y ; L, S ; e₁, …, e₆ ]  ∈ R^14
                └── 几何 5 ──┘   └范围2┘  └─ 语义 6 ─┘

q(p) = w₀ + α · ( w_dir · φ_dir(I,p) ),   w_dir ∈ R^13, ‖w_dir‖₂ = 1, α ≥ 0
s(p) = 3 · tanh( q(p) / 3 )  ∈ (−3, 3)
m̂(p) = r( s(p) )              r = 沿 s 的一元读出（§3）
```

- **14 维 = 1 个常数项 + 13 个方向维**。代码里常数项不进矩阵：`build_phi()` 对 `cols="full"` 返回
  `(P, 13)`（`run_fit.py:107–120`），常数由 `w₀` 承担（`e2lib.py:216–221`）。
  `e2lib.DIR_NAMES_14` 的注释写得很清楚：`13 dirs + [1]`（`e2lib.py:48`）。
- **Φ 的形状**：拟合时 stride=2 ⇒ `Φ_fit ∈ R^{65536×13}`；评测时 stride=1 ⇒ `Φ_eval ∈ R^{262144×13}`（512² 图）。
- **w 的形状**：`w = (w₀, α, w_dir) ∈ R × R₊ × S¹²`，**共 15 个数、13 个自由度**
  （`w_dir` 在 12 维球面上 + α + w₀）。这就是「一张掩膜 = 13 个自由度」的意思。
- **规范分解的理由**（PLAN §1.3，当前 L71）：把尺度全部收进 `α`，让 **`α = 0` 精确退化为全局掩膜**
  （`s ≡ 3tanh(w₀/3)` 为常数）。如果不做球面约束、直接学一个 `w ∈ R^13`，退化点是 `w = 0`，
  在球面参数化下不可达；分解之后 `α = 0` 可达且可检验——这正是 `constant` 族判据要验的东西（§7.1）。
- **α 的参数化**：`α = softplus(a_raw)`（`e2lib.py:219`），保证 α ≥ 0 且 α→0 可达。
- **ψ = 3·tanh(q/3)**：把无界的 q 压进 (−3,3)，与渲染器 s 轴的网格域 `μ ∈ [−3,3]`（PLAN L60）自洽。
  它是**严格单调**的，所以 s 的等值线族 = q 的等值线族——这条性质是 §7.2 那个解析论证的前提。

### 2.2 十四维逐维定义

#### (a) 几何 5 维（Legendre，中心化 / 除以短边一半）

`e2lib.norm_coords()`（`e2lib.py:82–89`）：

```
half = min(H, W) / 2
x(col) = (col + 0.5 − W/2) / half      y(row) = (row + 0.5 − H/2) / half
```

即**短边张成 [−1, 1]**，长边按同一尺度外推（非方图上长边会超出 [−1,1]）。五个几何维是

```
x,  y,  P₂(x) = (3x²−1)/2,  P₂(y) = (3y²−1)/2,  x·y
```

（`e2lib.py:92, 100–106`）。三次档 `cubic18` 另加 4 项 `P₃(x), P₃(y), P₂(x)·y, x·P₂(y)`（`e2lib.py:96, 104–105`）。

**为什么用 Legendre 而不是单项式 `1,x,y,x²,y²,xy`**：条件数。实测 Gram 条件数
Legendre **9.00007** vs 单项式 **17.2813**（`M:.condition_checks.gram_cond_legendre6 / .gram_cond_monomial6`），
预注册门是 <10（PLAN 当前 L217）。单项式档过不了这个门。

#### (b) 范围 2 维

`e2lib.range_channels()`（`e2lib.py:124–131`）：

```
L = 0.2126 R + 0.7152 G + 0.0722 B      （Rec.709 亮度权重，直接作用在 sRGB 值上，未做线性化）
S = (max(R,G,B) − min(R,G,B)) / max(R,G,B)   （HSV 饱和度；max ≤ 1e−6 时置 0）
```

两者都**逐图标准化**（减均值除标准差，eps=1e−6，`e2lib.py:134–135`，`prep_data.py:152`）。
逐图标准化在这里是允许的：红线禁止的是**对 s 场**做逐图 min-max/softmax 归一化，
这里归一化的是**输入基通道**，且是固定的确定性变换，不引入逐图自由参数。

#### (c) 语义 6 维（e₁..e₆）

这是唯一需要跑网络的一块。链路（`prep_data.py:140–165` + `e2lib.py:601–670`）：

1. **模型**：`openai/clip-vit-large-patch14-336`，本地权重（`local_files_only=True`）。
2. **文本锚**：6 组固定文本 `sky / skin / foliage / water / architecture / subject`
   （`e2lib.ANCHORS`，`e2lib.py:50–61`）。每组 3–4 个 prompt，各自 L2 归一化后取均值，再归一化 ⇒ `text ∈ R^{6×768}`（`e2lib.py:617–625`）。
   **顺序固定**为 `ANCHOR_ORDER`，所以 e₁..e₆ 的语义身份是固定的，不是学出来的（PLAN §1.3「固定文本投影锚定身份」）。
3. **稠密特征（MaskCLIP 式）**：图像 Lanczos 缩到 672²，patch 14 ⇒ 48×48 网格；
   位置编码从 24² 双三次插值到 48²（`e2lib.py:641–655`）。
   **最后一个 block 的注意力换成恒等**：`h ← h + out_proj(v_proj(LN₁(h)))`，再 `h ← h + MLP(LN₂(h))`，
   过 post-LN 与 `visual_projection`，L2 归一化（`e2lib.py:656–667`）。
   这一步是 MaskCLIP 的标准做法：不换掉最后一层 attention，patch token 会被 CLS 的全局池化污染，拿不到稠密的空间响应。
4. **相似度**：`sims = feats @ textᵀ ⇒ (48,48,6)`（`e2lib.py:668–670`）。
5. **上采样**：`scipy.ndimage.zoom` 双线性到 (H,W)（`prep_data.py:144–146`）。
6. **guided filter**：guide = L（亮度），r=32，eps=1e−3（`e2lib.py:165–173`，`prep_data.py:148–150`）。
   PLAN §1.3（当前 L77）明文要求 guided filter 作用在 **k 个基通道**上，**不是**作用在最终的 s 上——
   这里严格照此实现（滤的是 6 个语义通道，不是 s）。
7. **逐图标准化**（`prep_data.py:151`）。
8. **对几何+范围块做残差正交化**：`A = [1, x, y, P₂(x), P₂(y), x·y, L_std, S_std] ∈ R^{P×8}`，
   逐图最小二乘 `E_resid = E − A·(AᵀA)⁻¹AᵀE`（`e2lib.residualize`，`e2lib.py:138–152`；`prep_data.py:153–156`）。
   目的：让语义块**只携带几何/亮度解释不掉的那部分**，避免消融时把「语义贡献」和「几何贡献」算重。
9. **再标准化一次**（`prep_data.py:158`）。

**记账**：残差化前后块外相关的 Frobenius 范数逐图落盘在 `cache_meta/residualization.json`（276 条）：
前 mean **1.9858**、后 max **2.8506e−14**（`M:.condition_checks.offblock_corr_fro_before_mean / .offblock_corr_fro_after_max`）。
`M:.condition_checks.note` 自己诚实标注了：这是**逐图精确 lstsq 投影**，所以「后 ≈ 0」是构造性满足，
**不是一条独立证据**，不能当作「语义通道确实与几何无关」的实验发现。

### 2.3 为什么是「基 × 系数」，不是逐像素预测

五条理由，前三条是硬约束，后两条是收益：

1. **渲染器的硬边界**（PLAN 当前 L47）：「逐像素算子禁 (x,y)/邻域、禁 MLP、禁排序/α-blend；
   σ 必须有界；**s 须可折回逐点函数或「N 张 LUT+guide」**」。
   一个逐像素 CNN/MLP 预测的掩膜无法折回逐点函数，也就无法烘焙。
2. **烘焙一致性**：运行时的最终形态是 33³ LUT 查表（PLAN L46）。s 必须是能与 LUT 一起烘焙的东西。
   固定基 × 少量系数天然满足；逐像素网络不满足。
3. **可编辑性**：`q` 是 (x,y) 的非齐次二次型 ⇒ 可以闭式反解出椭圆中心 / 主轴 / 羽化环（PLAN §1.3 末），
   用户能直接拖动掩膜。逐像素预测给不出这些量。
4. **精确退化**：α=0 ⇒ 掩膜恒定 ⇒ 渲染器退回全局曲线。这是一条可检验的安全性质（§7.1 常数族判据）。
5. **容量证据**（PLAN 当前 L48，文献锚点）：把逐像素算子做大几乎不涨点
   （CSRNet×41 = +0.2 dB、AdaInt×7.6 = +0.05 dB、SepLUT×5.6 = +0.06 dB、NeurOp×2 = +0.03 dB），
   而给 CSRNet 加 condition network = +3.22 dB。**收益在「条件」而不在「像素算子」**，
   所以把自由度放在「基 × 系数」这一侧是有文献依据的选择。

**代价**（必须一起写）：单轴 v1 的表达力上限是「一族嵌套的水平集」。
它画不出**多个互不相连的实例**，也画不出**重叠的软掩膜**——前者在 §7.5 的语义族尾部已经被量化，
后者本实验完全没测（留给 MB-2 双轴）。

## 3. 沿 s 轴的读出（readout）

### 3.1 六种读出的数学形式

所有读出都作用在同一个 `s(p) ∈ (−3,3)` 上，实现在 `e2lib._forward()`（`e2lib.py:216–241`）
与 `e2lib._constrained_mask()`（`e2lib.py:198–213`）。σ(·) 记 logistic。

| # | 档名 | 公式 | 可学参数（含 w₀, α, w_dir 的 15 个数） | 约束 |
|---|---|---|---|---|
| 1 | `monotone`（无约束·单调） | `m = σ(g·s + b)` | +g, b（**无界**） | 无 |
| 2 | `bandpass`（无约束·平顶带） | `m = σ(k(s−μ+h)) − σ(k(s−μ−h))` | +μ, h, k ⇒ **18 个数** | μ 自由；`h = 0.02 + 2.48·σ(h_raw) ∈ (0.02, 2.5)`；`k = 1 + 39·σ(k_raw) ∈ (1, 40)` |
| 3 | `gauss`（无约束·严格单高斯） | `m = exp(−½((s−μ)/σ)²)`，**幅值恒 1** | +μ, σ ⇒ 17 个数 | μ 自由；`σ = 0.05 + 2.95·σ(sig_raw) ∈ (0.05, 3.0)` |
| 4 | **`cband_norm`（约束·归一化混合 = 渲染器真参数化）** | `m = Σᵢ cᵢ oᵢ N(s;μᵢ,σᵢ) / (Σⱼ oⱼ N(s;μⱼ,σⱼ) + 1e−9)` | +σ(12), o(12), c(12) ⇒ **51 个数** | **M=12；μ = linspace(−3,3,12) 固定 buffer，不进优化器**；`σᵢ = 0.025 + 0.275·σ(·) ∈ [0.025, 0.30]`；`oᵢ, cᵢ = σ(·) ∈ (0,1)` |
| 5 | `cgauss`（约束·单基元） | `m = exp(−½((s−μ_k)/σ)²)`，幅值恒 1 | +σ ⇒ 16 个数 | μ_k **锁死在网格点**上（起点时选定，不可学）；σ ∈ [0.025, 0.30] |
| 6 | `cband_unnorm`（约束·未归一化） | `m = clamp(Σᵢ cᵢ oᵢ N(s;μᵢ,σᵢ), max=1)` | 同 4 ⇒ 51 个数 | 同 4，**去掉分母** |

参数量对比来自逐档数参数（本文按 `e2lib.fit_mask` 的 `params` 字典逐项数出：
`w₀`(1) + `a_raw`(1) + `u`(13) = 15 是共有部分）：**约束档 51 vs 无约束平顶带 18**，与 `R§2` A-4 行、`N§补件轮` 的说法一致。

三条红线在这里逐条对上：

- **σ 一律有界 sigmoid，全程无裸 exp**：`_sig_bounded()`（`e2lib.py:193–195`）。
- **s 轴无任何平滑正则**：`_loss()` 只有 `1 − soft-IoU`（`e2lib.py:244–248`），没有第二项。
- **μ 不可学**：`params["mu_grid"]` 是 `torch.tensor(grid)` 且**不设 `requires_grad`**，
  优化器只接收 `[v for v in params.values() if v.requires_grad]`（`e2lib.py:377, 415–418`）。

### 3.2 为什么「渲染器真参数化」那一档是关键

前三档是**自由读出**：它们回答的是

> ∃ 某个一元函数 r，使得 `r(s(·))` 逼近目标掩膜？

而渲染器实际能画出的掩膜集合要小得多。按 PLAN 当前 L52 的权重式，固定一个 RGB 点后，基元 i 的权重退化为

```
w_i(s) = o_i N(s; μ_i, σ_i) / Σ_j o_j N(s; μ_j, σ_j)
```

而 PLAN 当前 L79 明文：「**s 轴上的 M=12 个高斯本身就是 12 张带通掩膜**」。
所以「一张渲染器能画出的掩膜」的正式定义是

```
m(p) = Σ_i c_i · w_i( s(p) ),   c_i ∈ {0,1}   （携带同一载荷的基元子集）
```

（`N§缺口 A：被测对象的形式化`）。这是一个**离散的、被 M/μ/σ 三重约束的**函数族：
μ 冻死在 12 点网格上、σ 被反塌陷红线 R-2 卡在 [0.025, 0.30]、权重必须跨基元归一化。

第一回合的核心数字 0.975 是用**自由平顶带**（第 2 档）拿到的。审阅（`REVIEW-result.md §2.4`）指出的问题正是：

> 0.975 依赖「读出有平顶」，而**没有任何产物证明受约束的 s 轴能合成这个平顶**。

如果合成不出来，那么 0.975 就只是「某个自由读出能画出薄环」，与渲染器无关，
审稿人一句「你挑的读出，渲染器根本做不到」就打掉了。**第 4 档就是来回答这一句的**，
第 5、6 档是它的两个对照：

- 第 5 档（`cgauss`）拆掉「多基元 + 归一化」只留「网格 + 有界 σ」，用来判断**约束到底咬在哪里**；
- 第 6 档（`cband_unnorm`）拆掉归一化分母（= R-6 / RD-D 的形态），用来判断**买到平顶的是「混合」还是「归一化」**。

### 3.3 读出形式的两处设计选择（都属于「两种做法都合理」）

**(1) 平顶带写成两阈值 logistic，而不是单高斯**（`N§冒烟后的两处修订` 第 2 条，主动声明为「看到冒烟数字之后做出的决定」）。
理由当时是经验的：环形目标的径向剖面是**梯形**（有平顶），幅值恒 1 的高斯只在单一半径取到 1，剖面对不上，冒烟中位数只有 0.78。
**补件轮把这条从经验升级成推导**（§6.3）：归一化高斯轴的单基元响应**在解析上就等于**两阈值 logistic 带（误差 1.51e−07，`MB:.formula_verification.anchor_round2_case`）。
所以这个选择现在有两重依据：实测差 0.78 vs 0.975，以及解析等价。

**(2) 载荷 cᵢ 用连续松弛 + 事后硬化，而不是直接搜 2¹² 个 0/1 组合**（`N§本轮的假设` 第 2 条）。
连续松弛可微、能进同一个 L-BFGS；代价是「平顶可能是靠连续幅值凑的」。
所以预注册了 **A-3**：把 cᵢ 四舍五入到 {0,1}（其余参数不动）重新评测，掉幅必须 ≤0.02（`e2lib.py:479–488`）。实测见 §7.4。

### 4.1 五个合成族的采样（`prep_data.py:48–133`）

公用量：`H = W = SIZE = 512`；**`D = hypot(512,512) = 724.077 px`**（对角线，径向类的长度单位）；

| 族 | 张数 | 生成式（像素坐标 `xs, ys` 取格心 +0.5） | 采样范围 |
|---|---|---|---|
| **linear**（线性渐变） | 200 | `t = xs cosθ + ys sinθ`；`m = smoothstep((t₀ − t + w/2)/w)` | `θ ~ U(0,2π)`；`w = U(0.05,0.50)·512`；`t₀ ~ U(q₂₀(t), q₈₀(t))` |

**薄环的定义是本实验里唯一被事后改过的东西，且被主动声明**（`N§冒烟后的两处修订` 第 1 条）：
初版是 `hw ~ U(0.03,0.10)·D`（**绝对宽度**），会产出「胖环 / 近圆盘」，

改成 `hw ≤ 0.10·r_mid`（**相对宽度**）后上界降到 0.21–0.33。
NOTES 的立场：这是**掩膜族定义的修正**（让判据检验读出能力而不是环的肥瘦），拟合器与判据一个字没动，
且「修正在看到冒烟数字后做出，特此声明」。§7.2 会说明这个修正的代价。

**一处实现与注释不符**（本文核对）：`prep_data.py:123–125` 注释写 `reject degenerate coverage`，
但代码是 `if not (0.02 <= m.mean() <= 0.9): m = np.clip(m, 0, 1)`——**只做了 clip，没有拒绝重采样**，
而 m 本来就在 [0,1] 内，所以这一句是空操作。后果：**15.5% 的 radial_ell 掩膜覆盖率 >0.9**
（最高 0.9894，即几乎全画幅）【本文现算：对 `results.jsonl` 中 `main14|monotone` 各族的 `target_mean` 统计】。
近全画幅的掩膜对单调读出是**送分题**，会让 radial_ell 那一格略微偏高。这条不影响任何判据的过/不过（该格判据是 ≥0.97，实测 0.9857），但复现者应当知道。

## 5. 拟合过程

### 5.1 目标函数：soft-IoU（min/max 形式）

```
softIoU(m̂, t) = Σ_p min(m̂(p), t(p)) / ( Σ_p max(m̂(p), t(p)) + ε ),   ε = 1e−6
loss = 1 − softIoU
```

（`e2lib.py:180–181, 244–248`）。

**为什么用 min/max 而不是乘积式**（`N§关键实现口径` 第 1 条，属于「两种做法都合理」的决策，已当场定标）：
对**软目标**，min/max 形式在完美恢复时恰好取到 1.0；而乘积式
`Σm̂t / (Σm̂ + Σt − Σm̂t)` 在完美恢复一个软掩膜时**小于 1**，无法支撑 ≥0.97 这种阈值语义。
乘积式仍然逐行落盘为次要指标 `iou_prod`（`e2lib.py:454`），随时可以换口径复核。

**为什么这不违反「IoU 禁当优化目标」红线**：该红线针对**在线训练**；
这里 soft-IoU 是 `PLAN §1.5`（当前 L205）**明文规定的离线拟合损失/度量**。
第一回合已论证，结果审阅明确背书并要求记录在案免得复审重开（`REVIEW-result.md §四 nit 6`）。

**常数族是例外**：目标 `m ≡ 0` 时分子恒 0，min/max IoU 恒 0，指标无意义。
所以常数族的判据用 **α 与 pred_std**，另报 MAE 与补集 IoU（`e2lib.py:447–454`），
且 IoU 聚合不含常数族（`N§关键实现口径`）。`metrics.json` 里这些格带 `metric_na: true` 标记
（`M:.per_cell["main14|bandpass|constant"].metric_na`），这是补件轮响应审阅 nit 2 加的。

### 5.2 优化器与多起点

`torch.optim.LBFGS`，**float64**，`line_search_fn="strong_wolfe"`，`max_iter=120`，
`history_size=20`，`tolerance_grad=1e−9`，`tolerance_change=1e−11`（`e2lib.py:415–418`）。

`max_eval` 未显式设置 ⇒ 取官方默认 `max_iter × 1.25 = 150` 次闭包求值。
这条是**在线核实过的**：`N§补件轮实施前核实` 第 2 条记录了打开 PyTorch 2.6 官方 API 文档逐条抄录
（本地 torch 2.6.0+cu124 对齐），并**据此推出一个风险**：约束档 51 个参数 vs 无约束带通 18 个，
150 次闭包**可能成为约束档的预算瓶颈**，从而把「表达力不足」与「优化预算不足」混淆——
所以补件轮加了 A-4 预算对照（§6.5）。这是本实验里「先核实事实、再据此加一条判据」的范例。

**起点集合**（`e2lib.fit_mask`，`e2lib.py:328–356`；`run_fit.fit_task`，`run_fit.py:138–146`）：

| 起点 | 构造 | 用在哪 |
|---|---|---|
| LSQ 起点 ×1 | 对 `logit(clip(t,1e−3,1−1e−3))` 做最小二乘 ⇒ (w₀, α, u)（`e2lib.py:250–260`） | 全部档 |
| 随机起点 ×6 | `u ~ N(0,I)`，`w₀=0, α=1`，读出参数按档给（`n_random=6`） | 全部档 |
| α≈0 起点 ×1 | `α = 0.05`——**保证常数掩膜的退化解在搜索路径上** | 全部档 |
| 质心-径向起点 ×2 | 用目标质心 (a,b) 解析构造 `q ≈ −((x−a)² + (y−b)²)`（借 `x² = (2P₂(x)+1)/3` 换算），缩放到 s 跨 ~[−2,2]，μ/σ 取目标加权的 s 统计量（`e2lib.radial_starts`，`e2lib.py:495–532`） | 除 `lin3`（D<5 直接返回空） |
| 约束档热启动 ×2 | 从**同一张掩膜的无约束平顶带解**构造：`q̃ = λ(q − q_μ) + q_grid`，`λ = 目标半宽/拟合半宽`，`q_x = 3·artanh(x/3)`，`σ = √(Δμ·λ/k)`，并按 n_on ∈ {1,3} 置 cᵢ（`e2lib.band_warm_start`，`e2lib.py:535–565`） | 仅 `cband_norm` / `cband_unnorm` |
| 网格中点锚 ×1 | `cgauss` 专用的第二个网格点候选 | 仅 `cgauss` |

**所以每张掩膜的实际起点数是：**

| 档 | 起点数 |
|---|---|
| `lin3`（2 维方向基，无质心-径向） | **8** |
| `monotone` / `bandpass` / `gauss`（非 lin3） | **10** |
| `cgauss` | **11** |
| `cband_norm` / `cband_unnorm` | **12** |

`R§1` 写的「每掩膜 12 个起点」**只对约束带通档成立**，无约束档实际是 10 个（`lin3` 是 8 个）。
这是表述不精确，不影响结论方向（约束档拿到的起点**更多**，比较偏向约束档一侧，
与 §6.4「公平性措施」的意图一致）。本文按代码给出精确值。

**热启动为什么不算作弊**：`N§缺口 A 的公平性措施` 第 1 条明确写了理由——
「热启动只是优化辅助，**问的是表达力不是优化运气**」。同时保留 LSQ / 随机 / α≈0 / 质心-径向全部起点，
再加 A-4 预算对照兜底。三条措施都是往「不许拿优化失败冒充表达力失败」这个方向使劲的。

**选优与 tie-break**（`e2lib.py:435–438`）：取损失最小的起点；**损失差 ≤1e−4 时取 α 更小的那个**。
理由：常数掩膜有一整条等价解流形（α 任意小都能画出常数），tie-break 保证退化解被选中，
否则 `constant` 族的 α 判据会被随机的大 α 解污染。

### 5.3 stride-2 拟合、全分辨率评测

拟合用 `Φ_fit`（stride=2，256²-等效，65,536 行），最终解在 `Φ_eval`（stride=1，512²，262,144 行）上评测
（`run_fit.py:134–137`，`e2lib.py:441–448`）。理由是成本：L-BFGS 每次闭包都要过一遍全部像素，
stride=2 直接省 4×。

**这个近似有多大代价**：拟合损失（stride-2）与评测 IoU（全分辨率）的逐格中位差【本文现算：
对每行取 `1 − loss_fit` 与 `iou_minmax` 作差】：

| 格 | stride-2 拟合值中位 | 全分辨率评测中位 | 中位差（评测 − 拟合） |
|---|---|---|---|
| `main14｜monotone｜ring` | 0.3433 | 0.3423 | **−0.00024** |

### 6.2 响应级实验的设计（`axis_response.py`）

掩膜级的比较里混着「基底能不能画出这个 s 场」和「读出能不能画出这个剖面」两件事。
响应级实验把前者剥掉，**只测形状**：

1. **目标**：第一回合每个环拟合出的 logistic 带，归到无量纲坐标 `u = (s−μ)/h` 上就是
   `r*(u) = σ(β(u+1)) − σ(β(u−1))`，其中 **`β = h·k` 是这条带唯一的仿射不变量**
   （`axis_response.py:54–57, 195–197`）。所以每个环给一个 β，n=200 条。
2. **被测**：约束轴响应 `r_c(s) = Σᵢ cᵢoᵢN(s;μᵢ,σᵢ) / Σⱼ oⱼN(s;μⱼ,σⱼ)`，σ/o/c 全部自由（在各自的界内）。
3. **允许仿射重参数化**：基底里的 α 与 w₀ 本来就自由，所以 s 轴允许缩放/平移：
   `s = μ' + h'·u`，`h' = 0.1 + 0.65·σ(h_raw) ∈ (0.1, 0.75)`，`μ' = (3 − 4h')·tanh(m_raw)`
   （`axis_response.py:114–115`）。**`μ'` 的这个参数化是关键的防作弊设计**：
   它强制评测窗 `[μ'−4h', μ'+4h']` 留在可达的 s 区间 (−3,3) 内，
   堵死「把带做得比整根轴还宽，于是处处平坦」这个退化解。
4. **损失**：**普通 MSE**（不是 IoU）——这是形状测试，`axis_response.py:123`；
   评测窗 `u ∈ [−4,4]`，1601 个采样点（`axis_response.py:51`）。
5. **优化**：LBFGS，`max_iter=200`，4 次重启（n_on ∈ {1,3} 的知情起点 ×2 + 加噪 ×2），
   `tolerance_grad=1e−10`（`axis_response.py:81–111`）。
6. **指标**：平顶区 `{r* ≥ 0.9}` 上的最大偏差、全窗 RMSE（`axis_response.py:131–140`）。

**A-5 的 27 格**就是把上面的协议在 `M ∈ {6,12,24} × σ_max ∈ 9 档` 上各跑一遍，每格 n=30 条真实 β
（`axis_response.py:217–235`；n=30 见 `--n-sweep` 默认值 `axis_response.py:188`）。
注意每格的 `sig_lo` 也随之收紧为 `min(0.025, σ_max·0.5)`（`axis_response.py:225`），
否则 σ_max=0.05 那几格会出现 `sig_lo > sig_hi`。

### 6.3 闭式可达范围：为什么「一定能」

这条推导把「事后换读出」的质疑一并解掉。设同一格内 σ 相等，看相邻两个基元的归一化竞争：

```
log( o_k N_k(s) ) − log( o_{k+1} N_{k+1}(s) )
      = (Δμ/σ²)·( s − s_mid ) + log(o_k / o_{k+1}),      Δμ = 6/(M−1)
```

即**对数比在 s 上是精确仿射的** ⇒ 一个基元的归一化权重 `w_k(s)` **精确是**一条两阈值 logistic 带：

```
w_k(s) = σ(k_eff (s − a)) − σ(k_eff (s − b))
k_eff = Δμ/σ²                                    （边斜率）
a = a_mid + (σ²/Δμ)·ln(o_left/o_on)              （左交点）
b = b_mid − (σ²/Δμ)·ln(o_right/o_on)             （右交点）
h = (b−a)/2,   β = h·k_eff                        （形状不变量）
```

（`beta_reach.py:5–13`）。两种读法：

- **等不透明度读法（第二回合报的那个）**：o 全相等 ⇒ 交点落在网格中点 ⇒
  `h = n_on·Δμ/2` ⇒ **`β_sym = n_on·Δμ²/(2σ²)`**（`axis_response.reachable_beta`，`axis_response.py:172–182`）。
- **自由不透明度读法（wave 3 补的修正）**：oᵢ 在 PLAN L52 里是**真实的可学参数** ⇒
  **`β = β_sym − ln(o_邻/o_载荷)`**（`beta_reach.py:22–27`）。
  把载荷格调暗、邻格调亮就能把 β 压到 β_sym 以下，**且平顶高度不受影响**
  （峰值 `1/(1+2e^{−β})`，与目标带的 `tanh(β/2)` 同形）。

**数值核验**（`MB:.formula_verification`，`beta_reach.py:174–189` 定点 + `beta_reach.py:79–126` 分层随机）：

| 情形 | β | `max|w_k − 两阈值 logistic 带|` |
|---|---|---|
| M=12, σ=0.1347, 等不透明度（复现第二回合的锚点） | 8.1988 | **1.5110e−07** |
| M=6, σ=0.30, 等不透明度 | 8.000 | 2.2484e−07 |
| M=6, σ=0.30, `ln(o_邻/o_载荷)=1.60` | 6.400 | 5.4941e−06（峰值 0.99669） |
| M=6, σ=0.30, `ln 比 = 1.84` | 6.160 | 8.8670e−06（峰值 0.99579） |
| 随机 1,500 组（seed=1），限在环形工作区 β∈[6,13]，n=308 | — | 中位 1.5749e−07 / p90 8.9776e−05 / max 5.3398e−03 |
| 随机 1,500 组，`Δμ/σ < 2`（相邻高斯严重重叠），n=243 | — | 中位 **0.2381**（恒等式失效区） |

**所以这条恒等式是有适用域的**：只在相邻基元充分分离（`Δμ/σ ≳ 3`）时成立，
而所有实拟合出来的环都住在 `β ≈ 8 ⇔ Δμ/σ ≈ 4` 这个区域里。这一条 wave 3 主动做了分层核验，
没有把「1e−07」这个数字外推到不成立的区域。

**可达集 vs 实需**（`MB:.required_beta`、`M:.wave3["beta_reach_per_M_domain_pm3_sigma_0.025_0.30"]`）：

- 200 条环实际需要的 β（= 第一回合逐环拟合出的 `h·k`）：
  main14 **min 6.158 / p10 6.466 / 中位 8.396 / p90 11.282 / max 12.660**；
  geo6-only min 5.969 / p10 6.379 / 中位 8.142 / p90 11.008 / max 11.936。
- M=12、σ∈[0.025,0.30]、等不透明度、n_on=1 的可达区间 **[1.653, 238.0]**；n_on=3 时 **[4.959, 714.0]**
  （`MA:.reachable_beta_closed_form`）。
- ⇒ 实需完整落在可达区间内部，两端都有量级余量。**这就是 A-2 的偏差只有 1e−05 的原因。**

**wave 3 的第二处修正**：把载荷组大小 n_on 放开后，等不透明度可达集 = `∪ₙ [n·f/σ_hi², n·f/σ_lo²]`（`f = Δμ²/2`）。
因为 `σ_hi ≥ √2·σ_lo`（0.30 ≥ 0.0354），相邻区间首尾相接 ⇒ **并集是一条射线 `[Δμ²/(2σ_hi²), ∞)`**
⇒ **真正起作用的只有下界；第二回合报的上界（238 / 714）从来没咬过**（`MB:.closed_form_correction.reachable_set_is_ray`）。

**这条修正的方向很重要**：它让「需要的 β 落在可达集内 ⇒ 画得出」这个**充分性**论证更强
（连最保守的等不透明度读法都够）；但让**反向推断**「落在可达集外 ⇒ 画不出」**不成立**。
所以 M=6 这一档不能只看解析表，必须补数值验证——wave 3 就是这么做的（§7.6）。

### 6.4 公平性措施（避免「约束档因为没调好而失败」）

### 6.5 A-4：把「表达力不足」和「优化预算不足」分开

**动机不是事后补的**：它来自 §5.2 那次对 PyTorch 文档的核实——
`max_eval` 默认只有 150 次闭包，而约束档参数量是无约束档的近 3 倍。
**预注册的门**：`max_iter` 120 → 300 的中位提升必须 **<0.01**，否则 A-1 只能叫「预算受限下的读数」，不能叫表达力结论。

第二回合实测 n=8（机器被压满，降 n）：**+0.010465**（`M:.criteria_supplement_gapAB.A4_budget_control_gain_lt001`）——**未过门**。
wave 3 按预注册的 n=40 正式复跑：**+0.012695**，bootstrap 95% CI **[+0.009949, +0.016416]**，
95.0% 的环变好（`MW:.A4_rerun`）——**仍未过门，而且效应量更大**。

**wave 3 另补了 A-4 真正该有的对照**（`MW:.A4_budget_matched`，明确标注**新增、非预注册**）：
光看约束档自己涨多少不够，要看**同预算下两档的差**。于是把无约束平顶带也在 300 步上跑同一批 40 条环：

| 对照 | 中位 soft-IoU | 配对中位差（95% CI） |
|---|---|---|
| 无约束平顶带 120 → 300 步 | 0.97556 → 0.97657 | **+0.0000788**（[3.07e−08, 2.147e−04]）⇒ **无约束档在 120 步就已收敛** |
| 约束档 120 → 300 步 | 0.97576 → **0.98904** | **+0.012695** ⇒ 约束档在 120 步确实吃不饱 |
| A-1 掉幅（约束 − 无约束）@ 120 步 | — | −0.000851（[−0.004088, +0.003042]） |
| **A-1 掉幅 @ 300 步（预算匹配）** | — | **+0.010848**（[+0.009681, +0.014791]）⇒ **约束档反超** |

**结论的正确写法**：A-4 **FAIL（未过预注册门）**，如实保留；
但它想防的那个错误（拿优化不足冒充表达力结论）**没有发生，方向完全相反**——
在预算匹配下约束档比自由读出还好 +0.011，所以第二回合的「掉幅 −0.000」是一个**被 120 步压出来的保守读数**。

「矩阵完备性」三格（约束档 × 线性/径向/楔形）降到 n=4，只作**存在性检验**（三格的格内 min 分别是 0.9903/0.9931/0.9233，方差很小）。
**n=4 的格不能用来做任何统计比较**，这一点 REPORT 已注明，本文再强调一次。

**语义族两个约束格是「不适用」而不是「缺格」**（wave 3 订正 R-1，`M:.wave3.corrections["R-1"]`）：
缺口 A 问的是「受约束的 s 轴能否合成**平顶**」；语义掩膜是主体/背景类软掩膜，沿 s 的目标剖面**单调**，没有平顶需求。
实测直接支持：语义族**单调 0.87301 vs 无约束平顶带 0.87439，平顶只值 +0.0014**；
而环形族同一对比是 0.34227 vs 0.97528（**+0.633**）。
仍然成立的限定（订正文自己写了）：若论文要把「渲染器可画出的掩膜」这句话**直接**用在语义掩膜上，
仍需补 `main14｜cband_norm｜semantic`（n=176，约 3–5 CPU-小时）——那是**另一个问题**（表达力覆盖面），不是缺口 A。

### 7.2 单调薄环失败是不是「解析必然」——本实验最有说服力、也最需要小心的一点

**论证**（`N§冒烟后的两处修订` 第 1 条 + `REVIEW-result.md §2.1`）：

1. `ψ = 3tanh(q/3)` 严格单调，`m = σ(g·s+b)` 也单调 ⇒ **`m` 是 `q` 的单调函数**
   ⇒ 预测掩膜的每个超水平集 `{m ≥ τ}` 就是 `{q ≥ c}`（g>0）或 `{q ≤ c}`（g<0）。
2. 几何-only 基底下 `q` 是 (x,y) 的**非齐次二次型**，它的超水平集是二次曲线围出的区域：
   圆盘/椭圆的**内部**或**外部**、半平面、双曲区域。
3. 目标是薄圆环（**非单连通**），它不是任何这类区域。最好的两个逼近是
   **(i) 覆盖圆盘 `{d ≤ r_out}`** 与 **(ii) 内盘的补 `{d ≥ r_in}`**。
4. 覆盖圆盘的 IoU = 环面积/盘面积 = `1 − ((1−u)/(1+u))²`，其中 `u = hw/r_mid ∈ [0.06, 0.10]`
   ⇒ **0.2144 – 0.3297**。这个上界 **< 0.40 的门**，所以「单调 ≤0.40」在这个族上**近乎必然**。

**这一步的科研含义**（审阅的判定，REPORT 接受）：核心对的**左半（≤0.40）信息量很低**——
它是掩膜族的性质，不是读出能力的发现；**右半（带通 ≥0.90）才是真发现**。
论文里必须把这个限定带上，否则等于把一个恒等式当成实验结果。

**但「解析必然」这四个字要打个折扣，交付物没有说破这一点**。本文独立复算：

【本文现算：对 200 张实际落盘的 ring 掩膜，用 `masks.jsonl` 里的 (cx, cy, r_mid, hw)
直接构造两个硬掩膜 `{d ≤ r_mid+hw}` 与 `{d ≥ r_mid−hw}`，与真实软目标算 min/max soft-IoU】

| 分支 | min | 中位 | max |
|---|---|---|---|
| (i) 覆盖圆盘 | 0.148 | 0.233 | 0.313 |
| (ii) 内盘的补 | 0.136 | 0.267 | **0.565** |
| 两者取大 | 0.177 | 0.278 | **0.565** |
| 解析式 `1−((1−u)/(1+u))²` | 0.2144 | 0.2726 | 0.3297 |

**关键点**：解析式只覆盖了分支 (i)。分支 (ii)「内盘的补」在**无界平面上**面积无穷、IoU→0，
但在 **512² 的有界画幅**上是有限的；而 `r_mid` 最大到 `0.35·D = 253 px`，此时环的外部有很大一块**掉出画幅**，
补集的 IoU 就爬到 0.5 以上。实测印证：

- `main14｜monotone｜ring` 的 **max = 0.5956、20.0% 的环 > 0.40 门**；
  几何-only 档 max 0.5957、17.0% > 0.40【本文现算：对 `results.jsonl` 逐行统计】。
  （交付物只报了 p90 = 0.4285，`M:.criteria_matrix_main14.ring.monotone.p90`。）
- 单调 IoU 最高的 5 张环，逐张都对得上分支 (ii)：例如 `ring_0598` 拟合 IoU **0.5956**，
  其「内盘的补」IoU = **0.5647**，覆盖圆盘只有 0.2596（r_mid = 250.0 px，u = 0.09）【本文现算】。

**所以正确的表述是**：
> 对 `hw ≤ 0.10·r_mid` 的薄环，单调读出被「覆盖圆盘」上界压在 0.21–0.33，
> **中位数意义上** ≤0.40 是几何必然；但在有界画幅上「内盘的补」这一分支能爬到 0.56，
> **20% 的环超过 0.40 门**。所以判据口径必须写「**中位数**」——这一点 `R§2` 自己也要求了，
> 本文补上了它背后的机制与占比。

**遗留**：审阅（`REVIEW-result.md §2.2`）建议做环厚度扫描 `hw/r_mid ∈ {0.05,0.10,0.20,0.40}`，
画「单调（沿解析上界爬升）vs 严格单高斯 vs 平顶带（恒 ~0.97）」三条曲线，
用来免疫「你把环调薄了」的质疑。**本实验三轮都没做**（`N§待主 agent 决策` 第 7 条：
不在任务卡范围，且需改 prep 采样动缓存，保守默认不做）。这是目前最大的一个未答外部质疑。

### 7.3 楔形：预测被推翻，以及归因

预注册（PLAN 当前 L212）说楔形单调应在 **0.55–0.70**，依据是「对顶领结」论证：
单支楔形的两条边界射线之积 `l₁·l₂` 是**齐次**二次型，其超水平集是对顶的领结，二阶基只能拿到一半 ≈0.5。

实测 **0.94217**（n=200）。判定必须写成**预测被向上推翻**，不是 PASS。
`metrics.json` 为此专门改了字段（响应 `REVIEW-result.md` nit 1）：
`M:.criteria.wedge_mono_expected_055_070` 现在是
`{prediction: "0.55-0.70", measured_median: 0.94217, impl_bug_floor: 0.50, floor_ok: true, prediction_refuted: true}`
（`analyze.py:425–435`）。`floor_ok` 只说明「不是实现 bug」，`pass` 字段被删掉了——
**因为在这个格上「pass」这个词本身没有意义**。这是一处值得学的记分卡设计。

**为什么预测错了**：φ 里同时有一次项 `[x, y]`，所以 `q` 是**非齐次**二次型，
超水平集是一般二次曲线区域，共轭支的位置由线性项控制。
审阅进一步核实：本实验的采样（apex ∈ U(0.3,0.7)²、半角 15°–45°）下**共轭支在画幅内**，
所以这不是「共轭支恰好出界」的采样运气，而是二次曲线族的真实表达力（`REVIEW-result.md §3.2`）。

**归因（本轮补做的几何-only 控制组，回应 `REVIEW-result.md §3.1`）**（`M:.ablations.wedge_attribution_monotone`）：

| 配置 | 楔形单调中位 | 增量 |
|---|---|---|
| `lin3 = [1,x,y]`（= Exposure 类工具的表达上限） | **0.53817** | 基线（**正中预注册的「领结一半」预测**） |
| `geo6 = + P₂(x), P₂(y), xy`（纯几何 6 维，n=100） | **0.93103** | **二次几何项 +0.393** |
| `main14`（+L,S+6 语义） | 0.94217 | 图像/语义通道 **仅 +0.011** |
| `cubic18`（+4 个三次项） | 0.94939 | 三次项 +0.007 |

**不是语义基作弊**。而且这条可以从 limitation 翻成卖点：
`lin3 0.538 → geo6 0.931` 是一条 **+0.39 soft-IoU 的二次项净收益**，
而 lin3 正是 Exposure 类工具的表达上限——「我们比线性渐变多买到什么」就是这个数。

## 10. 这份文档还答不上、mentor 大概率会追问的问题

按「杀伤力」排序：

1. **wave 3 的 M 扫描是在 120 步上做的，而 A-4 证明 120 步会让约束档欠优化约 +0.0127。
   M=6 vs M=12 的配对差只有 −0.0018（main14）/ −0.0114（geo6）——它们比预算效应小一个数量级。
   那么「M=6 掉一点点」这个结论，有多少是 M 的效应、多少是欠优化噪声？**
   交付物没有在 300 步上重做任何一档 M 扫描，也没有报 M 各档的收敛证据。这是目前最尖锐的一个洞。
2. **薄环族被改窄之后，判据到底还剩多少信息量？** 环厚度扫描（`hw/r_mid ∈ {0.05,0.10,0.20,0.40}`）三轮都没做。
   §7.2 的补充分析进一步说明：即便在改窄后的族上，「≤0.40」也只在**中位数**意义上成立，
   20% 的环靠「内盘的补」这一支越过了门。厚度扫描是唯一能一次性回答「你把环调薄了」的实验。
3. **语义族 0.873 里有多少是「同源性」送的？** 语义通道的第 6 个锚就是 `"the main subject of the photo"`，
   而目标 C_GT 正是主体候选掩膜。没有做「去掉 subject 锚只用 5 类锚」的对照，
   也没有做「打乱图像-掩膜配对」的负控制。**语义族这一格缺一条负对照。**
4. **约束档从来没在语义族上跑过**（订正 R-1 把它定性为「不适用」）。
   如果论文要写「渲染器可画出的掩膜」而不是「渲染器可画出的环形掩膜」，这一格必须补。
5. **单轴 v1 画不出重叠软掩膜**——这条 limitation 本实验一次都没测（属 MB-2 双轴）。
   现在 limitation 的证据只有语义族尾部的「多个不相连实例 + 细碎边界」。
6. **soft-IoU 只测覆盖，不测形状贴合。** 环形这种细结构上，两个 soft-IoU 相同的解可能边界质量差很多。
   交付物没有报任何边界类指标（如 grid 级边界 F1），也没有零参数基线列。
   （仓库在 2026-08-05 新加的「空间场判据」红线要求 IoU + grid 边界 F1 + 中心先验基线三列；
   E2 是离线拟合而非空间场读出，不直接适用，但审稿人会问同样的问题。）
7. **`radial_ell` 族有 15.5% 的掩膜覆盖率 >0.9**（近全画幅，§4.1 的 clip 空操作所致）。
   这一格的 0.9857 里有多少是被这些送分题抬上去的？没有按覆盖率分层的报告。
8. **热启动是从「同一张掩膜的无约束解」构造的**（§5.2）。它对表达力问题是合理的，
   但它让约束档与无约束档的比较不是完全对称的（约束档 12 个起点、无约束档 10 个，且其中 2 个源自对方的解）。
   交付物没有做「约束档不给热启动」的对照，所以「约束档反超 +0.011」里有多少来自热启动，无法拆开。
9. **A-2 的目标是第一回合拟合出来的 `r*`，不是真实掩膜的剖面。** 也就是说响应级实验证明的是
   「约束轴能复制自由读出找到的那条带」，而不是「约束轴能画出理想的环剖面」。
   两者在 β 落在可达集内时等价，但这一步的等价性只在闭式层面论证过，没有直接测过。
