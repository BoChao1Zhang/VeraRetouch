## 第二部分 · 本周工作进展

### 2.1 优化 local edit —— 主体感知几何 + 全新标注（最新样本 = 两层）

**动机**：筛查高分 local edit 模板后发现，local edit 的主要目的就是**突出主体**。所以 mask 不能再随机撒，必须能把相片主体凸显出来 → 改成**在 SAM3 主体 mask 的基础上**构造几何。

最新一批 local edit 样本由**两层**组成，分别说清楚：

#### 第一层：几何 / 渲染底座（Mask v3，成片已入库）

**四类模板**（`subject_geom.py`，均为软过渡、画面自然第一）：

| 模板 | 目的 | 构造方式 |
|---|---|---|
| **径向** | 突出主体 | 主体 PCA 长椭圆完整覆盖主体；外扩系数随占比自适应（小主体外扩大、大主体刚覆盖） |
| **束状** | 突出主体（径向变体） | 长轴穿出画幅的软边条带，画面分「侧 \| 束 \| 侧」，束方向取主体主轴 |
| **线性（分区）** | 分区、营造对比 | 主体**完整落在一侧**，分割线可倾斜；分割线离主体距离随占比自适应 |
| **语义 mask** | 贴合主体形状 | 直接用 SAM3 主体 mask + 占比自适应软羽化（走 numpy 合成，LR 表达不了） |

- **采样策略**：有主体 → 径向 0.4 / 束状 0.3 / 线性 0.3，失败沿序退阶；无明确主体 → 只做线性二分（不用径向）。
- **工程约束**：**v2 随机几何 fallback 已彻底禁用**——SAM3 主体几何拿不到时直接抛 `NoSubjectGeomError`、记入 `failures.jsonl` 并跳过，保证低质量随机 mask 永远不会静默混进数据集。
- **落点**：`vera_directionA_1M/construct_local_v3/`（78 组 / **125 条 SFT** + 16 DPO + 11 failures，含 `groups.jsonl` 的 radial/band/linear v3 provenance、`cgt/` mask 渲染、成片 render）。这轮**没加 `--no-db`，已持久化进 PG**（`construct_sft / construct_candidates / construct_renders / runs` 等表）——PG 是这批样本的**权威落点**。

#### 第二层：v5 英文标注（instruction / reasoning，100 条，回写中）

- 位置（research_agent 侧）：`research_agent/data/runs/vst-annot-redesign/` 下 `v5-samples.json`、`v5-anns.json`（标注正文）、`annotate-v5-system-prompt.md`、`v5-id2muid.json`（V-id ↔ mask_unit_id 映射）、`v5-guard-fails.json`。
- 正在**按 `mask_unit_id` 匹配回写 `construct_sft`**，把构造时内联生成的旧中文标注替换成 v5 英文版——**此步进行中，尚未确认全部写完**。
- **databuild_viewer**（`~/VeraRetouch/databuild_viewer`）：若它读 PG 的 `construct_` 表，v3 底座现在就能看、v5 文本待回写完成后显示英文；若它读固定 jsonl 路径，则需确认其数据源是否指向 `construct_local_v3`。viewer 具体读哪个源**尚未实测，不打包票**。

### 2.2 搭建 Photographer-IAA benchmark，为排序模型选型

**做法**：从 **PARA / ArtiMuse / TAD66k** 的摄影子集中，筛选覆盖 **9 个常见摄影场景**的美学图片，搭建 Photographer-IAA benchmark。

- **9 场景**：人像 / 风光 / 动物宠物 / 美食 / 室内 / 建筑 / 静物 / 夜景 / 植物
- **规模**：9 类 × 8 模式 × 25 图 = **1800 张**（另有 ArtiMuse-10K 1002 张公开测试集做交叉验证）

**在两个 benchmark 上测了最新 IAA 模型**（PLCC/SRCC，越高越好）：

**Photographer-IAA（1800 张，GT=人评美学均分）**

| 模型 | PLCC | SRCC | KRCC |
|---|---|---|---|
| **ArtiMuse** | **0.8555** | **0.8343** | **0.6494** |
| AesExpert-LLaVA-7B | 0.8004 | 0.6038 | 0.4714 |
| OneAlign | 0.8491 | 0.4199 | 0.2886 |
| HumanAesExpert-8B | 0.4152 | 0.5107 | 0.3588 |
| Charm-PARA-random* | 0.9782 | 0.9425 | 0.8048 |

\* Charm-PARA-random 是 PARA 域内设置（≈见过分布），**不是**公平的跨集泛化数，仅作参考。

**ArtiMuse-10K（1002 张公开测试集）**

| 模型 | PLCC | SRCC |
|---|---|---|
| ArtiMuse（复现，与论文 0.627/0.614 一致） | 0.6237 | 0.6150 |
| **ArtiMuse + Charm 混合（0.75/0.25）** | **0.6205** | **0.6146** |
| 旧 QA-AES 问卷基线 | 0.3250 | 0.3066 |
| OneAlign | 0.3038 | 0.3172 |
| Charm-AVA-frequency | 0.2896 | 0.2951 |

**结论 → pipeline 排序模型选 ArtiMuse + Charm**：
1. **ArtiMuse 是最强主干**（Photographer SRCC 0.834，全场领先且跨集稳健）。
2. 混合方案**大幅碾压旧的 QA-AES 问卷 pipeline**：SRCC 0.615 vs 0.307（+0.31），这才是本次真正要替换的对象。
3. Charm 提供互补的跨数据集信号；混合与 ArtiMuse 单模在 ArtiMuse-10K 上基本持平（差 ~0.001，非退化）。

### 2.3 VLM 表征工程调研与实验（Lens / SAE）

**出发点**：VeraRetouch 本质是**用 VLM 的表征去做修图**。一个关键探索方向是——**选什么表征**（残差流 / attention / 激活值）才最优？

> **核心问题**：VeraRetouch 现在从 VLM"读取修图知识"的方式——取 3 个 special token 的**末层 hidden state**——是不是最优的？VLM 内部还有哪些没被利用的信号（中层表示 / 注意力空间分布 / 可分解概念方向）？
> （详见 `lens_exp_results_r2/REPORT.md`）

**方法**：主流表征工程分两条路线——**Lens**（读出/换层）与 **SAE**（稀疏概念字典）。在一个 Qwen2-0.5B 级 VLM（hidden 896，24 层 14 头）、ArtEdit-Bench/Lr 全量上做了两轮实验。挑几个最重要的：

> 组织与配图见 `lens_exp_results_r2/REPORT_TUTORIAL.md`（每个实验统一模板：参考论文 → insight → 实验设计 → 结论）。详细分镜见 `docs/PPT_SLIDES_2026-07-08.md`。

#### （A）Lens / 读出层（E1→E6）—— 末层读出次优，换层有真实因果增益

- 借鉴：Logit/Latent Lens、*Devils in Middle Layers*、Tuned Lens。**Insight**：感知类信息在**中层最丰富**，越到末层越被语言化稀释。
- **E1 逐层探针**：`<LIGHT>` 第 11 层 R²=0.100 vs 末层 0.029（差 3 倍多），光影信息在中层。
- **E6 换层重训（因果定档）**：ΔE00 从 baseline 12.12 → **9.64（L11/14/23 重训）全场最优**；比"末层重训"对照还好 **+0.82（p=3.7e-5）**，增益**随数据放大**（200→640 图：0.58→0.82，过拟合消解）。
- **多层融合 / 仿射校准都更差**（−0.61 / −0.28）——正解是"**选对层再重训**"，花样都被对照排除。
- **结论**：取末层不是最优；一行读出层索引 + 重训 = 相对 ~8% 的最高性价比收益。

#### （B）Attention 空间分布（E3→E7→E8）—— 弥散但可用，可当空间输出

- 借鉴：GUI-AIMA、V-SEAM（正/负注意力头）、attend-and-segment（attention-as-output）。**Insight**：注意力权重携带空间定位，且可当模型的空间输出。
- **E3**：retouch token 注意力弱对齐指令 `<box>`（median IoU 0.43 ≈ 1.8× 随机）——部分看向指令区域但不精确。
- **E7**：拆到 24×14 头后**没有被平均稀释的"神头"**（单头 0.26 ≈ 头均 0.28），V-SEAM 式 rescale 干预**无效**（阴性）——定位信息弥散。
- **E8（阳性）**：把注意力热图当 soft mask 做局部化渲染，ΔE00 11.05 显著优于全局 12.15，**甚至优于人工 oracle-box 11.57**——注意力落点真实可用。
- **结论**：注意力有真实但弥散的空间信息，是局部修图的"免费种子"；但要变产品收益，需先让参数预测够好（如接 E6a 读出）。

#### （C）SAE 稀疏字典（E9 pilot）—— 重构极好，但修图概念高度分散

- 借鉴：*SAE Learn Monosemantic Features in VLMs*、PatchSAE、CaFE（相关 ≠ 因果，必须干预验证）。**Insight**：稠密激活里叠加多概念，SAE 拆成稀疏方向可单独"拧"。
- TopK-SAE（L11，896→7168，55 万 token）**重构 val R²=0.976、死特征仅 0.2%**——SAE 本身没训坏。
- 但**修图概念高度分散**：633 样本上仅 **1 个特征**过 |ρ|>0.3 门——**单特征↔单概念假设在该 0.5B 模型上不成立**（n=60 曾出 86 个"候选"，扩到 633 全部消失，印证小样本相关全是噪声）。
- steering 沿 SAE 方向**因果方向成立**（一致率 94%）但**幅度极小**——是"可检出的方向"而非"可用的控制旋钮"。
- **结论**：pilot 证据支持"表征可干预"，不支持"已有概念字典"；下一步价值在更大 SAE / 更多数据。

**一句话小结**：末层读出非最优（换中层重训 +0.82 有真实像素增益）；注意力是弥散但可用的空间种子（优于人工 box）；SAE 在 0.5B 上无单义修图概念但方向性因果可检出。

## 第三部分 · 遇到的问题

### 3.1 IAA 模型分数有偏置：系统性偏好反色 / 黑白样本

改用 IAA 模型（ArtiMuse 系）后，发现打分对**黑白 / 反色样本有系统性正偏置**，已污染 SFT winner 选样：

| 指标 | 数值 |
|---|---|
| SFT winner 里**黑白占比** | **33.9%（13,077 / 38,606）** —— 单一风格占了三分之一 |
| 黑白 vs 彩色**选样分** | q 0.649 vs 0.615、merit 0.649 vs 0.616（黑白系统性高 **~0.034**） |
| 按 preset 类型 | **lut 类 50% 是黑白**（5,597/11,223）、param 25%、local_param 仅 6% |

**考虑的三种解决方法**：

| 方案 | 做法 | 定位 |
|---|---|---|
| **A. 选样分加"色度惩罚"** ⭐推荐 | 在 render-QA/tiering 处算 after 图平均色度（LAB 的 ab 模长 / HSV 饱和度，纯 CPU 不用 GPU）；越接近灰度惩罚越大（除非源图本就黑白或指令明确要黑白）。改动在 `tier.py` 打分处，很小 | **最对症** |
| B. 给 ArtiMuse 去黑白偏置 | 标定 ArtiMuse 黑白 offset（同图彩色 vs 黑白各打一次拟合差值），低色度时从 iaa_mixed 里减掉 | **根治**（需跑一轮标定） |
| C. 黑白配额硬上限 | 最终 SFT 黑白占比封顶（≤8-10%），超了只留 q 最高、其余用最佳彩色候选回填 | **兜底最稳**（不修评分器本身） |

### 3.2 SAE 结论偏弱，希望在更大规模数据上再试

- 现有 SAE pilot 规模有限：~10⁵·⁷ token、单层、单尺寸，结论是"0.5B 模型无单义修图概念、信号分散"（633 样本仅 1 个特征过门）。
- **诉求**：在更大规模数据 /（更大模型）/ 更宽字典上继续验证，看分散信号能否收敛成可用概念。
