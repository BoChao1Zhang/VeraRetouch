## 二、口径问题（本实验的核心审阅意见）

### 2.1 「记忆口径」：字典与查询是同一批 LUT，且评测点就是拟合点（未声明）

E1b 的做法是 `X_r = U_r U_rᵀ X`，其中 `U_r` 来自**包含被重建 LUT 在内的全部 3,522 个** LUT 的 Gram 分解，
ΔE00 又是在**这 3,522 个向量自己的 33³ 节点上**算的。这是**双重 in-sample**：

- 秩 r 相对样本数 3,522 并不小（r=384 = 10.9%，r=512 = 14.5%）；
- 极限上 r→3522 时重建误差**恒为 0**（矩阵秩上界），所以「高秩段收益加速」（比值 1.44→1.74）
  有相当一部分是**记忆化伪影**，不是真实的谱结构。

**我方补做的留出对照**（脚本 `scratchpad/rv_e1b_heldout.py`，与交付物同一 ΔE00 实现、同一 Gram 路径）：
把 3,522 随机对半分，`U_r` 只用「字典半」1,761 个 LUT 拟合，在从未参与字典的「查询半」1,761 个上评测。

| r | 查询半（**泛化**）p50/p90/p99 | 字典半（in-sample）p50/p90/p99 | 交付物全库（in-sample）p90 |
|---|---|---|---|
| 64 | 1.931 / 3.201 / 5.582 | 1.857 / 3.133 / 5.341 | 3.105 |
| 128 | 1.326 / 2.286 / 4.281 | 1.237 / 2.047 / 3.353 | 2.070 |
| 256 | 0.895 / 1.643 / 3.268 | 0.786 / 1.233 / 1.838 | 1.345 |
| **384** | 0.714 / **1.374** / 2.732 | 0.576 / 0.852 / 1.240 | **0.989** |
| 512 | 0.613 / 1.213 / 2.495 | 0.446 / 0.646 / 0.892 | 0.775 |
| 1024 | 0.423 / 0.940 / 2.075 | 0.161 / 0.261 / 0.381 | — |
| **1536** | 0.337 / **0.810** / **1.846** | 0.012 / 0.079 / 0.134 | — |

**达门最小秩**：
- in-sample（交付物口径）：p90<1&p99<2 → **r=384**；三门全过（含 p50<0.5）→ **r=512**
- **held-out（泛化口径）：p90<1&p99<2 → r=1536；三门全过 → r=1536**
- **held-out 且只看 E1 那 400 个 LUT：r=1536 仍不达门**（p99=2.324>2.0）

即：**交付物报的 384 低估了真实需求约 4 倍。** 这不是实施错误（任务卡字面就是"展平做截断 SVD"），
但 REPORT 把它当成「condition 宽度需求」上报，而 condition 是要给**没见过的** LUT 用的 —— 必须用泛化口径。

### 2.2 群体口径与 E1 不一致（跨实验推论的直接影响）

E1b 用**全部 3,522 个生产 preset**；E1 用**分层抽的 400 个**（e18 176 / quandian 224）。
我方核实：**E1 的 400 个全部落在 E1b 的 3,522 内**，可以精确对齐。对齐后（in-sample 口径）：

| r | 全库 3522 p50/p90/p99 | **E1 的 400 子集** p50/p90/p99 |
|---|---|---|
| 256 | 0.784/1.345/2.206 | 0.804/1.420/2.334 |
| **384** | 0.597/0.989/1.543 | 0.595/**1.078**/1.662 |
| 512 | 0.490/0.775/1.187 | 0.491/0.816/1.264 |

**在 E1 实际拟合的那 400 个 LUT 上，r=384 的 p90 是 1.078 → 不达门；最小达门秩是 512。**
E1 的 400 分层子集比全库更"硬"（分层抽样刻意覆盖了 77 个 minor，含小众极端 look 桶）。
任何「E1 的 N vs E1b 的 r」比较必须在同一群体上做，否则会系统性高估线性基底。

### 2.3 色域口径不对称（E1 是留出色，E1b 是拟合点）

E1：训练 128³ hald，评测 **256³−128³ = 14,680,064 个留出色**（插值型留出）。
E1b：评测 = 被 SVD 的那 33³ = 35,937 个节点本身（零留出）。
两侧都偏向线性基底。结论方向因此更稳（见跨实验汇总），但 REPORT 必须写明。

## 三、结论正确性复核

REPORT 的 4 条结论，我方逐条核：

1. 「预注册 32–64 不成立，512 以内无拐点、近幂律」→ **成立**（泛化口径下更加成立：1536 都还在幂律段）。
2. 「重建整库到 E1 门需 r≈384」→ **仅在记忆口径 + 全库群体下成立**。应改写为
   「记忆口径 r≈384（同群体对齐到 E1-400 则 512）；泛化口径 r≥1536」。
3. 「曲线光滑 ⇒ 没有天然截断点，选宽度是预算权衡」→ **成立且被泛化对照加强**。
4. 「尾部由极端风格化 preset 主导」→ **成立**，且与 E1 的尾部归因高度一致
   （E1 最差 5% 集中在 青橙/复古/胶片/暗调 桶，且 quandian 桶超代表 17/20；E1b failure_r48 也是近单色/双色调/硬色阶）。
   **两个实验独立指向同一个"难 LUT"子群，这是本批次最扎实的交叉印证，建议在 REPORT 中互引。**

「建议下一步」提的**判别 vs 重建**二分是对的，也是本实验最有价值的产出建议。补充：
判别探针要在**留出字典**上做，否则会重蹈 §2.1。
