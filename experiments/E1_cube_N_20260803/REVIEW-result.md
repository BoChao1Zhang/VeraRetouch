### 1.1 「判据被事后放宽 / 口径不一致」认定

**这是本实验唯一的实质问题，且是本批次三个实验里最需要计划层修订的一条。**

PLAN 第一级里有**两套并存且互相不一致的数字**：

- L190 定义 `N* = 最小满足 p90<1.0 且 p99<2.0`（两条件）
- L195 定义 `门槛：p50<0.5 / p90<1.0 / p99<2.0，不过停在这里改渲染器`（三条件）

**实现侧是忠实的**：`model/glut_repro/run_e1.py` 的 docstring（L13–15）**同时抄了两套**
（`N* = min N with p90<1.0 and p99<2.0` 与 `gate: p50<0.5 / p90<1.0 / p99<2.0`），
只计算了前者（L75–76），`criteria` 字段里写着 `"p50": 0.5` 但**没有任何一处把 p50 纳入判定**。
所以**这不是实施 subagent 主观放宽，而是 PLAN 自身两处判据打架**。

问题出在**汇报口径**：把只满足 L190 两条件的 N=32 说成"达门"。
0.572 不满足 p50<0.5 —— **N=32 没有达 L195 的门**。交付物（本应有的 REPORT.md）也没有指出这个矛盾。
必须在计划层裁决，并在 REPORT 里把两套判据的差异写明。

### 1.2 N=32 的 p90 达门不稳健（新增证据：bootstrap CI）

400 个 LUT 是分层抽样，跨 LUT 分位有抽样误差。我方对逐 LUT mean ΔE00 做 20,000 次 bootstrap：

| N | p50（95% CI）→ P(过 p50<0.5) | p90（95% CI）→ P(过 p90<1.0) | p99（95% CI）→ P(过 p99<2.0) |
|---|---|---|---|
| **32** | 0.572 [0.541, 0.617] → **0.000** | 0.980 [0.897, **1.062**] → **0.712** | 1.559 [1.330, 1.763] → 1.000 |
| **48** | 0.467 [0.446, 0.507] → **0.961** | 0.785 [0.735, 0.873] → 1.000 | 1.264 [1.082, 1.442] → 1.000 |
| 64 | 0.416 [0.390, 0.445] → 1.000 | 0.697 [0.651, 0.766] → 1.000 | 1.127 [0.924, 1.319] → 1.000 |

**N=32 的 p90 95% CI 跨过 1.0 门线（过门概率仅 0.71）**。即使只按 L190 的两条件版，
N\*=32 也是一个「换一批 400 个 LUT 就有 ~30% 概率翻车」的判定。N=48 三门都稳。

## 二、审阅问题 3 的回答：「r(N) 全程 >1.25 判未饱和」与「N=32 已达绝对门」矛盾吗？

**不矛盾（逻辑上两者度量不同的东西），但 N\*=32 不稳妥。**

1. **不矛盾的原因**：r(N) 是**相对收益率**（再翻倍 N 还能降多少），绝对门是**误差水平**。
   一条幂律衰减曲线可以永远「未饱和」（相对收益恒定）同时早早跨过任何绝对门。
   实测正是幂律形态：log₂ p90 对 log₂ N 的斜率近乎常数（r 稳定在 1.32–1.51），
   意味着**这个模型族在 N≤128 内没有容量拐点** —— 与 E1b 的秩–ΔE 曲线「无肘部」是同一现象的两种表现。
   PLAN 把 r(N) 写成「饱和判据」本身就是一个**会永远失败的判据**：只要曲线是幂律，
   r 就不会掉到 1.15。这条判据应改为「用于诊断曲线形状」，不再当 gate。

2. **N\*=32 不稳妥的三条独立理由**：
   - 未过 L195 的 p50<0.5（超门 14.5%，bootstrap 过门概率 0.000）；
   - p90 达门的 bootstrap CI 跨门（过门概率 0.71）；
   - 评测口径是 2^21 留出色子样 + 400 LUT 分层子集，**尚未在全量 3,522 上复验**。

3. **N=32 vs N=64 的成本–收益（我方算）**：
   参数 716 → 1420（+98%），ΔE00 逐 LUT 比值 dE(32)/dE(64) 中位数 **1.389**、p90 **1.514**，
   p99 1.559 → 1.127。**ΔE00>1.0 的 LUT 占比：N=32 9.2% → N=48 3.5% → N=64 1.5%。**

   **建议：N\* 取 48（1068 参数）。** 理由：
   - 是 PLAN L195 三门全过的最小 N（bootstrap 过门概率 0.96/1.00/1.00）；
   - 相对 N=32 只 +49% 参数（不是 N=64 的 +98%），却把 ΔE00>1.0 的尾部从 9.2% 砍到 3.5%；
   - 仍在 GLUT 文献锚点的可比区间内（GLUT Table 9 N=32→45.47 dB；我方 N=48 = 44.33 dB，
     口径不同——我方是**跨 4000 库逐 LUT 过拟合**、文献是 75-LUT 联合训练，不可直接比，见 §四 nit）。

   若坚持 32，**必须**在 REPORT 里写明「按 L190 两条件版取值、p50 未达 L195 门、p90 CI 跨门」，
   并把 N=48 作为主实验的备用配置排进 RD 臂消融。

## 三、失败案例归因（PLAN 步骤 7，交付物缺，我方补做）

最差 5%（N=32，n=20，阈值 ΔE00=1.141）的 minor 桶分布：

| minor 桶 | 命中/桶容量 | 桶内占比 |
|---|---|---|
| 青橙暗调_00 | 2/2 | 100% |
| 复古暖调_08 | 2/2 | 100% |
| 胶片复古_00 | 2/6 | 33% |
| 暖调复古_01 | 2/11 | 18% |
| 高亮暖调_10 / 暖调高亮_03 / 青橙暗调_02 | 各 1/1 | 100% |
| 青绿胶片_01 / 青橙复古_05 | 各 1/6 | 17% |

来源分布：quandian 17 / e18 3（总体 224/176）——**quandian 桶显著超代表**。

**关键发现（交付物没有的）：N=64 的最差 5% 是几乎同一批 LUT**（前 9 个桶完全重合）。
即把容量翻倍并**没有改变"谁难"，只是把所有 LUT 的 ΔE00 等比例压低 1.39×**：
N=32 最差 5% 的平均 ΔE00 1.391 → N=64 仅降到 0.997，其中 6/20 仍高于 N=32 的整体 p90。

**归因**：尾部由「青橙/复古/胶片/暗调」这一族**强色调分离 + 锐转折**的 look 主导，
与 PLAN L191 的预设假说（锐转折主导）一致，也与 E1b 的尾部归因（极端风格化 preset 离主子空间最远）互相印证。
**这正是 PLAN L191 要求做 A/B（N=32 vs N=32+1D 曲线 vs N=64）的场景，而 A/B 未做。**
本审阅的证据（加 N 只等比缩放、不改变难点身份）**支持"曲线赢"的预期**：如果瓶颈是各向同性的容量不足，
加 N 应该优先修好最难的；实测是等比例缩放，说明缺的是一个**沿色调轴的锐转折自由度**，而不是更多局部高斯。
