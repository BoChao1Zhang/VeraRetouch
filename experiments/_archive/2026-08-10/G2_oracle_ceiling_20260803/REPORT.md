## 要验证的结论

如果 G2 成功，我们就能说「**把 oracle s（真值掩膜）作为第四根轴加进逐像素色彩算子，在自家真实
局部编辑数据上确实存在可观的可解释增益**（Δ_ceil = PSNR_4D_ceil − PSNR_3D_ceil 中位 ≥ 1 dB），
因此『3D LUT 不够、需要 s 条件的 4D 算子』这个立项前提在数据上成立」；失败（< 0.4 dB）就不能说
这句话 —— 那意味着自家数据里的"局部编辑"其实 3D LUT 靠颜色就能寻址完，整条渲染器线要停工或换数据。

> **补批（D-34）追加的子结论**：上面这个数字**不是抽样偏差** —— 它在 l1–l6 全部 6 个真实档 build
> 与 g1–g4 全部 4 个对照档 build 上都成立（§6.2′）。

## 为什么需要验证它

它是论文「用 s 条件的 4D 色彩算子做局部精修」这条主张的**存在性前提**：审稿人只要问一句
"你怎么知道 3D LUT 不够"，没有这个数就只能答"我们觉得"。文献给的预期只有 +0.36～0.5 dB
（PLAN §4.2 C 层转述），若自家数据也只有这个量级，整个方法的收益空间就被压到噪声里。
这同时是 EXPERIMENTS_v3 分支树上 `G2 oracle <0.4 dB → 停/换数据` 那条边的判据来源。

## 怎么验的

零训练的**解析上界**测量：对每张图的像素集 {(x,y,s)}，按颜色分层建 3D 条件模型、再加 s 轴建 4D
条件模型，两者 PSNR 之差即 Δ_ceil（估计器 = 逐箱最小二乘仿射，D-24 权威口径）。三档并跑：
① D-CONSTRUCT(S-val) 8 级容量阶梯（有 GT 的刻度尺）② D-SFT-L(S-val,normal) 真实档

外加三道零点对照（Δ_const / Δ_donor / 对照档）与 GLUT 真拟合互证。

## 四 三道控制臂（有限样本膨胀的主控）

细分越多越会拟合噪声，Δ_ceil 天然有正偏。四道控制**全部跑在同一估计器、同一分区细度上**：

### 4.1 Δ_const（s ≡ 1）—— 实现自检，构造上恒为 0

| 档 | `delta_const`（嵌套） | `delta_arm_const`（臂式） |
|---|---|---|
| 构造 (192) | 逐位 **0.0** | 逐位 **0.0** |
| 对照 (600) | 逐位 **0.0** | 逐位 **0.0** |

**这道臂证明分区/细化代码本身不会白捡差额。**

### 4.2 全局对照档 D-SFT-G + 移植掩膜（③）—— 编辑是真·全局，任何非零 Δ 全是膨胀

## 五 实验法互证：GLUT 三臂（真拟合，不是解析上界）

解析法给的是「任何 3D/4D 查表能达到的上限」；互证臂问的是**一个真实的、参数量极小的可微模型**
能不能把这个上限兑现出来。

- 引擎 `model/glut_repro/BatchedGLUT`（GLUT 复现臂），32 高斯 / **716 参数每张 LUT**，
  1200 步、bs 8192、lr 5e-3、每图采样 131,072 像素；数据 = 与 ② 同源的 D-SFT-L(S-val,normal) **n=100**。
- 三臂：`1lut`（单张 3D LUT）/ `mask3`（按 **C_GT 三分位桶**分 3 张 LUT）/ `luma3`（按 **Rec.709 亮度三分位桶**分 3 张 LUT，**「随便一根轴」对照**）。

| 臂 | PSNR 中位 | 相对 1lut 的增益（中位） |
|---|---|---|
| identity（不修） | 26.21 dB | — |
| **1lut**（3D 基线） | 31.20 dB | — |
| **mask3**（语义轴） | **37.00 dB** | **Δ_mask3 = 5.370 dB** |
| **luma3**（亮度轴对照） | 31.37 dB | Δ_luma3 = **0.138 dB** |
| 净额 | | **Δ_net = 5.105 dB** |

三条读数：
1. **方向一致**：真拟合在同一批数据上拿到 5.37 dB，与解析天花板 7.97 dB 同号同量级 —— 解析法不是空中楼阁。
2. **兑现率约 2/3**：3 个桶 × 716 参就吃掉了天花板的 ~67%；剩下的靠更细的 s 分辨率与更大容量。
3. **「随便一根轴」被排除**：把 s 换成亮度分位桶（同样是 3 桶、同样多参数），增益只有 **0.138 dB**。
   这是对「4D 的收益只是变相加容量」这一质疑的直接反驳，与 §4.3 的 L5 错配臂互相印证。

### 7.1 信息性负结果：**L6 —— 单标量 s 的秩上限**

L6 用**两张重叠的软掩膜、顺序施加两个不同变换**，而交付给估计器的 `s = max(mask_a, mask_b)`
（`_mask.png` 便携版；D-12 记录 harness 侧应走 npz 双通道）。这一级的读数与其他局部级质变不同：

| 现象 | L6 | 对照（L1/L2） |
|---|---|---|
| Δ_arm | **3.66 dB**（局部级最低） | 19.89 / 23.46 dB |
| **臂式相对嵌套式的增幅** | 3.35 → 3.66，仅 **+0.31 dB** | 5.58 → 19.89（+14.3）/ 6.74 → 23.46（+16.7） |
| 4D 臂后的绝对 PSNR | **39.78 dB**（局部级最低，比 L1 低 30.7 dB） | 70.48 / 70.86 dB |
| Δ_arm_cv | 1.89（局部级最高） | 0.21 / 0.60 |

**解读**：`max(a,b)` 把「哪个区域」这一位信息压掉了 —— 重叠区、仅 a 区、仅 b 区三种像素可以映到相同的 s 值，
而它们需要**不同**的色彩变换。给再多 s 桶、再细的颜色分层都补不回来：这不是估计器的问题（同一估计器在
L1/L2 上给出 70 dB），而是**单标量第四轴的表达秩上限**。臂式几乎不比嵌套式好（+0.31 dB）正是这个上限的
指纹 —— 增加「每桶一张独立 LUT」的自由度并不能解决 s 本身不可分的问题。CV 列反而最高（1.89 dB）说明
剩下那 3.66 dB 是真实、稳健的（重叠软掩膜确实携带一些强度信息），只是量级被秩卡死。

**这是本实验唯一的负结果，且是信息性的**：它给出了一条明确的架构边界 ——
若目标场景包含「重叠区域各自不同变换」，单通道 s 天花板就在 ~40 dB，
必须走多通道 s / 双轴（EXPERIMENTS_v3 的 **RD-F 双轴 5D** 臂）才能突破。
**它不构成对 G2 主结论的反证**：真实档 D-SFT-L 的编辑形态是单区域单变换（`render_mode=local` 600/600），
落在单标量 s 的可表达范围内。

## 九 方法学（两处修正，均已进 `docs/DECISIONS_2026-08-03.md`）

### D-24 · Δ_ceil 估计器口径变更：采纳**逐箱最小二乘仿射**为权威口径

**问题**：PLAN §4.1 字面的「逐箱条件均值」在 33³ 等宽分箱下有一个**硬性量化地板**。
箱宽 = 1/33 ≈ 7.7 个 8-bit 级 → 箱内色差自身贡献 MSE ≈ 7.7²/12 ≈ 4.9 → PSNR 封顶 ≈ 41 dB。
实测 L0（纯全局编辑档）在字面口径下 `PSNR_3D = 41.41 dB`，**与理论地板吻合到 0.01 dB**。

而 D-CONSTRUCT 的恒等映射（什么都不做）本身就有 37–41 dB（L3 41.23 / L4 41.61 / L5 40.75）。
于是常数估计器的 `PSNR_3D` 反而**低于恒等映射**（L3 39.92 < 41.23，L4 39.06 < 41.61），
Δ_ceil 被压到 0.06–1.88 dB。**用一把最小刻度 41 dB 的尺子去量 8 dB 的差，判据 ① 在任何数据上都不可达。**

**对策**：单元内改用最小二乘仿射 `ŷ = A x + b`（12 自由度）。**局部线性正是三线性插值 3D LUT
在单个格子里的真实行为**，因此它不是「更强的模型」，而是**更贴近真实 3D LUT 能力**的天花板。
地板从 41.41 dB 抬到 L0 实测 **63.43 dB**。

**⚠ 裁定理由不是「为了达标」。** 换估计器抬的是**基线（3D 侧）**，如果它同时虚抬 4D 侧，三道零点对照
必然报警。实测在**新口径下**：

| 零点对照 | 新口径实测 | 应然值 |
|---|---|---|
| 全局对照档 D-SFT-G（真·全局编辑 + 移植掩膜） | **0.040 dB** | 0 |
| L5 掩膜故意错配（分区自由度同 L1/L2 的 19.9 / 23.5 dB） | **0.159 dB** | 0 |
| Δ_const（s ≡ 1） | **严格 0**（构造/对照逐位 0；真实档 ≤1.7e-6 float 噪声） | 0 |

**估计器错的是它低估了 3D LUT 的能力，不是阈值定高了。** 字面条件均值口径的全套数字并列保留进
**附录 A**。PLAN §4.1 Step 2 已按此改写。

### D-25 · 数据坑：`.in.jpg` **不是** I_in（影响所有后续实验）

shard 成员布局实测：`.in.jpg`（VLM 预览图，尺寸任意，抽样见到 1000×667 / 683×1024 / 2048×3640 / 540×360）
/ `.jpg`（归档 after = I_tar）/ `.cgt.png`（C_GT 掩膜）—— 后两者**恒为短边 1024 的渲染分辨率**。
`.in.jpg` 与它们**逐像素不可比**；强行 crop/resize 对齐后实测 `|I_in − I_tar|` 均值达 **75/255**（纯错位）。

**正确取法（本实验采用）**：从 **img 银行**按生产渲染管线重建 ——
`ImageOps.exif_transpose → RGB → LANCZOS 缩到短边 1024`（复刻
`tools/bgr_check/common.py:preprocess_source_bytes`，银行解析复用 `BankResolver`：
full_path 优先、unsplash 必须命中 `unsplash_work`；journal 里的本机路径已失效）。
重建后三方尺寸 **100% 一致**。已写入 `DATA_ASSIGNMENT §1.2` 硬规则。

> 若不做这项修正，本实验的 I_in 会是错位图，`PSNR_3D` 与 `PSNR_4D` 双双塌到噪声水平，
> Gate D2 会被**假阴性**判死。这是一个足以改变项目走向的坑。

### 其余方法学决策（NOTES §四登记，本报告采信）

- **对照档 s 用「移植掩膜」而非 s≡1**：D-SFT-G 没有 C_GT，若取 s≡1 则 Δ_ceil 构造上恒为 0，测不出虚高。
  改从 l 系 S-val 取 64 张 C_GT 组池（面积 2%–98% 过滤）轮转贴图（最近邻，不引入新灰度）。
- **混淆过滤器只报不筛**（§6.5 已给敏感度）。
- **像素取原生分辨率全像素、不做插值 resize**（`avg(f(x)) ≠ f(avg(x))` 会同时污染 3D 与 4D 天花板）。
- **配准检查跳过**：I_in 由源图经与生产**同一条** LANCZOS 管线重建，几何上逐像素同源，无配准自由度。

## 十 结论与对计划的影响

### 结论

1. **Gate D2 通过，且余量极大。** 自家真实局部编辑数据（D-SFT-L, S-val, normal）上，
   oracle s 带来的天花板增益中位 **7.97 dB**，交叉拟合下界 **5.51 dB**，97.8% 的图 ≥ 1 dB。
   死刑线（<0.4 dB → 停项目 / 换数据）**不触发**，且离触发线差 20 倍。
   **补批（D-34）证实这不是抽样偏差**：按 build 分层重抽 600 组后中位 **8.04 dB**，
   **6/6 个 l build 全部落在 7.68–8.82 dB**（极差 1.14 dB，每 build 的 q10 都 ≥2.71 dB），
   4/4 个 g build 全部 ≤0.053 dB；原批次的结论一条也没被推翻（§6.2′）。
2. **这个增益不是方法虚高。** 三道独立零点对照全部归零：全局对照档 0.040 dB、
   掩膜错配 L5 0.159 dB、Δ_const 严格 0；扣掉 Δ_donor 后净增益仍有 6.60 dB。
3. **解析上限与真拟合互相印证。** 716 参数 / 3 桶的 GLUT 臂在同批数据上真拿到 5.37 dB（天花板的 ~67%），
   而换成亮度轴的同容量对照只有 0.14 dB —— **不是「随便一根轴都行」。**
4. **容量侧没有瓶颈。** MLP 探针 6/6 全过（最小 67.66 dB ≥ 45 dB），无 s 对照臂中位低 17.8 dB。
5. **单标量 s 有明确的秩上限**（L6：3.66 dB，绝对 PSNR 卡在 39.78 dB），
   适用边界是「单区域单变换」；真实档 600/600 落在此边界内。
6. **PLAN §4.1 的字面估计器不可用**（D-24），`.in.jpg` 不是 I_in（D-25）——两条都已回写权威文档。

> Mann–Whitney p=0.68 相互印证。
>
> 成功侧则**多出一条原批次 6 张里没有的机制**：`success_1` 的「近单色画面 + 大软掩膜」。
> 前三张成功案例（原批次）都是「前景强改色、掩膜小」，容易让人误读成
> 「Δ_ceil 高 = 小掩膜强改色」；这张 s̄=0.705 的低调人像给出反例 ——
> **决定 Δ_ceil 的是「掩膜内外的输入颜色分布是否可分」，不是掩膜大小、也不是编辑幅度**。
> 建议后续 E14/E20 的分层里直接加一列「掩膜内外颜色分布的重叠度」，
> 它比掩膜面积（Spearman 仅 0.093）更可能是真正的隐变量。
