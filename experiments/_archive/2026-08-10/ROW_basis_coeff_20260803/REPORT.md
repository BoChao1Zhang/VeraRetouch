## 要验证的结论

如果这个实验成功，我们就能说 **VLM 可以直接吐出 14 个基系数、由固定基底合成出足以支撑局部编辑的空间场，而且这组系数随指令变化**；失败就不能说「不问 VLM 要图、只问它要系数」这条路成立，where 线必须回退到逐像素读出或外部掩膜。

## 为什么需要验证它

它支撑论文里唯一把本方法与「SAM 分区 + 分区 LUT」区分开的那条主张——**s 是一根跨图共享刻度的坐标轴，不是逐图掩膜**；这条主张的技术前提就是「空间场由固定基底 φ 合成、系数 w 低维且跨图可比」。不做的话，审稿人会说：G1 已经判定 VLM 读出的场与指令无关（Gate D1 FAIL），你们的 where 线没有证据，4D LUT 的 s 轴不过是把别人的掩膜换了个名字。

## 怎么验的

在 D-CONSTRUCT（S-train 1600 样本训练 / S-val 192 样本评测，L0–L7 八级）上，先在同一套 14 维基底上逐掩膜离线拟合出 w\*（离线上界），再训练两种读出头（mean-pool MLP / cross-attention query）从 VeraRetouch **冻结**的隐状态回归这 14 个数，三档监督（回归 w\* / 端到端 BCE / 混合）各跑一遍；每个臂同时跑**跨级**与**同级**两种跨图指令打乱的对照批；指标在 S-val 上按 G1 口径（归一化 Mann-Whitney U + 亮度基线）报。

## 一、设置

**基底（PLAN_v2 §1.3 单轴 v1，14 维）**

```
q(p) = w0 + alpha * (w_dir . phi_dir(p)),  ||w_dir|| = 1,  alpha >= 0
s(p) = 3 * tanh(q/3)                        <- psi 固定不训
phi  = [1] + [x, y, P2(x), P2(y), xy] + [L, S] + [e1..e6]
m(p) = sigmoid(g0 * s(p)),  g0 = 6        <- 全局固定，逐图无自由参数
```

- 几何块 = Legendre，中心化 / 除**短边**；range = Rec.709 luma 与 HSV saturation，逐图标准化；语义块 = CLIP-L/14-336 dense（MaskCLIP v-proj，输入 672²，48×48 网格）对 6 个固定文本锚点的余弦，guided filter(r=32, eps=1e-3) 后逐图标准化并对「几何+range」块残差正交化。**与 E2 `e2lib.py` 同一套实现**（逐字复制 `process_image`，避免与在跑的 E2 补件轮耦合）。

## 二、数据（split 代号）

- **D-CONSTRUCT**：`experiments/tooling-wave1/T4_construct/sanity/`，train 套 = **S-train**（8 级 × 200 = 1600），val 套 = **S-val**（8 级 × 24 = 192）；manifest 每行带 `split_rule: t1_side_table:splits.sqlite3(rows=33652)`，**无任何 ad-hoc 切分**。

## 十、实现层面必须写进报告的三件事

1. **任务卡说的「E2 拟合产物 w\*」在本臂训练集上覆盖率 = 0%**。E2 的掩膜是它自己 `prep_data.py` 现造的（4 个几何合成族 + 常数 + 从 D-MASKBANK 抽的 200 个语义掩膜），与 T4_construct 的 L0–L7 没有一个 uid 重合。处置：用同一套基底代码在 T4_construct 上**重新离线拟合**（NOTES D2）。**因此 E2 的 0.975 不是本臂的上界**——那是 E2 在自己的解析几何掩膜上的数字；E2 自己在真实语义掩膜上是 0.848。本臂的上界是上表的离线列。
2. **拟合器对拍**（`config/fitter_validation_val.json`，n=10）：批量 GPU 拟合器相对 CPU L-BFGS 参照的中位差 = **-0.0078**（最差 -0.1061）。离线上界因此是**被低估**的，对本臂的主张是保守方向；同时 (a) 档的回归标签带这个量级的噪声。
3. **指令是从真值反推的模板**（见第二节）：几何级上的成功只证明「读指令→出几何系数」，不证明视觉 grounding；语义级上的成功才需要把词落到图上。
4. **无名词那一格在本数据上只能读作「模型有多依赖区域词」**：D-CONSTRUCT 的掩膜（L4/L6/L7 是随机几何、L1–L3 是任取的语义候选）与图像内容无关，**无名词指令在原理上无法确定区域**。要回答「无名词指令下 w 还能不能对」，需要 D-SFT-G 风格指令 + 真实区域 GT，属下一步。
5. **读出口径在实验中途按 RO-3 判决改过**：任务卡原设计（取 `<retouch_light>` 隐状态）被 RO-3 证伪（该 token 池在全部 336 个 (层,头) 上 AUC_target ≤ 0.5542，低于置换零分布 q95=0.596），主档改为 **instruction 文本 token**，原设计**全部保留为负对照行**（表里 tap=retouch 的行）。
