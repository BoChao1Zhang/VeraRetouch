## 要验证的结论

如果 G1 成功，我们就能说「冻结 VLM 里 `<retouch_light>` special token 打向 image token 的
pre-softmax 注意力场 s 是一张**跟着指令走的空间寻址图**，可以零训练直接当局部精修的 where 通路」；
失败就不能说这句——也就不能把这类 attention 场当成指令条件的掩膜（mask）来用。

## 为什么需要验证它

论文「VLM 负责 where、参数通路负责 how much」这条主张的最省事实现就是 RO-9（直接读 SFT
special token 的注意力当 s）；不先把它证否，审稿人会直接问「那你为什么不直接拿注意力当 mask？」
——而如果它其实只是一张与指令无关的图像显著场，任何搭在它上面的 where 叙事都是假的。

## 怎么验的

在 S-val 300 源上做 **1388 次 eager pre-softmax attention 读出**，比较同一张图在四种指令扰动下
s 场的相关性——同义改写 / 方向词取反 / **点名不同区域** / **换成别的图的指令**——
并用 SAM3 主体掩膜的 ROC-AUC 直接量化「s 到底落在哪」（含 luma16 基线）。

### 措辞纪律（D-31）——两个 PASS 各自到底说明了什么

- **ρ_Y = 0.177（PASS）**：**低相关只排除「s 是亮度的线性或单调翻版」这一种失败模式，
  不构成「s 有用」的正面证据（纯噪声同样通过这一条）。** 此前档案里
  「最致命的死刑线已排除 ✅」的表述属于过度解读，已按 D-31 更正。
- **ρ_syn = 0.867（PASS）**：同样只说明「读出是可重复的、不是随机数」。在 ρ_shuf = 0.895 ≥ ρ_syn
  的背景下，这个高稳定性恰恰是**坏消息**：s 稳定，是因为它压根不看指令。
- 今后凡写「某判据 PASS」，**必须区分「未触发死刑」与「获得正面证据」**（D-31 通用条款）。

### 判定的实质：不是「s 只编码 where 不编码 how much」，而是 **s 不依赖指令**

三条对照连起来读，可用的解释只剩一个：

1. **方向对立不分离**（ρ_opp 0.870 ≈ ρ_syn 0.867）——曾被解读为「s 是 where 场，对方向词不敏感」；
2. **区域对立也不分离**（ρ_region_opp 0.884 **≥** ρ_syn 0.867）——同一张图、同一方向词、
   **明确点名两个不同区域**，s 场几乎不动。上面那个「where 场」解释就此被排除；
3. **跨图错位指令同样不分离**（ρ_shuf 0.895 > 配对 ρ_syn 0.842）——把**别的图的指令**扣到这张图上，
   s 场比换个同义说法还要稳；配对逐源看，同义对 ρ 高于错位对的比例只有 **40%（24/60）**。

⇒ **s 是纯图像驱动的场，指令条件性 ≈ 0。** 这正是 NOTES §六**分析前预注册**的「更糟的解释」，
对应 EXPERIMENTS_v3 RO-9 行的失败判据——不是事后编出来的解释。

## 八、结论与建议下一步

### 结论

1. **Gate D1 = FAIL**（主判据 ρ_region_opp 中位 0.884，判据 <0.3，**0/214 达标**）。
2. **失败模式已定性到底**：不是「s 只有 where 没有 how much」，而是 **s 根本不随指令变化**——
   跨图错位指令的 ρ（0.895）甚至高于同义指令的 ρ（配对 0.842），胜出率仅 40%；
   AUC 口径下「说主体」与「说背景」的配对差只有 +0.0005（p=0.121）。
   RO-9 的「零训练直接把 VLM 注意力当 s 用」路线，**在原发布 checkpoint 上不成立**。
3. **四种补救全部已在本报告内被排除**：换层（24 层逐层）、换区间（10 个区间）、
   换 token（三 token 两两 ρ 0.81–0.94 同源）、换度量与掩膜源（AUC / C_GT）。
4. **唯一可回收的正向结论**：s 是一个**弱但真实的、图像驱动的主体显著性场**——
   对 SAM3 主体掩膜 AUC = 0.664（local 段 0.690，L20–22 区间 0.825），显著高于亮度基线 0.475。
   它可以当**先验 / 初始化 / 伪标签种子**，但**不能**当「指令条件的 s」。
5. **⚑U5 定案有数据支撑**：`<retouch_light>` 在主体 AUC 上是三 token 里最高的（深层领先最明显）。
6. **被证伪的范围要说清（D-30）**：本实验证伪的是**「GL token 注意力这个读法能拿到 where」**，
   **不是**「VLM 内部有 where 信息」（H2 未被证伪）——后者由 RO-1 / RO-3 / RO-2 / RO-5 回答。

### 本实验自身的局限（供结果审阅 agent 核）

- 区域对立对是**模板构造**的（主批 214 源中无任何一图带 ≥2 个不同 subject，见 NOTES D8），
  reg_b 用「背景」（165 源）或空间对侧（49 源）。两类的 ρ 分别为 0.887 / 0.871，**都远离判据**，
  所以模板构造不是失败原因；但「若有真实的一图多主体对，结论是否一样」严格说未验证。
- fallback 样本（6.3%，全在 style 段）的 s 来自末尾追加的 GL token，与自然生成位置的语义可能不同；
  但 local 段 fallback = 0，而 gate 的主判据（区域对立）全部落在 local 段，**结论不受 fallback 影响**。
- 判据用 canonical L8–15；已用 `layer_scan`（逐层）与 `band_scan`（10 个区间）穷举，**无更优选择存在**。
- shuffle 对照 n=60（非 300），配对 Δ = −0.015、win rate 0.40 的 binomial p=0.155：
  严格说是**「没有证据表明同义优于错位」**，而非「已证明错位优于同义」。方向与主判据一致，
  但若要在论文里写强断言，建议把该批扩到 ≥200 源。同理 AUC 配对 p=0.121 也是「无差异」而非「B 优于 A」——
  **主判据 ρ_region_opp（0/214 达标、中位 0.884 vs 判据 0.3）才是 gate FAIL 的承重判据，两个对照是佐证。**
- 本实验只测「s 是否随指令变」，**没测**「s 用作渲染条件时的下游收益」——B2 的先验价值需 RO-5/RO-8 实测。
