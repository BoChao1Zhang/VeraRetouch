## 要验证的结论

如果这个实验成功，我们就能说「VLM 内部**同时**存在 what（颜色）与 where（空间）信息，且两者
分处不同层、各自被不同机制破坏，所以**分头读、各用各的通路**是表征结构逼出来的必然设计」；
失败就不能说这句——只能说分头读是工程口味，没有表征依据。

## 为什么需要验证它

这是论文从「又一个 pipeline」升级成「一个表征发现 + 由它导出的方法」的唯一支点；不做，审稿人
会直接问「你凭什么把 where 和 what 拆成两条通路？塞进同一个读出头不行吗？」——而且
G1/RO-9 已经判死了「直接读 attention 当 s」，没有这张判决图就说不清**信息到底在不在里面**。

## 怎么验的

在 **S-val 400 源 / 4160 次冻结前向**上做逐层线性探针：颜色侧 6 个属性（配对 delta，A1–A6）
× **159 个位点**（视觉塔 13 + connector + LLM 24 层 × 6 位点家族 + 线上 3-latent 读出口），
空间侧用 **G1 区域对立批的同一批 214 源、同一份 SAM3 掩膜、同一对指令**做 token 级探针，
配 C1–C5 全套对照（随机骨干 / token 置换 / 灰度输入 / 像素统计基线）、行为五档，
以及在**整段 image token** 上的擦除与 steering 干预。

## 二、PR-3：H3 判决图与 where 线

### 2.1 预注册判据

| 预注册 | 实测 | 判定 |
|---|---|---|
| 两峰层距 **≤ 6 层**（1/4 深度）⇒ what/where **纠缠**；> 6 ⇒ **可分离** | 颜色峰 **L5**、空间峰 **L13**，**层距 = 8** | **SEPARABLE**（PLAN §0 口径：**H3 被证伪**，不存在统一读出层） |

### 2.2 但这条判据在本数据上**不具判别力**（必须写在结论前面）

- 颜色曲线全层极差 **≤ 0.08 R²**（A1 0.86→0.90，A3 0.91→0.93）；空间曲线全层极差 **0.025 AUC**（0.928→0.953）。
- 峰值层 bootstrap 95% CI：颜色 A1 **[2,15]** / A3 **[3,16]** / A4 **[1,23]**；空间 **[11,14]**。
- ⇒ **两条曲线都近乎平坦，argmax 是噪声。** 正确读法不是「峰距 8 层所以可分离」，而是：
  **what 与 where 在每一层都同时在场，包括 connector 输出的第 0 层。**
  这两句在 `viz/H3_verdict.png` 上以 CI 条形式画出，图注也这么写。

### 2.3 空间探针本体（S1：图像驱动的 where）

| 量 | 值 |
|---|---|
| token 级 ROC-AUC（SAM3 主体掩膜，212 源，逐源 CI） | **0.953**（峰 L13；逐源均值 CI **0.940–0.960**） |
| C1a **H&L control task**（格位固定随机标签，样本级折） | 0.566 → **selectivity = 0.387** |
| C1b 逐图打乱标签 | 0.611 / 0.651 |
| **C5 像素基线**（逐 token RGB+Lab+luma） | **0.660** |
| **C2a 随机 LLM**（视觉塔保留） | **0.872** |
| **C2b 全随机骨干** | **0.704** |
| **C3 整段 image token 置换** | **0.678** |

读法：where 信息**强、可线性解码、明显超过像素基线与全随机骨干**；但 C2a 0.872 说明
**大部分 where 也来自视觉塔**，LLM 只加 0.08 AUC。C3 掉到 0.678 说明 0.68 里有很大一块是
**位置先验**（主体居中），真正的内容性 where 增量 ≈ 0.95 − 0.68 = **0.27 AUC**。

### 2.4 ★ 结构事实：image token 在因果序里**先于**指令 —— 这解释了 G1/RO-9

prompt 实测：`<image>` 在第 75 字符，`Instruction:` 在第 239 字符（`config/env.json`）。
decoder-only 因果注意力下，**image token 的 hidden state 在结构上不可能依赖指令**。实测确认：

| 量 | 值 |
|---|---|
| reg_a vs reg_b 下 image token 的相对 L2 差（中位，L12） | **0.0033**（L0 = 0.0000；差异量级 = bf16 kernel 舍入） |
| 「哪条指令」从 image-token 均值解码（L12，分组 CV） | **AUC = 0.503**（随机） |
| 线性探针读**指令点名区域**（S2，逐层） | **0.500，24 层全部，精确到小数点后三位** |

⇒ **S2 = 0.500 不是实验发现，是架构的数学后果。** 任何「从 image token 读指令条件空间场」的
读法在这个 prompt 布局下都注定失败——**RO-9 的失败不需要用表征来解释，用因果序就能解释。**

### 2.5 ★ 但「指令条件的 where」是**读得出来**的 —— 只要换读出形式

唯一在结构上**可能**随指令变的最小读出 = image token 与「见过指令的 token」的交互项。
实现：`score(t) = w · [h_img(t) ⊕ h_img(t) ⊙ h_GL]`，`h_GL` = `<retouch_light>` 第 L 层 hidden state。

| 读出方式（**同 214 源 / 同掩膜 / 同 reg_a·reg_b 指令**） | AUC_target 逐层 |
|---|---|
| 线性探针读 image token | **0.500**（全层） |
| **双线性读出（image token ⊙ GL token）** | **0.815 – 0.917**（峰 L13 = 0.917） |
| 同上但**把指令向量跨源打乱**（对照） | **0.481 – 0.539** |
| **RO-9 线上 GL-token attention 读出**（G1 已落盘） | **0.479 – 0.526**（24 层全部） |

⇒ **信息在，交互也在，坏在读出形式上。** 这是本实验对负责人主张最直接的支持——
只是支持的对象是 **where 线，不是 what 线**。
（图：`viz/g1_crossref.png`，四条曲线同图、同源、同指令，唯一变量是读出方式。）

**一条必须写明的局限**：本批每源只有两条指令（点名主体 / 点名补集），所以双线性读出
只需判别「a 还是 b」就能拿到 0.9——**本实验无法区分「读懂了区域描述」与「只识别了
主体/背景这个二分」**。要分开需要一图多命名区域的样本（G1 NOTES D8 已记录该数据不存在）。

## 三、因果性 vs 相关性（逐条标注，禁止混写）

| 结论 | 类别 | 依据 |
|---|---|---|
| 颜色信息在 VLM 各层线性可解码（R² 0.89–0.93） | **相关性** | 探针 + C1/C2b 对照 |
| where 信息在 VLM 各层 token 级可解码（AUC 0.95） | **相关性** | 探针 + C1/C2/C3/C5 对照 |
| image token 与指令无关 | **结构性（数学必然）** | prompt 字符位置 + 因果掩码；实测 AUC 0.503 复核 |
| 指令条件 where 可由双线性读出恢复 | **相关性**（含 shuffle 对照，故非平凡） | S2-bilinear 0.917 vs shuffled 0.539 |
| 颜色方向被下游**用到** | **因果性（部分）** | steering 剂量-反应，见 §3.2 |
| 「擦掉颜色方向后下游不变 ⇒ 模型没用它」 | **不成立，实验未通过操作检查** | 见 §3.1 |

### 3.1 擦除（LEACE rank-1，干预对象 = **整段 256 个 image token**）：**操作检查未通过**

| 量 | clean | 擦颜色方向 | 擦同范数随机方向 |
|---|---|---|---|
| 同层重拟合探针 R² | 0.906 | **0.894** | 0.906 |
| 下游 3-latent 读出口 R² | 0.882 | 0.886 | 0.876 |

rank-1 擦除**根本没擦掉**（0.906→0.894），所以「下游没变化」**不能**解读为「模型没用这条信息」。
**结论：INCONCLUSIVE**，需要多秩 INLP/LEACE 才能下因果判定（写进下一步 N4）。

### 3.2 steering 剂量-反应（同一层、同一干预对象）：**正面因果证据**

λ ∈ [−3, +3]·σ，测下游 3-latent 读出口沿清洁读出权重的投影（相对 λ=0）：

| λ | −3 | −2 | −1 | 0 | +1 | +2 | +3 | Spearman | **幅度** |
|---|---|---|---|---|---|---|---|---|---|
| 颜色方向 | −0.153 | −0.111 | −0.052 | 0 | +0.033 | +0.077 | +0.139 | **1.00** | **0.292** |
| 同范数随机方向 | −0.052 | −0.036 | −0.015 | 0 | +0.001 | +0.021 | +0.022 | 1.00 | 0.074 |

> **单调性本身不判别**（随机方向的 Spearman 也是 1.00）。判别量是**幅度比 = 3.95×**：
> 同样范数下，探针找到的颜色方向把下游读出推动的距离是随机方向的近 4 倍。
> reverse 曲线按构造是 colour 的镜像，不含独立信息（故不计入）。

| `src_0e6178111d466cfb` | 0.653 | 主体占比 >60%，正负例极不平衡 |

**系统性**：空间探针在「主体≠显著区」与「主体占比极端」两类上失灵——与 G1 报的 RO-9
「主体显著场」性质一致，说明这部分 where 更接近**显著性**而非**语义分割**。

## 五、结论

1. **what 没坏。** 颜色量在 VLM 各层线性可解码（R² 0.89–0.93），**到线上 3 个 latent query token
   的读出口仍保留峰值的 93–99%**。**「颜色信息在读出层坏掉」这个判断，本实验不支持。**
2. **what 也不是 VLM 的增量。** C5 像素统计在 6 个属性中的 5 个上**打赢**了 VLM 探针
   （A1 0.977 vs 0.901；A5 0.956 vs 0.913；A6 0.206 vs 0.134）。预注册的 A5/A6 ≥+20% 判据 **FAIL**。
   ⇒ **颜色读出不值得为它换通路。**
3. **where 才是断的，且断因已定位到架构而非表征**：
   - image token 在因果序里先于指令 ⇒ 从 image token 读指令条件空间场**数学上不可能**（S2 = 0.500 全层）；
   - 但 where 本身很强（AUC 0.953，selectivity 0.387，超像素基线 0.660、超全随机骨干 0.704）；
   - 且**换成双线性读出立刻拿到 AUC_target 0.917（打乱指令降到 0.539）**，而线上 attention 读出全层 ≈0.50。
   ⇒ **「分头读、各用各的通路」在 where 这条腿上成立，且是被架构逼出来的。**
4. **H3 的预注册判据给出 SEPARABLE（层距 8 > 6），但该判据在本数据上不具判别力**——两条曲线
   全层极差分别只有 0.08 R² 与 0.025 AUC，峰值层 CI 覆盖大半个网络。**可写的结论是
   「what 与 where 在每一层都同时在场」，不是「它们分处不同层」。**
5. **需要语义的颜色量（A6 色恒常）在 connector 处被压掉**（视觉塔 0.44 → connector 0.018），
   且 LLM 未恢复。这是本实验唯一一处真正的信息断点，但它**不在读出层**。
6. **因果性**：steering 幅度比 **3.95×**（正面因果证据）；rank-1 擦除**操作检查未通过**，
   因果擦除结论**暂缺**。

### 对 pipeline 的影响（诚实报出）

- **where 线（14 维基系数 + 固定基底）**：**得到支持并被加强**。两条新依据：
  (a) 因果序决定了 where 必须从**文本侧 token**读（这正是「VLM 输出基系数」的形态）；
  (b) 双线性/attention 形态的读出能拿到 0.92 AUC_target，而线上的 attention 读出拿不到——
  说明**要训练这个读出，而不是白嫖它**。
- **what 线（颜色读出）**：**负责人「读出层坏掉」的判断不被支持**。颜色在 3-latent 读出口上
  R² 0.85–0.90，且打不过像素统计。建议把 what 线的叙事从「捞回被丢掉的颜色」改为
  **「颜色本来就够用，预算全部投给 where 与渲染器」**；或把 what 的主张限缩到
  **A6 这类需要语义的色彩量**（那里确有断点，但断在 connector）。
- **不要**再写「3-latent 瓶颈把颜色压掉了」——本实验有直接反证。

## 七、本实验自身的局限（供结果审阅 agent 核）

1. **A6 陷阱集是自建的**（NOTES 决策 D2）：本机无 Cube+/NUS-8。A6 结论只在「我方构造的
   gray-world 陷阱集」上成立。
2. **三个 retouch latent 用追加位置读**（决策 D4），非生成位置。已用 `llm.last.L23` 做旁证
   （0.784–0.865，与 lat3 同量级同趋势），但严格说未在生成位置复核。
3. **S2-bilinear 只有两条候选指令**（§2.5 已展开）：无法区分「读懂描述」与「识别 a/b 二分」。
4. **对照 run 规模小于主 run**（颜色 60 源 × A1/A2/A3；空间对照 80 源），CI 更宽。
5. **MDL 不具判别力**：online code 的 compression 在探针与 C5 上都 < 1（0.51–0.89），
   因为 896 维线性探针在早期小块上严重过自信。本报告**不从 MDL 得出任何结论**。
6. **行为侧样本量**（66 源 × 8 = 529 行）小于计划的 100 源；抽取作业按 D-20 增量落盘后主动停止
   以让出 GPU，已完成部分足够（每属性 ≈265 行）。
7. **两个数值陷阱已在实现中修掉并留档**（`tools/probe/probes.py` 文档字符串）：
   (a) 按样本切折的 α 选择因同源近邻而失效（C5 R² 曾为 −18.6）；
   (b) 闭式 block-LOGO 在近插值时给出虚假低误差（A6 R² 曾为 −6.1）。
   两者都会**系统性虚高 VLM 相对基线的优势**，故必须记录。
8. **第一版 matched probe 是错的**（整段平均把「左右两半之差」这个待读量本身平均掉了，
   probe MAE 退化到常数预测器）。已改为**左右半均值之差**并重跑，§1.4 用的是修正版。
