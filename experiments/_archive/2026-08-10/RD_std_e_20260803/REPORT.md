## 要验证的结论

如果这个实验成功，我们就能说**"给一根干净的语义轴 s，LUT 量级的逐像素算子确实能表达局部编辑——这是渲染器的容量，不是数据的巧合"**，并且能说**"全 RD 停工"这条一票否决没有被触发**；失败就不能说 4D 渲染器路线还有命，得按 EXPERIMENTS_v3 RD-E 行转去修 s / 修数据。

## 为什么需要验证它

它是创新点 ②（语义轴渲染器）的**存在性前提**：审稿人第一句就会问"你这根 s 轴真的带来了什么，还是 3D LUT + 一张 alpha 图就够了"，没有 oracle s 下的容量阶梯 + Δ_shuffle，整条渲染器线连"值得做"都证不了。

## 怎么验的

在 D-CONSTRUCT 八级阶梯（S-train 200 对 / S-val 24 对每级）上用 GT 掩膜当 oracle s，同预算训练 **9 个臂 × 8 级 = 75 个 run**（RD-STD / RD-E / RD-A / RD-C K∈{1,3,5} / RD-D + 两个同族 3D 对照），全部走 `tools/harness` 同一套打分；**训练之前先逐级测出"≥3 dB 判据在这份数据上到底可不可达"**，只在可达的档上宣读判决。

## 2. 可达性预检（**本实验最重要的方法学前置**）

### 2.1 这个数字是什么、不是什么

预检估计器 =「s 分位桶 × 层级 RGB 分箱」逐单元最小二乘仿射表（D-24 权威口径），**S-train 拟合、S-val 评分、走与训练臂完全相同的 harness 调用**。

- 它是**被实际达到的数值** ⇒ **天花板的下界**（certified lower bound）。
- **它不是天花板**：实测被训练臂越过（L1/`fixed` 参考 in-mask 30.3 dB，RD-STD 42.6 dB）。原因是该表沿 s 只有 8 个分位桶而掩膜 s 强双峰。
- **只在下界方向使用**：`Δ*_shuffle ≥ 3 dB` ⇒ 「≥3 dB」在该档**可证可达**；`Δ*_shuffle < 1 dB` ⇒ **什么都没证明**，该档标 **N/A，绝不判 FAIL**。
- 唯一的**真上界**在 L0，且是代数的：掩膜恒为 1 ⇒ 每张图 s 场逐点相同 ⇒ 跨图置换 = 恒等映射 ⇒ **对任何模型 Δ_shuffle 严格为 0**。故 L0 结构性豁免 Δ_shuffle 判据。
- 因此 PLAN L1 行的子判据「距天花板 < 2 dB」在本实验**不可评估**（没有合法上界估计器），只以 `gap_to_ceiling_in_db` 作描述统计给出，**不作判据用**。容量主判据仍用 PLAN 自己给的「in-mask vs 同 N 3D ≥ +8 dB」。

**定稿读法**：

- **RD-E 通过，且是代数保证的**：**−0.02 dB**（56.52 vs 3D-LUT 56.54）。

- **RD-STD 判死：−0.93 dB**（判据 −0.50）。比 8000 步的 −2.02 小了一半以上，

- **RD-A 边缘：−0.20 dB**（落在 −0.05 与 −0.50 之间）。**同预算下 RD-A 的 L0 代价只有 RD-STD 的 1/5**，
  与 §3.4 "RD-A 在局部级与 RD-STD 打平"合起来看，**R-5 比 R-1 更划算的证据又强了一分**。
- **RD-D 判死：−0.76 dB**。PLAN R-6 行自己的回退线是"L0 掉 > 0.6 dB → 回退完整归一化"，

- **RD-C K=3 反超对照 +1.82 dB**：它的几何是 s-free 的（s 只进载荷），
  所以退化是结构性的；多出来的 1152 个载荷参数直接变成全局档的容量。
  ⇒ **"退化能力"与"局部能力"在这份数据上确实此消彼长**（RD-C 局部落后 3–6 dB，全局反超 1.8 dB）。

## 4. 结论

1. **RD-E 一票否决门未触发，且不是勉强通过。** 6 个合格档上 Δ_shuffle 为 **+5.66 至 +22.62 dB**，最低档也高出 0.3 dB 门限 19 倍。
   ⇒ **"全 RD 停工"不成立**，渲染器线继续。
   ⇒ 同时它给出了 H5 的正面读数：一个**零归纳偏置**的 17³×5 四线性表，只要把 s 作为第 4 根格点轴，就能在 L1–L4 上比同族 3D LUT 多出 **+17.9 至 +22.5 dB** 的 in-mask。**s 轴本身就有信息量**，这不是高斯参数化的功劳。（代价：73.7K 参数、格点利用率只有 4.5–16.4%。）

2. **RD-STD 的容量阶梯：L1–L4 全过，且过得很宽。** in-mask vs 同 N 3D **+20.6 至 +23.5 dB**（判据门 +8），
   Δ_shuffle 绝对与相对（`max(3, 0.5·Δ*)`）两个口径同时过线。L5（错配）与 L6（重叠秩上限）按预注册不过。
   **未能宣布"L0–L7 每一级都过"**——**L0 在收敛处判死**（−0.93 dB，线 −0.50），L7 则是"意外通过"（见下两条）。
   ⇒ **RD-STD 的晋级判定：L1–L4 全过、L5/L6 按预期不过、L7 的判据本身需要改写、L0 不过。**
   任务卡对 L0 的原话是"掉幅大说明 s 轴伤了全局能力"——**实测成立，但只对 4D 高斯寻址成立**：
   同样加 s 轴，**RD-E 是 −0.02 dB（代数退化）、RD-C 是 +1.82 dB（几何 s-free）**，
   而把 s 放进高斯寻址的三个臂全部付出代价（RD-STD −0.93 / RD-D −0.76 / RD-A −0.20）。
   ⇒ **代价来自"s 进寻址"，不是来自"有 s 轴"。**

3. **L7 在 RO-0 下不是负控制。** 全部五个 s 臂都以 +17.6 至 +26.0 dB 大幅通过。
   **这不是 (x,y) 泄漏**：CI 检查 10 证明算子逐像素置换等变（打乱像素顺序输出同样打乱），
   模型结构上拿不到坐标或邻域。真正的原因是 **L7 的设计前提是"s 分不清同色区两侧"**，
   而 RO-0 直接把 GT 掩膜当 s 喂进去 = **把答案给了模型**；可达性预检也证实该档 Δ\*_shuffle 高达 **+23.49 dB**（全阶梯最高）。
   ⇒ **L7 只有在 s 来自读出（RO-1/RO-3/RO-5…）时才构成负控制**，PLAN §3 的 L7 行需要加这个限定。

4. **s 的空间分辨率是当前主瓶颈，不是渲染器容量。** 同一个 RD-STD，把 oracle s 从 INF-5 的 32×32 缓存换成全分辨率，
   L1 从 42.61 → **53.81**（+11.20 dB）、L4 从 42.87 → **51.42**（+8.55 dB）。
   边界带 PSNR 也印证：32×32 档 L1 边界带只有 26.38 dB（掩膜内 42.61），差 16 dB。

5. **核心科学问题（R-1 vs R-5）有了第一个读数：s 大概率只需要改强度，不需要改方向。**
   同预算（2530 vs 2575 参）下四个容量级差 **+0.23 / +0.19 / −0.24 / −0.68 dB**，全部落在 PLAN 的
   「差 < 0.5 dB → 换用 R-5」区间附近，且**没有任何一处 RD-STD 领先 > 2 dB**。
   ⚠️ 单 seed，**不足以定案**，但方向明确。

6. **s 进寻址（R-2）优于 s 只进载荷（R-4）。** RD-C 在四个容量级上一律落后 RD-STD/RD-A **3–6 dB**，
   且 K=1→3→5 的增益小且非单调（L1/L4 的 K=3 反低于 K=1）⇒ **秩不是瓶颈，"s 在哪一层进入模型"才是**。
   对偶结论：正因为 RD-C 的几何是 s-free 的，它在 L0 上**反超**同 N 3D 对照（+0.44/+0.49/+1.18 dB）——
   退化能力与局部能力在这条路线上此消彼长。

7. **R-6（RD-D）用 780 个参数拿到了接近 RD-STD 的局部能力**（L1 −1.3、L3 −0.3、L4 −0.6 dB），
   代价集中在 L0（见 §3.6）。它也是**唯一一个 μ_s 可学的臂**，实测 μ_s 从 K=6 网格漂到 std 0.291–0.424，
   **从未塌向退化集 D**——与 G3 的 D-27 一致：塌陷通道不会被梯度自发走进去。

8. **方法学（最重要的一条）**：任务卡字面的 `mixed` 档上，RD-STD 的 Δ_shuffle 实测 **−0.06 dB**。
   若无可达性预检，本实验今天就会以「全 RD 停工」结案。**判据必须先证明它在数据的表达范围内，才有资格被宣读。**

| S5 | **R-7/R-10 的评测场合搬家**。本实验 λ 在 75/75 个 run 上都衰减到下界、从未 pinned ⇒ 在 s 收益高的数据上它们没有机会起作用。应在 **s 收益低的档**（`mixed`、真实 SAM3 掩膜档）上做 R-7/R-10 的开关消融，否则这两项永远测不出效应量 | `EXPERIMENTS_v3` §3.1 **RD-STD 行**的消融列 |
| S6 | **RD-C 降级为附录消融**。四个容量级一律落后 3–6 dB 且 K 曲线非单调 ⇒ 「s 依赖需要几阶自由度」的答案是"阶数不是瓶颈"。但保留它的 **L0 反超**（+0.44~+1.18 dB）作为「s-free 几何 = 完美退化」的证据行 | `EXPERIMENTS_v3` §3.1 **RD-C 行** |
| S6b | **L0 的判读必须跑到收敛才算数**（本卡教训）：8000 步给出 −2.02 dB 的"判死"，30000 步补充网格里 RD-A/RD-C/RD-D 已收敛到 −0.86/−0.08/−0.27。建议把 **"L0 退化验证必须跑到曲线平台期"写进 EXPERIMENTS_v3 的 T3 退化验证行**（并给一个平台判据，如"末 3 个探针点极差 < 0.1 dB"），否则每个臂都会得到一个由预算决定的假判死 | `EXPERIMENTS_v3` §3.1 横评行 **T3 退化验证** |
| S6c | **收敛数据支持"L0 代价来自 s 进寻址"，且指向 R-2 的 σ_s 上界**：同样有 s 轴，RD-E −0.02（四线性沿 s 代数退化）、RD-C +1.82（几何 s-free）**都不付代价**，而三个 s 进寻址的臂全部付（−0.93 / −0.76 / −0.20）。高斯要退化只能靠 σ_s 变大把 s 维抹平，而 R-2 恰好把 σ_s 卡在 ≤0.30。建议 **L0-only 消融**：σ_s 上界 ∈{0.30, 1.0, ∞} × RD-STD × L0，判定"防塌陷"与"优雅退化"是不是同一个旋钮的两端 | `EXPERIMENTS_v3` §3.1 **RD-STD 行**；`PLAN_v2` §2.1 **R-2 行**（σ_s∈[0.025,0.30]） |
| S6d | **R-6 的回退线在收敛处触发**：RD-D 的 L0 掉幅 **−0.76 dB**，越过 PLAN R-6 行自己写的 "L0 掉>0.6dB → 回退完整归一化"。建议按 PLAN 原文处置，或在 S6c 的 σ_s 消融里一并复核 | `PLAN_v2` §2.1 **R-6 行**；`EXPERIMENTS_v3` §3.1 **RD-D 行** |
| S7 | **烘焙一致性（E22）必须在任何 RD 臂晋级前补**。本卡没有覆盖，而「烘焙一致性从第一天当一等指标」是红线。`tools/harness/bake_consistency.py` 已就位 | `EXPERIMENTS_v3` §3.1 横评行 **E22** |
| S8 | **把「L2 = VLM 实际 s」与「D-CONSTRUCT 数据级 L2」在文档里区分开**。本实验的 L2 是后者（与 L1 同配方、独立 seed 流），报告已标注，但 PLAN §3 的表格里两者同名，后续实验会踩 | `PLAN_v2` §3 容量阶梯 **L2 行** |
