## 一 可达性预检（**本实验最重要的方法学前置**，任务卡硬要求）

### 1.1 为什么必须先做

G3 的教训（D-26）：D-CONSTRUCT 每级的**出厂目标混了最多 40 种变换身份**
（`class|tier|sign`，`COMBOS24 = 6 类 × 4 档` 再随机符号），而 oracle s **只编码 where、不编码 which**。
任何 f(x,s) 的最优解只能是条件均值 E[y|x,s]，符号近似对称 ⇒ 该均值退回近恒等。
于是在这类数据上**任何模型**都读不出大的 Δ_shuffle——
**RD-E「Δ_shuffle < 0.3 dB → 全 RD 停工」这条全表最重的判决会被数据假象触发。**

### 1.2 这个数字是什么、不是什么（**G3 踩过的坑，本实验明确不重踩**）

预检估计器 = 「s 分位桶 × 层级 RGB 分箱」的逐单元最小二乘仿射表（D-24 权威口径），
在 **S-train 像素上拟合、S-val 整图上评分**，评分走的是**与训练臂完全相同的 harness 调用**。

- 它是一个**被实际达到的数值**，因此是**天花板的下界**（certified lower bound）。
- **它不是天花板**：实测被训练臂越过（L1/fixed 参考值 in-mask 30.3 dB，RD-STD 2000 步就到 41.9 dB），
  原因是该表沿 s 只有 8 个分位桶而掩膜 s 强双峰、训练臂在 s 上是连续的。
- **只在下界方向使用**：`Δ*_shuffle ≥ 3 dB` ⇒ 「≥3 dB」这条判据在该档**可证可达** ⇒ 该档才有资格
  参与 s 轴判据与 RD-E 停工门；`Δ*_shuffle` 小 ⇒ **什么都没证明**，该档标 **N/A，绝不判 FAIL**。
- 唯一有**真上界**的是 **L0**，且是代数的而非统计的：掩膜恒为 1 ⇒ 每张图的 s 场逐点相同 ⇒
  跨图置换就是恒等映射 ⇒ **对任何模型 Δ_shuffle 严格为 0**。故 L0 结构性豁免 Δ_shuffle 判据。

因此 `PLAN §3` L1 行的子判据「距天花板 < 2 dB」在本实验**不可评估**（我没有合法的上界估计器），
报告里以 `gap_to_reference` 作描述统计给出并明标不可作判据用。容量主判据仍用 PLAN 自己给的
「in-mask vs 同 N 3D ≥ +8 dB」，那一条我**可以**评估。

### 1.3 结果

见 `ceiling/ceiling.json` 与 REPORT §3.1。脚本落盘 `config/ceiling_rd.py`（G3 的教训：预检脚本
不落交付目录 = 数字不可复现）。

## 三 待主 agent 决策（**保守默认已采用，可推翻**）

### 决策 1（最重要）：主判读用重渲染的 `fixed` 档，`mixed` 档并排报为对照

**问题**：任务卡的字面输入是 `T4_construct/sanity` 的出厂目标（=`mixed`）。§1.1 的理由说明
该档表达不了「≥3 dB」。**保守默认**：沿用 D-26 已裁定的 G3 先例，把 `fixed`（同源图、同掩膜、
同 `T.composite` 原语，只把目标按**单一固定变换**重渲染）作为主判读，`mixed` 在 L1/L4 上四臂
全跑作为字面档对照。`fixed` 的固定变换取 exposure **+0.60 EV**（tier 2，与 G3 逐字相同，
两实验数字可直接并排）；**L6 例外**必须用一对不同变换（exposure +0.60 → wb δ=+0.12），
否则两张重叠掩膜退化成一张并集掩膜，L6 想问的秩问题就不存在了。

**请裁决**：是否确认 `fixed` 为 RD 全系主判读档（G3 的 D-26 只裁定了 Gate D3）。

### 决策 2：oracle s 走 32×32 缓存瓶颈（INF-5 生产口径），另开小侧网格量化其代价

`DATA_ASSIGNMENT` §3.2 只说「s=GT 掩膜」，未说分辨率。Δ_shuffle **要求跨图 s 形状一致**
（`collapse_probes` 正确地拒绝静默 resize），而各图 H×W 不同 ⇒ 必须有统一表示，
32×32 正是 INF-5 缓存口径。**保守默认**：主网格全部走 `mask → PIL BOX 32×32 → 双线性 → H×W`
（与 G3 逐字相同，且是生产端真实会拿到的东西）。

代价是真实的：32×32 上采样把锐边界摊成 ~30 px 宽的软坡，边界带（±3 px）PSNR 会因此显著劣化，
这正是 M7 要报的东西。为了把「渲染器不行」和「s 缓存不行」分开，**另开 3 个 run 的侧网格**
（L1/L4/L7 × RD-STD × 全分辨率 s）。侧网格的 Δ_shuffle 用**自写的 derangement**
（供体全分辨率掩膜双线性 resize 到受体尺寸），口径与主网格不同，报告里明标。

### 决策 3：RD-D（R-6）的初始化改为 M=0, b=0, **G=I**, g=0

R-6 的局部支路**故意不归一化**（Σ_i w_i < 1），沿用 (M=I, G=0) 会得到 f(x,s) = x·Σ_i w_i ≈ 0.3x
——一个收缩映射而非恒等，该臂会把全部预算花在爬回恒等上，测出来的就不是 R-6 的代价。
红线「G 初始化 = 0 不是 I」的括号里写明了理由是「否则 f(x)=2x」，其保护的不变量是
**init 时 f(x,s)=x**；把恒等放到全局支路、局部支路从零起步同样满足该不变量，且 **M=0 使 f(x)=2x
结构性不可能**。仓库内已有同一配对的先例：`model/glut_repro/model.py::init_e1_residual`
（"f(x) = x + Σ w_i b_i at step 0"）。CI 检查 2c/2d 同时钉住「f(x,s)=x」与「Σ_i w_i ≠ 1」。
**请裁决**：是否追认这条对红线字面的偏离（仅限 RD-D 一个臂）。

### 决策 4：RD-D 的 μ_s **可学**，初值铺在 K=6 锚点网格上

PLAN R-6 行没写 μ_s 是否可学，但**参数量 780 只有在 μ_s 可学时才对得上**（748+32）。
采纳可学。初值不用「全 0.5」（那正好落在 PLAN §1.2 的退化集 D 上），改用 K=6 网格铺开。
副作用是**只有这个臂的 R-3 μ 项是活的**——其余 R-2 臂 μ_s 冻结，μ 项结构性恒为 0。

### 决策 5：GECO 的对数步长与上界（原文只写 "∝"，未给数值）

预注册：约束先除以 τ 无量纲化，`Δlog λ = 0.01 · C_ma/τ`，单步 clip 到 ±0.05，
λ ∈ [1e-4, 100]，λ 初值 1（原文）。上界的存在是 PLAN R-7 失败判据
「β 钉上界仍不满足 → 架构问题」可观测的前提；`pinned_frac` 逐 run 上报。

### 决策 6：R-10 的三项里 (a) 在 oracle 档下是**空转的**，已关闭并记录

R-10(a) = `BCE(Φ(s), mask)`。RO-0 下 s **就是**掩膜（下采样再上采样），Φ=恒等即得 BCE≈0，
没有任何可学的东西——不是「我们不想做」，是这一项在 oracle 档下**没有内容**。
(b)「s 扰动要求输出变」与 (c)「惩罚 ∂f/∂s≈0」合并实现为 GECO 管理的约束
`C = τ − E|f(x,s±δ) − f(x,s)|`，δ=0.5，τ=**0.02**（RGB[0,1] 的 L1 尺度）。
τ 的定标依据：exposure +0.60 EV 在中灰处的 sRGB 位移约 0.094，δ=0.5 对应约 0.045，
故 0.02 是一条**低于任务本身所需**的地板——只禁止「s 完全不起作用」，不规定幅度。
响应量在平均前逐通道 clamp 到 1.0：不 clamp 时该量不在 τ 的尺度上
（在从未共现的 s 处求值是外插，未截断的混合可以返回上百的数值，任何有限 τ 都被平凡满足；
实测未 clamp 版在 L1 上读到 9.6）。

**为什么用扰动而不是置换做代理**：L0 每张图 s≡1，置换代理恒为 0 ⇒ 约束永远违反 ⇒
λ 冲上界 ⇒ 在「s 必须零代价」的那一级上把模型打坏。扰动代理在 L0 可以零重建代价地满足，
这正是 R-7 自称要化解的「强制敏感 vs 优雅退化」矛盾。

### 决策 7：R-3 的 γ_μ 改为**相对量**（主 agent 已授权），γ_λ 为本 agent 预注册

γ_μ = `0.4 × std(锚点网格)`。本实验 s∈[0,1]、K=6 网格 ⇒ γ_μ = **0.1497**，与 PLAN 字面的
0.15 三位小数吻合（CI 检查 18 钉住）；换到 PLAN §1.2 的 s∈[−3,3] 时字面 0.15 只占网格 std 的
7%，hinge 会静默空转。γ_λ（`std(log σ_s)` 的地板）PLAN 未给，预注册 **0.15**，
权重 w_div 预注册 **0.1**（hinge 上限 0.015，与 L_rec 同量级而不压过它）。
**请裁决**：γ_λ 与 w_div 两个数字。

### 决策 8：RD-C 的 B 样条基（PLAN 只写「B 样条基」，未给次数/节点）

预注册：K≥2 用**次数 min(3, K−1) 的钳位均匀 B 样条基**（Cox–de Boor，单位分解，
k≥1 系数零初始化 ⇒ init 时 M_i(s)=M_i⁰）。**K=1 特判为 β₁(s)=s**：
一个基函数的 0 次钳位基是常数 1，会让 K=1 这一档**完全看不见 s**，整个 K 扫描变成
「0 vs 3 vs 5」，与该档要问的「s 依赖需要几阶自由度」正相反。CI 检查 17 逐档钉住
「基能区分 s=0 与 s=1」。

### 决策 9：RD-E 的 TV 只加在 RGB 轴（λ=1e-4），**s 轴 TV 严格为 0**

PLAN R-11 写「17³×5 + TV 正则 λ→∞ 退化 3D」。s 轴平滑正则是红线；更要命的是
**RD-E 是全渲染器线的一票否决门**，沿 s 平滑会让「读不到 s 信息」变成自我实现。
故主线 run 一律 `--tv-s 0`；「λ→∞ 退化 3D」的扫描留作附录（旋钮已在，未跑）。
RGB 轴 TV=1e-4 是标准 LUT 平滑先验，不碰 s 轴。

### 决策 10：加挂的三个小臂并进本目录，不另开实验文件夹

主 agent 允许二选一。选并进 `experiments/RD_std_e_20260803/`：五个臂共享同一份像素缓存、
同一个 seed、同一套 harness 调用与同一份可达性预检——**并排成表的前提是配置逐字节相同**，
拆目录会引入「两套数据装配」的隐患。STATUS.md 已记录此选择。

### 决策 11：预算 8000 步（不是 20000）

gstd 实测 2000 步已到 in-mask 41.86 dB / Δ_shuffle +17.10（L1/fixed），远过判据线；
75 个 run × 20000 步在卡 0 的 25 GB 预算与 5 并行下要 ~5 h。取 8000 步（4× 冒烟点）。
**风险已知**：8000 步是「够不够过判据」而非「收敛到极限」，因此**臂间比较是同预算比较**，
报告里的绝对数字应读作下界。若主 agent 要终值，重跑同脚本改 `STEPS=20000` 即可（可续跑）。

### 决策 12（**跑完后新增，需裁决**）：L0 的 30000 步复核用「匹配步数」口径读

主网格 8000 步处 L0 的**全部**臂仍单调上升，故补跑 30000 步。写报告时该网格尚未跑完，
REPORT §3.6 的表用的是 **trace 的匹配步数对照**（8 对 val 探针，每臂同一组），
而不是 metrics.json 的 24 对终值——两者**不可混读**（实测同一 run 两口径能差 2–3 dB，
因为 8 对探针集与 24 对终值集不是同一批图）。24 对终值到齐后需复核一次，
刷新命令写在 `job.marker` 作业 3。**最终（30000 步已跑完，7 臂全部收敛，定稿）**：判读经历三次修订，全部登记在 REPORT §3.6：
① 8000 步 −2.02 dB 写成"判死"；② 10000 步中途我写"差没有收窄"——**错的，已删**；
③ 30000 步终值 **−0.93 dB**——差缩到不到一半，但**判据结论仍成立（线 −0.50）**。
同判据下 RD-A −0.20（边缘）、RD-D −0.76（越过 R-6 自己的 0.6 dB 回退线）、
**RD-C +1.82（反超）**、**RD-E −0.02（过）**。
⇒ **L0 代价来自"s 进寻址"，不是来自"有 s 轴"**：s-free 几何（RD-C）与四线性代数退化（RD-E）都不付代价。
**教训：退化类判据必须跑到收敛再判**，否则得到的是由预算决定的假判死/假通过（REPORT §5 S6b）。

### 决策 13（**跑完后新增**）：R-7/R-10 在本实验里没有机会起作用，不等于无用

GECO 的 λ 在 **75/75 个 run 上都衰减到下界、pinned_frac 恒为 0**。在 s 有信息量的数据上，
纯 L_rec 自己就把 s 响应推到远高于 τ=0.02 的水平（实测局部级 0.015–0.052，L0 0.41–0.98），
安全网一次都没兜住过东西。因此**本实验的 RD-STD 实际等价于 R-1+R-2+R-3**。
保守默认：**不据此降级 R-7/R-10**，改为建议把它们的消融搬到 s 收益低的档（REPORT §5 S5）。

## 四 已知局限（结果审阅请一并看）

- **玩具规模**：每级 200 train / 24 val 对，单一全局渲染器（无生成器、无条件化）。
  这是 sanity 批的规模，不是 INF-2 要求的「每级 ≥2000 张」——**不能外推到全量**。
- **单 seed**：75 个 run 都是 seed 0。臂间差 <0.5 dB 的结论（特别是 RD-A 的
  「与 RD-STD 差<0.5 dB → 换用」判据）**在单 seed 下不可信**，需要补 seed。已在建议下一步列出。
- **s 只有 where 没有 what**：oracle 掩膜 s ∈[0,1] 是真实 s（VLM 读出/掩膜基底，值域 [−3,3] 且连续）
  信息量的**下界**情形。所有结论都带这个前提。
- **L2 不是 PLAN 的 L2**：PLAN §3 的 L2 = 「L1 换 VLM 实际 s」，属 RO 侧，本实验（RO-0 oracle）
  做不到。D-CONSTRUCT 的数据级 L2 是「与 L1 同配方、独立 seed 流」的第二条二值语义梯级，
  本实验按「L1 复现档」判读，报告里明标。
- **L0 在收敛处判死（RD-STD −0.93 dB）**，但要点是**代价的归属**：同样有 s 轴，
  RD-E（−0.02，四线性沿 s 代数退化）与 RD-C（+1.82，几何 s-free）都不付代价，
  三个"s 进寻址"的臂全部付。待验假说：代价来自 R-2 把 σ_s 卡在 ≤0.30，
  使高斯无法靠 σ_s 变大抹平 s 维——**已有对照支持，但尚未直接消融**（REPORT §5 S6c）。
- **烘焙一致性未测**：`tools/harness/bake_consistency.py`（F2）已就位但本卡未覆盖 E22。
  「烘焙一致性从第一天当一等指标」是红线，本实验**没有兑现这一条**——必须在 RD 晋级前补跑，
  已列入建议下一步。
