## 要验证的结论

如果这个实验成功，我们就能说 **"VeraRetouch 的三个 retouch special token 对 image patch 的注意力，经 DiffLMM 序列均值减法（M1）后确实落在主体上，且这不是单张 `sample_flower.jpg` 的偶然"**；失败就不能说 —— 只能说 6-09 那张图是个例，或者"落在主体上"这件事经不起 214 张图 + SAM3 掩膜的量化。

## 为什么需要验证它

论文里凡是引用 6-09 那两张对比图来支撑"C(x) 来自 retouch token 时携带可定位空间信号"的地方，目前**唯一的证据是一张图的定性观察**；审稿人一句"n=1、没有 GT、只有肉眼"就能全部划掉，而这张图又是 attention-readout 路线最常被拿出来讲故事的素材。

## 怎么验的

在 G1 已冻结的 S-val 区域对立批（214 源，零重新采样）上，用 6-09 原脚本**逐行照抄**的 M1 读法（teacher-force `<retouch_light>/<retouch_color&temp>/<retouch_colormixer>` 于 prompt 末尾 → 一次 eager 前向 → 全层全头平均的 post-softmax 注意力 → 减"图像之后所有 query 行"的均值），对 SAM3 主体软掩膜报 `mass-in-GT` / `point∈GT` / `AUC`，并与 raw（不减共模）配对比较；4 个 prompt 条件 ×214 源 = **856 次前向**，全部成功、0 错误。

# 五、⚑ 本实验坐实了什么 / 没有坐实什么

**坐实了（"找主体"）**

1. 三个 retouch special token 的注意力**确实携带主体信号**，且在 214 源上稳定：M1 主体 AUC 0.695、raw 0.784（L），置换零模型 0.499，配对 p < 1e-27。
2. **6-09 的定性现象是真的、可复现的、不是单图偶然**：raw 三 token 近乎同图（余弦 0.88–0.97）、被 sink 主导（sink 格独占 40% 质量）；M1 后三 token 分化（可分性 0.082 → 0.824，超过 6-09 记载的 0.714），GC 视觉上落到主体（`viz/repro_*_pair.png`）。
3. **共模消除确实把注意力质量搬进了主体**：mass-in-GT +0.0395，p=2.8e-19。

**没有坐实（"听指令"）—— 且本实验不试图去救它**

1. `AUC_target` = **0.487**，与随机不可区分。**这与 G1（0.48–0.53）、RO9-L、RO9b（≤0.572）、G1b（0.496）四个实验的判决完全一致，未产生任何冲突，红旗未触发。**
2. 逐源指令相对"一条对所有图相同的指令"的净增量 **≤ 0**（raw −0.002 / M1 −0.039）。也就是说：**这里读到的全部是指令无关的主体显著性**。
3. 因此本实验**不构成**任何"VLM 能读出指令指定区域"的证据，也**不改变** `docs/EXPERIMENT_REGISTRY.md` §3.1 中 G1/RO9-L/RO9b/G1b 的 FAIL 判决。

**新增的一条否定性发现（对 6-09 结论的修正）—— ⚑ 措辞已按补件 B 修订，见 §九**

> 6-09 写的「**raw 注意力下三 token 的图几乎完全相同、只有一个左上角 sink 热点**」是准确的；但由此推出的「**raw 没有主体信号、M1 才解锁了 grounding**」**不成立**：那个 sink 长在 `expand2square` 的**黑边**里（93% 的源全局 argmax 落在黑边格，黑边吃掉 53–74% 的 image 注意力质量），而 AUC 只在有效格上算，**该 sink 从未进入过 AUC**；把色标改成只取有效格，主体立刻显形（`viz/diag_raw_colormap.png` 第 4 列）。M1 的真实作用是**搬走 sink 质量**（mass +0.04，p=2.8e-19），不是"从无到有地解锁定位"。
>
> **但这不等于 raw 有 grounding**：一个**完全不看图像**的纯几何中心先验场拿到主体 AUC **0.836**，高于 raw L 的 0.784、raw GC 的 0.736、M1 GC 的 0.695，配对全部显著为负（见 §九）。

# 七、失败案例（`viz/failure_*`）

四张最差（cond=`auto`，GC，M1 AUC 升序）：

| 源 | 池 | subject_area | raw AUC | M1 AUC | 形态 |
|---|---|---|---|---|---|
| `src_1e24cfef9724078a` | unsplash | 0.516 | 0.404 | **0.351** | 珊瑚礁占左半幅；M1 峰值落在主体右侧的**空蓝水域**，正好在主体边界外 |
| `src_08aef2f575be97b1` | awards | 0.263 | 0.480 | **0.374** | raw 已在 0.5 附近，M1 把峰进一步推离主体 |
| `src_8a214e14be583fde` | awards | 0.273 | 0.519 | **0.381** | 同上 |
| `ppr10k_6019_a` | ppr10k | 0.115 | 0.485 | **0.407** | 小主体，但 raw 本身已失败 |

**归因（有数据支撑，不是叙事）**

1. **主体越大越差**，两档都一样：`spearman(subject_area, AUC)` = **−0.48**（M1）／**−0.56**（raw）。分层：area<0.1 时 M1 **0.779**（≥0.75）、0.1–0.2 **0.691**、0.2–0.35 **0.634**、>0.35 **0.620**。⇒ **预注册的 0.75 这条线本身对主体尺寸分布高度敏感**；本批 32.5% 的源 M1 AUC ≥0.75（raw 44.8%）。
2. **失败是继承的，不是 M1 制造的**：`spearman(raw AUC, M1 AUC)` = **0.853**；四个最差源 raw AUC 已是 0.404–0.519。M1 只是把已经不准的场再推远一点（M1<0.5 占 7.2%，raw 占 3.6%）。
3. **SC token 是系统性失败者**，不是个别样本：M1 下 SC 主体 AUC **0.475**（低于随机），`reg_a` 条件下更掉到 **0.335**、mass 中位 **0.000**（GT 内没有任何正响应）。SC 的 M1 场与 GC **系统性反相关**（余弦 **−0.330**）。6-09 说的"SC→局部花朵"在批量上**不成立**。

# 八、结论与建议下一步

## 可以写进论文/汇报的

- ✅ **定性图可直接用**（`viz/repro_*_pair.png`，5 张，input | L | GC | SC | GT，raw 上 / M1 下）。它现在有 214 源的量化背书，且**必须配一句限定**：raw 那一行之所以"只有一个角"，是逐图 min-max 着色所致；秩次口径下 raw 也找得到主体。
- ✅ **"共模消除把注意力质量搬进主体"** —— mass +0.0395，p=2.8e-19（这条不受 §九 影响：mass 是质量口径，不是判别口径）。
- ✅ **"6-09 那张 raw 图的 sink 在黑边里"** —— 结构性发现，有七列消融图（§九）。

## 不能写的（§九 之后收紧）

- ❌ "M1 解锁了 grounding"（raw 的秩次结构本来就在，见 §九 col4）。
- ❌ **"retouch token 注意力能定位主体"** —— ⚑ **本次新增的禁写项**：它打不过一个不看图像的中心先验（0.836 vs 0.784/0.736/0.695，配对全部显著为负）。只能写"场落在主体上"，不能写"能找到主体"。
- ❌ 任何"读到了指令指定区域"的表述（AUC_target 0.487）。
- ❌ "SC 落到局部花朵"（批量上 AUC 0.475，低于随机）。

# 九、补件 B：raw「肉眼只有 sink 却 AUC 0.736」的图证 + 中心先验对照

**触发**：用户看 `viz/repro_*_raw.png` 后问 —— **"raw 可视化的效果在哪？我只能看到 sink。"** 这个矛盾必须用图证明。

## 9.1 判读结论：假说**成立**，但机制比预想的更具体

预写的判读规则是「④ 或 ⑤ 列能肉眼看出主体轮廓且与 GT 对应 ⇒ 假说成立」。**GC 与 L 两版都成立**（`viz/diag_raw_colormap.png` / `_L.png`，七列消融，5 源 effect-blind）。

实测查明是**两个**混杂，不是一个：

| # | 混杂 | 实测 | 隔离它的列 |
|---|---|---|---|
| **A ⚑ 决定性** | **sink 长在 `expand2square` 的黑边里** | 16 格中约 **5.3 格是纯黑边**（有效格占比中位 0.625）；黑边格吃掉 image 注意力质量中位 **68.8%（L）/ 53.4%（GC）/ 74.4%（SC）**；**93.0%** 的源全局 argmax 落在黑边格（cell 0 同为 93.0%）。**而 AUC 只在 valid 格上算 ⇒ 该 sink 从未进入过 AUC。** 在**有效区内部**，最大格只占 **2.7%（L）/ 4.1%（GC）** 质量 —— 有效区里根本没有主导 sink | col3 → col4 |
| **B** | 6-09 `render()` 把 16 格直接 `resize` 到**未 pad** 的图上，网格却覆盖 **pad 后的方形** ⇒ 约 **1/3** 的系统性错位 | 已由 `make_figs.grid_to_img`（`luma_to_grid` 的严格逆映射）修正 | col2 → col3 |

**七列消融读法**：col2（6-09 逐字原版）与 col3（只修正错位）**都是一片蓝、什么也看不见** ⇒ 错位不是主因；col4（**只把色标改成取自有效格**）**主体立刻显形**，且与 col7 的 GT 明显对应。**这是单变量证明：压平 raw 图的不是"没有信号"，是那个位于黑边、且从不参与 AUC 的 sink 在做 min-max 的分母。**

# 十一、补件 D：中心先验的 0.836 是"更会找主体"，还是"AUC 判不出能不能当 mask"？

**触发**：用户看到补件 B 的表之后 —— **"生成四张可视化图，四个场；你的数值可能没有反映真实的结果。"**

**待检验假说**：AUC 是秩次统计量，对"形状贴不贴合"几乎不敏感；一个平滑的中心圆斑只要主体
大体居中就能拿高 AUC，但它根本不能当 mask 用。若成立 ⇒ 0.836 说明的不是"中心先验更会找主体"，
而是"**AUC 不足以判 mask 可用性**"。

## 11.1 口径（预先写死，见 `metrics.json → four_field_multimetric.metric_spec`）

**阈值化对四个场完全一致 = 面积匹配 top-k**：k = 该源 GT 正格数（valid 格内），
取场在 valid 格上的前 k 名为预测前景。**纯秩次** ⇒ (a) 对任何单调变换不变，
各场值域差异（中心先验全负 / raw 全正 / M1 有正有负）不影响公平性；
(b) **完全不需要逐图 min-max**（红线），阈值也不再是自由参数。

| 指标 | 定义 |
|---|---|
| `auc` | 主体 AUC，与主实验/补件 B **逐字同实现** |
| `soft_iou` | `Σ min(pred, m_soft) / Σ max(pred, m_soft)`，pred 为 top-k 二值、m_soft 为 SAM3 软掩膜（另报 `hard_iou`） |
| `bf1` | **像素级 3px 边界 F1**：pred 最近邻上采到 512² canonical square，与**全分辨率** GT 边界比对；3px 按 canonical square 原生尺度换算（与 point∈GT 的 ±6px 同一换算式）。另报容差扫描 |
| `bf1_grid` | 网格级边界 F1（16×16，1 格容差）—— **分辨率公平的伴随列**（3px 远低于一格 ≈ 32–64 原生 px） |
| `point` | argmax 格落在 6px 膨胀 GT 内（复用 `config/point_ok16.npz`）。二值量，**报率不报中位数** |

⚑ **着色与算数分离**：出图用"只取有效格"的 min-max（补件 B 已证明正确的那一档，**不做 relu**——
否则全负的中心先验场会被压成空白），**四个场同一条规则，仅用于出图**；上表任何数字都不经过它。

⚑ **新增伪影守卫（本节最关键的方法论动作）**：加一条 **同支撑、同 k 的随机 top-k 零模型**。
边界 F1 有一个已知失效模式 —— 散得到处都是的预测边界极长，`recall`（GT 边界附近有没有预测边界）
会被白抬高。**不加这条对照，"attention 边界更好"这个结论无法与"attention 更碎"区分开。**

## 11.3 ⚑ 判读：**部分翻转 —— 重叠类指标没翻转，边界类指标翻转**

**按任务卡的两分支定义（"中心先验 AUC 高但 IoU/边界显著差于 attention 场"），本节落在
"不翻转"分支：IoU 没有翻转，中心先验在 soft-IoU / hard-IoU 上仍然显著更高（Δ=+0.062…+0.108，

1. **边界类指标上，三个 attention 场全部显著胜过中心先验**（bf1 3px：+0.016…+0.027，p ≤ 7.0e-10；

（`bf1_grid` +0.03…+0.11，可信口径下），但它覆盖的格整体是错的 —— 在所有重叠类判据
（AUC / soft-IoU / hard-IoU / 峰值落在 GT 内）上仍然输给一个从不看图像的场。**
用户的直觉"数值可能没反映真实结果"**方向正确**（AUC 确实测不出形状，四指标里有两个翻了），
**但结论方向不变**：翻转的是边界类指标，而"能不能当 mask 用"的主口径是重叠度，那一列没翻。

`viz/diag_four_fields.png` 把这件事画在了一起：白色实线 = 面积匹配 top-k（**IoU/边界 F1 真正
打分的那块**），红色虚线 = GT。中心先验那一列永远是画面中央**一个紧凑圆斑**（连通块数中位 **1**）
——形状上根本不像掩膜，却因为压在主体上而 IoU 更高；attention 那三列是**散落 7–10 块**的碎片
（连通块数中位 9–10、边界格数 23 vs 12），边界总长几乎是中心先验的两倍。

## 11.4 中心先验 sensitivity（它有没有可调的自由参数？）

**没有。** 主档 `−distance` 的任何**单调递减**变换在秩次口径下给出**逐位相同**的全部指标
（面积匹配 top-k 与 AUC 都是秩次量）——数值验证而非口述：

| 变体 | AUC | soft-IoU | bf1(3px) | 与主档逐位相同？ |
|---|---|---|---|---|
| `−L2 距离`（**主档，与补件 B 逐字一致**） | 0.8358 | 0.3156 | 0.0327 | — |
| 高斯 σ=2 / 3 / 5 | 0.8358 | 0.3156 | 0.0327 | **是（全部指标逐位相同）** |
| `−L1（曼哈顿）距离` | 0.8382 | 0.3072 | 0.0393 | 否（换的是距离度量本身） |
| `−L∞（切比雪夫）距离` | 0.8121 | 0.2897 | 0.0293 | 否（同上） |

⇒ **半径/衰减不是自由参数**（秩次不变）；换距离度量的三个变体全部落在 0.812–0.838，
**结论对度量选择稳健**，且主档不是三者里最高的那个（L1 更高）——没有为凑结果挑参数。

## 11.5 D-1 选源规则（effect-blind，`config/four_field_picks.json`）

## 11.6 对 RO 系判据的建议

| # | 建议 | 指向 |
|---|---|---|
| **C9 ⚑** | **RO 系主体判据从单列 AUC 改为「AUC + soft-IoU + 边界 F1」三列**，且**每一列都必须并排中心先验**。本节实证：同一批场，AUC/IoU 说中心先验赢、边界 F1 说 attention 赢 —— 只报一列会得到两个相反的故事 | §2.1 RO 系公共判据行（与补件 B 的 C6 合并） |
| **C10 ⚑** | **任何形状类指标必须同时报「同支撑同 k 的随机 top-k 零模型」**。本节实证：3px 边界 F1 的随机零模型（0.0394）**高于**中心先验（0.0327），该口径在 16×16 分辨率上主要在测边界长度 —— 没有这条对照就会把碎片化误报成"边界更准" | §2.1 RO 系公共判据行；亦适用于将来任何 IoU/边界类指标 |
| **C11** | **阈值化一律用面积匹配 top-k**（纯秩次），既避免阈值成为自由参数，也天然满足"s 禁逐图归一化"红线 | RO/PR 系所有需要把场变成 mask 的地方 |
| **C12** | 16×16 场做像素级边界评测时，**容差不得低于一格**（本批一格 ≈ 32–64 原生 px）。要更细的边界判据必须先提高读出分辨率 | 与 C9 配套 |
