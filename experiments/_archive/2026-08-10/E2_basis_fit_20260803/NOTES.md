## 关键实现口径（假设，已当场核实/自行定标）

- **soft-IoU 形式**：min/max 版 Σmin(m̂,m)/Σmax(m̂,m)（软目标完美恢复=1.0，与 ≥0.97 阈值语义一致；
  乘积版对软掩膜在完美恢复时 <1，无法支撑 0.97 判据）。乘积版同存 metrics（iou_prod）。
  注意：IoU 此处是**离线拟合实验的预注册损失/度量**（PLAN §1.5 明文），不违反「IoU 禁当（训练）优化目标」红线——后者针对在线训练。
- **带通读出** = 两阈值 logistic 带 σ(k(s−μ+h))−σ(k(s−μ−h))（k∈(1,40)、h∈(0.02,2.5) 有界 sigmoid，禁裸 exp）。
  依据：渲染器 s 轴是 M=12 高斯**混合**，可合成平顶带；单高斯读出无平顶，环形（梯形剖面）实测中位数只到 0.78
  （已存档于冒烟记录），logistic 带才是「高斯轴能买到什么」的代表性单带读出。单调读出 = σ(g·s+b)。
- **拟合协议**：L-BFGS（strong Wolfe，max_iter=120，float64），逐掩膜；重启 = logit-LSQ 启发式 + 6 随机 + α≈0 起点
  + 质心-径向解析起点（x²+y² 的 Legendre 换算）；tie-break（损失差<1e-4 时取 α 最小）保证常数掩膜的退化解可达。
  拟合在 stride-2 网格，soft-IoU 在全分辨率评估。
- **几何族参数**：linear/radial/elliptical 按 PLAN §2 数值表适配 512²；wedge = 顶点内置的单支角扇（apex U(0.3,0.7)²，
  半角 U(15°,45°)，角羽化 U(2°,8°)）；**ring（专项）**= 薄环：r_mid U(0.24,0.35)·D，hw = r_mid·U(0.06,0.10)，
  feather = hw·U(0.3,0.6)。
- **常数掩膜度量**：全 0 目标下 min/max IoU 恒 0（分子恒 0），判据本就用 α 与 std（另报 MAE 与补集 IoU），
  IoU 聚合不含 constant 族。
- **几何掩膜的 range/语义通道**：与随机配对的 S-val 真实图像（100 张池，round-robin）绑定——14 维全量在场，
  几何判据同时检验「干扰通道在场时优化器仍找到几何解」。
- **语义通道后处理链**：cos-sim 48² → bilinear 上采样 → guided filter（r=32, eps=1e-3，guide=luma；
  PLAN §1.3「guided filter 作用在基通道上」）→ 逐图标准化 → 对 [1,geo5,L,S] 残差正交化 → 再标准化。
- **语义五类**：l 系 C_GT 语义槽只有 semantic-0/1（皆主体类掩膜），无五类标签；按掩膜内主导内容锚
  （sky/skin/foliage/water/architecture 五类）指派 class5 并分组报告。winner_confidence=low 的候选行剔除（保守）。

## 冒烟后的两处修订（透明记录，非事后调参）

1. **环形族几何修正**：初版采样（r_mid U(0.15,0.35)D，hw U(0.03,0.10)D）会产出「胖环/近圆盘」，
   任何单调读出的解析上界 = 覆盖圆盘 IoU = 1−(r_in/r_out)²，胖环时该上界 0.5–0.77，预注册 ≤0.40 **解析不可达**。
   改为 hw ≤ 0.10·r_mid 的薄环后上界 0.21–0.33。这是掩膜族定义修正（让判据检验读出能力而非掩膜肥瘦），
   拟合器与判据未动；修正在看到冒烟数字后做出，特此声明。
2. **带通读出形式**：单高斯 → logistic 带（理由见上；单高斯冒烟中位数 0.78 作为次要观察保留在本 NOTES）。

## 缺口 A：被测对象的形式化（先定义，再预注册）

固定 RGB 点上，s 是唯一自变量，基元 i 的权重退化为
`w_i(s) = o_i N(s; μ_i, σ_i) / Σ_j o_j N(s; μ_j, σ_j)`。
一个「渲染器可画出的掩膜」= 携带同一载荷的基元子集的权重和：`m(p) = Σ_i c_i · w_i(s(p))`，
`c_i∈{0,1}`（松弛为 `c_i∈(0,1)`，见 A-3 的硬化检验）。四个读出档：

| 档 | 读出 | 参数化 |
|---|---|---|
| 无约束·平顶带（第一回合交付物用的） | `bandpass` | σ(k(s−μ+h))−σ(k(s−μ−h))，μ 自由、k∈(1,40)、h∈(0.02,2.5) |
| 无约束·单高斯 | `gauss` | exp(−½((s−μ)/σ)²)，μ 自由、σ∈(0.05,3.0)，**幅值恒 1** |
| **约束·平顶带（缺口 A 的正主）** | `cband_norm` | **M=12、μ=linspace(−3,3,12) 固定不可学、σ_i∈[0.025,0.30] 有界 sigmoid、o_i=sigmoid、c_i=sigmoid，带归一化分母** |
| 约束·单高斯 | `cgauss` | 单基元：**μ 锁在固定网格点**、σ∈[0.025,0.30] 有界 sigmoid，幅值恒 1 |

附加档 `cband_unnorm`（去掉归一化分母 + clamp 到 ≤1）= R-6/RD-D 形态的对照，用来回答
「买到平顶的到底是归一化还是混合」。**全程无任何 s 轴平滑正则**（红线）；σ 一律有界 sigmoid，**无裸 exp**（红线）。

### 预注册判据（**本节在跑任何约束档之前写入**，时间戳见 git）

- **A-1（主判据）**：`main14 | cband_norm | ring`（n=200，同一批薄环、同一 L-BFGS 协议）
  中位 soft-IoU **≥0.90**（= MB-1 环形带通核心门）**且**相对无约束平顶带（0.9753）掉幅 **≤0.03 绝对**。
  两条同时满足 = 缺口 A 闭合（正面证据）；中位 <0.90 = **负面结论**，核心证据图不能进论文。
- **A-2（响应级）**：以第一回合每个环拟合出的无约束平顶带 `r*(s)` 为理想目标，
  允许 s 的仿射重参数化（α/w₀ 本来就自由），约束混合的响应 `r_c(s)` 拟合 `r*`：
  平顶区（`r*≥0.9`）**最大偏差中位 ≤0.05**，全域 RMSE 中位 **≤0.05**。
- **A-3（载荷硬化）**：把 `c_i` 四舍五入到 {0,1}（其余参数不动）后，中位 soft-IoU 掉幅 **≤0.02**。

## 缺口 B：`gauss` 路径崩溃的定位与修复

- **根因**（复核确认）：`e2lib.radial_starts` L369 只对 `readout=="bandpass"` 产出含 `mu`/`sig` 的起点，
  `else` 分支产出单调式的 `g`/`b`；而 `fit_mask` 对一切非 `monotone` 读出都去取 `st["mu"]` ⇒ `KeyError('mu')`。
  审阅侧实测 600/600 复现。
- **修复**：把分支条件从「是不是 bandpass」改成「是不是 monotone」，与 `fit_mask` 的分支结构对齐
  （`monotone` → g/b 起点；其余一切带通类读出 → mu/sig 起点）。这样新增的 `gauss`/`cgauss`/`cband_*`
  也自动拿到质心-径向起点，不再有分支遗漏。
- **补数**：`gauss` 档写进 `CONFIGS` 并全量落盘（四类几何 + 语义 + 常数，main14 与 geo6_ring 各一遍），
  使「单高斯只到 0.78」这个决定核心判据成败的数字**可从交付代码复现**。

## 第一件的方法学要点：REPORT §3.2 的 β 区间是**等不透明度**读法，不是可达集的边界

第二回合的闭式（`axis_response.reachable_beta`）设 o_i 全相等，于是相邻基元的归一化竞争交点恰在网格中点，
半宽 h = n_on·Δμ/2，得 β_sym = n_on·Δμ²/(2σ²)。**但 o_i 在 PLAN L48 里是可学参数**，交点位置随 o 移动：

```
两基元归一化竞争的交点：  s* = s_mid + (σ²/Δμ)·ln(o_left/o_on)
⇒ h = n_on·Δμ/2 − (σ²/(2Δμ))·[ln(o_left/o_on) + ln(o_right/o_on)]
⇒ 对称情形 β = h·k_eff = n_on·Δμ²/(2σ²) − ln(o_nb/o_on)
```

即 **β 可以靠「把载荷格调暗、把邻格调亮」压到 β_sym 以下**，而平顶高度不受影响
（峰值 = 1/(1+2e^{−β})，与目标带的 tanh(β/2) 同阶同形）。本轮把这条**数值核验**过（见 REPORT §12.1）。

推论（写进 REPORT）：**第二回合报的 [1.65, 238] 是可达集的一个保守子集**，
「需要的 β 落在里面」仍然是有效的**充分性**论证；但反过来「落在外面 ⇒ 画不出」**不成立**，
所以对 M=6 必须补数值验证（任务卡已预见这一点）。

另一处修正：把载荷组大小 n_on 放开后，等不透明度可达集 = ∪_n [n·f/σ_hi², n·f/σ_lo²]（f=Δμ²/2）。
因 σ_hi ≥ √2·σ_lo（0.30 ≥ 0.0354），相邻区间首尾相接，**并集是一条射线 [Δμ²/(2σ_hi²), ∞)**。
⇒ **唯一起作用的是下界**；上界（238 / 1152 之类）从来没咬过。
