# E2：掩膜基底离线拟合（MB-1）+ 缺口 A/B 补件

## 要验证的结论

如果这个实验成功，我们就能说：**14 维单轴基底把线性/径向/语义掩膜画到 0.987/0.986/0.873，薄环掩膜只有沿 s 的「平顶带通」读出画得出（0.975）、任何单调读出都画不出（0.342）；而且这个 0.975 不是靠一个自由挑选的读出凑出来的——渲染器自己那根受约束的 s 轴（M=12、μ 固定网格、σ_s∈[0.025,0.30] 有界、跨基元归一化）本身就能合成它（0.975，掉幅 −0.000；几何-only 0.990 反超 0.977）**；失败就不能说「s 是寻址坐标而不是混合强度」，5D 方案与整条 novelty 都要重估（PLAN L214 决策规则）。

## 为什么需要验证它

这是创新点②「s 是第四根坐标轴」的唯一量化证据，审稿人两句话就能打死：①「这不就是 3D LUT 加一张 alpha 图？」②「0.975 是你挑的自由读出凑的，渲染器那根被反塌陷约束绑住的高斯轴根本合成不出那个平顶」。第一句由 0.975 vs 0.342 挡住；**第二句在第一回合没有任何产物回答**（REVIEW-result §2.4 判定为「本实验最关键未答问题」），本补件轮就是来回答它的。

## 怎么验的

在 1,020 张 512² 掩膜（线性/径向椭圆/薄环/束状楔形各 200 + 全局常数 20 + S-val 真实图 C_GT 语义 176）上逐掩膜 L-BFGS 拟合 soft-IoU（stride-2 拟合、全分辨率评测），**六种沿 s 的读出各跑一遍**：单调 / 无约束平顶带 / 严格单高斯 / **约束 M=12 归一化混合（渲染器真参数化）** / 约束单基元 / 约束未归一化；再在**响应级**把约束轴拟合到第一回合逐环拟合出的平顶目标 r*(s) 上（n=200×2，σ_max×M 共 27 格扫描），并给出闭式可达范围。共 6,217 次拟合，`n_fit_errors=0`。

## 3. 缺口 A：受约束的 s 轴能不能合成 0.975 所依赖的平顶？

### 3.1 结论：**能**，而且不是勉强能

图：`viz/constrained_axis_evidence.png`（六读出并排 + 同一个环的五种渲染）、
`viz/constrained_axis_response.png`（响应曲线 vs 理想平顶 + 12 张带通掩膜 + σ_max 扫描）。

| 环形掩膜 · 读出（同一批薄环、同一 L-BFGS 协议） | 14 维基底 | 几何-only 控制 |
|---|---|---|
| 单调 σ(g·s+b) | 0.3423（n=200） | 0.2910（n=200） |
| 严格单高斯（幅值恒 1，**无平顶**） | 0.7781（n=200） | 0.7770（n=200） |
| 约束单基元（μ 锁网格、σ∈[0.025,0.30]，幅值恒 1） | 0.7771（n=50） | 0.7793（n=100） |
| 约束轴 · **未归一化**（R-6/RD-D 形态） | 0.9634（n=13） | — |
| **约束轴 · 归一化（渲染器真参数化）** | **0.9754**（n=184） | **0.9901**（n=60） |
| 无约束平顶带（第一回合用的） | 0.9753（n=200） | 0.9766（n=200） |

三点读法：

1. **约束档没有掉分**。14 维档配对中位差 −0.0010，几何-only 档配对中位差 **+0.0130（约束档反超）**，
   两档都是 **0% 的环掉幅超过 0.03**。「0.975 靠一个自由读出凑出来」的质疑不成立。
2. **几何-only 档反超**（0.9901 vs 0.9766）说明这不是「图像通道帮忙」——恰恰相反，图像/语义通道在场时
   优化器偶尔被图像结构带偏（见 §7 失败案例）。
3. **平顶仍然是必需的**：严格单高斯 0.778、约束单基元 0.777，**都不过 0.90 门**。
   把「带通」写成「任何沿 s 的非单调读出」是错的，必须写「**具备平顶的**带通读出」。

### 3.2 为什么能——闭式机制（这条把「事后换读出」的质疑一并解掉）

固定 RGB 点上渲染器的权重 `wᵢ(s) = oᵢN(s;μᵢ,σᵢ) / Σⱼ oⱼN(s;μⱼ,σⱼ)`。等 σ 时相邻两基元的归一化竞争
**恰好是一条 logistic**：

```
log(oₖNₖ) − log(oₖ₊₁Nₖ₊₁) = (Δμ/σ²)·(s − s_mid) + log(oₖ/oₖ₊₁),   Δμ = 6/(M−1)
⇒ 单个基元的归一化权重 = 两条 logistic 边夹出的平顶带，边斜率 k_eff = Δμ/σ²，
   半宽 h = n_on·Δμ/2  ⇒  形状不变量 β = h·k_eff = n_on·Δμ²/(2σ²)
```

数值核验（M=12，Δμ=0.5455）：σ=0.1347 时 `max|wₖ(s) − [σ(k(s−a))−σ(k(s−b))]| = 1.5e-07`，β=8.199。

- **第一回合逐环拟合出的平顶带需要的 β**（= h·k，唯一的仿射不变量）：14 维 p10 6.47 / 中位 **8.40** / p90 11.28；
  几何-only 6.38 / **8.14** / 11.01。
- **约束轴可达的 β**（M=12、σ∈[0.025,0.30]、n_on=1）：**[1.65, 238]**；n_on=3 时 [4.96, 714]。
- ⇒ 需要的区间**完整落在可达区间内部，两端都有量级余量**。这就是 A-2 的偏差只有 1e-05 的原因。

**对论文写作的直接后果**：第一回合把带通读出从单高斯换成两阈值 logistic 带，被审阅质疑为「看到冒烟数字之后
做的事后决定」。现在可以改成一句**推导**：logistic 平顶带**就是**渲染器归一化高斯 s 轴的响应形式（误差 1e-07），
不是为了好看挑的。这条从「可疑的事后选择」变成「方法论上的必然选择」。

### 3.3 归一化才是买到平顶的那一半，混合本身不是

- 未归一化档（幅值 oᵢ,cᵢ ≤ 1 的高斯和 + clamp）：响应级平顶最大偏差 **0.1618**（n=200，**不过 0.05 门**），
  RMSE 0.0472；mask 级 0.9634（n=13，比归一化档低 0.012）。
- 机理：σ ≤ 0.30 而 Δμ=0.5455 时，等幅高斯和在平顶上有 ~16% 纹波；归一化把纹波精确消掉（分子分母同相消）。
- 另一侧的边界：σ 取到上界 0.30 时，**单基元归一化权重的峰值只有 0.722**（相邻基元抢走权重），
  所以「σ 越大越平」是错的——平顶要求 σ 落在中段（实测最优 σ≈0.135，正好在 [0.025,0.30] 中间）。

## 4. 缺口 B：`gauss` 路径修复与全量补数

- **根因**：`e2lib.radial_starts` 的分支条件是「是不是 `bandpass`」，而 `fit_mask` 的分支条件是「是不是 `monotone`」，
  于是 `gauss` 拿到了单调式的 `g`/`b` 起点却被按 `mu`/`sig` 读取 ⇒ `KeyError('mu')`。
- **修法**：把 `radial_starts` 的分支改成与 `fit_mask` 同构（`monotone` → g/b 起点；**其余一切带通类读出** → mu/sig 起点）。
  这样新增的 `gauss`/`cgauss`/`cband_*` 自动获得质心-径向起点，不会再有分支遗漏。
- **补数结果**（1,196 拟合，0 报错）：

| 掩膜族 | 严格单高斯（14 维） | 对比：无约束平顶带 | 对比：单调 |
|---|---|---|---|
| 线性渐变 | 0.9899（n=200） | 0.9867 | 0.9866 |
| 径向/椭圆 | 0.9878（n=200） | 0.9863 | 0.9857 |
| **环形** | **0.7781（n=200，不过 0.90 门）** | **0.9753** | 0.3423 |
| 束状楔形 | 0.9237（n=200） | 0.9431 | 0.9422 |
| 语义 | 0.8688（n=176） | 0.8744 | 0.8730 |

## 9. 结论

1. **缺口 A 闭合，结论是正面的**：渲染器那根受约束的 s 轴（M=12、μ 固定网格、σ_s∈[0.025,0.30] 有界、
   跨基元归一化）**能**合成 0.975 所依赖的平顶——mask 级 0.9754（掉幅 −0.000）、几何-only 0.9901（反超 +0.013）、
   响应级平顶偏差 1.4e-05、载荷硬化到 {0,1} 不掉分。**「s 是坐标轴」的核心证据图可以进论文。**
2. **而且拿到了比「能合成」更强的结果**：归一化高斯 s 轴的单基元响应**在解析上就等于**两阈值 logistic 平顶带
   （误差 1e-07），第一回合的读出换形从「事后决定」升级为「推导结果」。
3. **平顶是硬需求**：幅值恒 1 的单高斯（无论 μ/σ 自由还是锁在网格）只有 0.777–0.778，**不过 0.90 门**。
   论文里必须写「具备平顶的带通读出」，不能写「任意带通读出」。
4. **归一化才是买到平顶的那一半，混合本身不是**：去掉分母后响应级平顶偏差 0.16（不过 0.05 门），
   mask 级掉 0.012。这对 **RD-D（R-6 未归一化 s 门）** 是一条独立于 PSNR 的新代价。
5. **反塌陷的 σ 上界不用拿掩膜表达力去换**：σ_max 从 2.0 压到 0.15 对平顶保真毫无影响，压到 0.05 才出现 2e-2 偏差。
6. **缺口 B 修复**：`gauss` 路径 1,196 拟合 0 报错，「单高斯 0.78」现在可从交付代码复现。
7. **楔形归因补齐**：0.94 的 96% 来自二次几何项（lin3 0.54 → geo6 0.93），不是语义基作弊。
8. **环形单调 ≤0.40 这一半仍然只是「未触发死刑」而非发现**（薄环族上解析必然），叙述必须带这个限定。

## 12. β 可达区间随 M 的变化

图：`viz/beta_reach_vs_M.png`（(a) 等不透明度 β 区间 vs M ｜ (b) 响应级平顶偏差 vs M ｜ (c) 掩膜级配对差 vs M）。

### 12.1 先修一处方法学：§3.2 报的 β 区间是**等不透明度子集**，不是可达集的边界

§3.2 的闭式（`axis_response.reachable_beta`）默认 o_i 全相等，于是相邻基元的归一化竞争交点恰落在网格中点，
半宽 h = n_on·Δμ/2，β_sym = n_on·Δμ²/(2σ²)。**但 o_i 在 PLAN L48 里是一个真实的可学参数**，交点随 o 移动：

```
交点：  s* = s_mid + (σ²/Δμ)·ln(o_邻/o_载荷)
⇒ 对称情形  β = h·k_eff = n_on·Δμ²/(2σ²) − ln(o_邻/o_载荷)
   （平顶高度不受影响：峰值 = 1/(1+2e^{−β})，与目标带 tanh(β/2) 同形）
```

**本轮数值核验**（`beta_reach.py`：定点例 = `fixed_cases_quoted_in_report`，
1,500 组随机 (M, σ, ln o 比) = `verify_stratified(seed=1)`；两者都落在
`metrics_beta_M.json → formula_verification`，可逐格复现）：

| 情形 | β | max\|w − 两阈值 logistic 带\| |
|---|---|---|
| 复现第二回合的锚点：M=12、σ=0.1347、等不透明度 | 8.199 | **1.51e-07**（§3.2 报 1.5e-07 ✅ 逐位复现） |
| M=6、σ=0.30、等不透明度 | 8.000 | 2.25e-07 |
| **M=6、σ=0.30、o_载荷=0.202（ln 比 = 1.60）** | **6.400** | **5.49e-06**（峰值 0.99669） |
| M=6、σ=0.30、o_载荷=0.159（ln 比 = 1.84） | 6.160 | 8.87e-06 |
| 随机 1,500 组，限在环形工作区 β∈[6,13] | — | 中位 1.6e-07 / p90 9.0e-05 / max 5.3e-03 |
| 随机 1,500 组，Δμ/σ < 2（相邻高斯严重重叠，恒等式失效区） | — | 中位 2.4e-01 |

**第二处修正**：把载荷组大小 n_on 放开后，等不透明度可达集 = ∪ₙ[n·f/σ_hi², n·f/σ_lo²]（f = Δμ²/2）；
因 σ_hi ≥ √2·σ_lo（0.30 ≥ 0.035），相邻区间首尾相接 ⇒ **并集是一条射线 [Δμ²/(2σ_hi²), ∞)**。
⇒ **真正起作用的只有下界；§3.2 里的上界（238 / 714）从来没咬过。**

**两条后果**（D-31 标注）：
- §3.2 的「需要的 β 落在 [1.65,238] 内部」仍然成立，而且是**更强的充分性论证**（连最保守的等不透明度读法都够）——**正面证据**保持不变；
- 但反向推断「落在区间外 ⇒ 画不出」**不成立**。所以 M=6 这一档**必须补数值验证**，不能只看解析表。

### 12.2 主表：β 可达区间随 M（域 [−3,3]，σ_s∈[0.025,0.30]，`beta_reach.py`）

环形掩膜实需 β（第一回合 200 条环各自拟合出的平顶带的 h·k）：
