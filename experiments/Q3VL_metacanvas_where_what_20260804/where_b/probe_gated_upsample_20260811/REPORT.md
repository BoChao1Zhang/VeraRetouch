## 要验证的结论

如果这个探针成功，我们就能说 **几何族边缘脏是图像引导上采样造成的（机理 (b)），而且按家族门控把引导关掉能在零训练、零 IoU 代价下修好它**；失败就不能说这句话，只能承认脏边来自粗场本身或损失，门控改造不值得做。

## 为什么需要验证它

DX-1/DX-2 是**测量**归因，本卡是**干预**归因——两种独立证据对上，「(b) 是主因」才站得住。若不做，P1（带限基 + 门控引导残差）整条处方就只有相关性证据；而且门控一旦被证无害，就能立刻进配方，不必等任何训练。

## 怎么验的

在已训好的 P3'（step 1200）上**只做推理**，V_where local 400 条，同一次前向出三档上采样：A 引导全开（现状）／B 家族门控（类型词路由：语义留引导、几何走低通）／C 全关引导（负对照）。判据：分家族 top-k IoU、grid 边界 F1、E_HF、κ̃，全部同图配对 + 置换 p 值。

## 2. 结论

1. **(b) 机理由干预证实**：几何族关掉引导后 κ̃ 从 3.40 降到 0.08（−97.6%，p=1e-4），而 **IoU 差分实测为 0（p=0.99）**——引导上采样确实在往解析族里刻曲率，且刻进去的东西对重叠度毫无贡献。
2. **引导对语义族确有价值**：C 档掉 bF1 0.107、IoU 0.012（p≤8e-4）。正确形态是**条件化**，不是删掉。
3. **B 档已采纳进 P3' 推理配方**（`AmortModel.gate_upsample` 默认开），A 档保留为对照列。
4. **期望管理**：本修复改善的是边缘解析质量，**不提高 top-k IoU**。把 0.74 推过 0.75 的是续训（0.7417→0.7622），不是本卡。

## 4. 判据完整性与一处度量修正

无 AUC；阈值化一律匹配 GT 面积 top-k；配对差分同图内 + 10,000 次置换；色标禁逐图 min-max。

**κ̃ 度量在本卡过程中修了两处**（原实现会给出误导性读数，已修并记录）：

1. **τ 改为按家族标定**（仍是臂常量，非逐图）。实测 GT 梯度幅度跨家族差**两个数量级**（linear 峰值 ~0.006、semantic ~0.60），单一 pooled τ 被锐边语义族拉高到**超过整个 linear 族的梯度上限**，导致 linear 全族窄带为空、κ̃ 恒为 NaN 而**静默从中位数里消失**。
2. **窄带一律取自 GT**，A/B 在**同一批像素**上比较。原实现从各自场取带，于是「更光滑」的 B 档反因带为空得 NaN（与预期读数相反），且 GT 带内曲率近零时比值会炸到 2e5。

> **对已上报数字的影响**：主表的 κ̃ 3.398→0.080 与 p 值取自修正前的聚合；方向与量级已被本卡 16 样本用修正后度量独立复现（2.26→0.088）。**建议全量重算一次 κ̃ 列**再写进论文表格。
