## 2. 终局数字独立复核

### 2.1 复核结论：全部复现，但发现三处**口径**问题

从 `eval_final/per_sample.jsonl` 重算，与 `metrics.json` **逐位一致**（W01 median 0.5565023211157843、W02 0.5616658861337771、p10 0.23575787076226096 / 0.29647779309086110、vs-oracle 0.57939668681024 / 0.58193493024042 等）。任务卡给的「0.557/0.562、vs oracle 0.58、p10 0.24/0.30」**全部核实通过**。

复现过程中确定的口径，以及由此发现的三处问题：

**（a）`median` 不是插值中位数，是 nearest-rank 序统计量。**
n=400 时报告值 = 排序后第 201 个元素，而不是第 200/201 的平均。W01 两种口径分别是 0.556502 与 0.556113（差 3.9e-4）；p10 同理（0.235758 vs 0.234500）。差异小到不影响任何判定，但 **gate 表的阈值比较用的是哪个 median 应当写进协议**——0.75 这类硬阈值上，一个口径差就是一次翻案的余地。**建议：在 A-WhereA-1 里补一句「所有分位数一律 nearest-rank」。**

**（b）`相对逐图 oracle` 的分母与协议脚注 2 / NOTES §14.4 的自述不一致 —— 需要一次 amendment。**
实测该列 = **逐样本比值 `soft_iou / oracle_soft_iou` 的中位数**，其中 `oracle_soft_iou` 是**交付档（hi）逐图**天花板，中位 **0.9651（W01）/ 0.9759（W02）**。
而协议 §5.6 脚注 2 与 `NOTES.md §14.4` 都写「分母 = `ORACLE_CEILING_LOW_MINMAX`，band 0.827 / cband12 0.835（**low 档常量**）」。两者不是一回事：

| 读法 | W01 | W02 |
|---|---:|---:|
| 实际落盘（逐图 hi 档比值中位） | **57.94%** | **58.19%** |
| 按脚注 2 的常量分母（0.827 / 0.835） | 67.29% | 67.27% |

更要紧的是脚注 2 附带的那条「读表推论」在现行实现下**是反的**：脚注说「天花板约 0.83 ⇒ 绝对值那行（0.75）对应约 90.7%，高于 85%，所以**绝对值那行才是更紧的**」。按实际分母（≈0.965/0.976），0.75 只对应 **77.7% / 76.9%**，**低于 85% —— 相对那行才是更紧的那个**。这句话是专门写来防止误判的，现在它本身会造成误判。
（本次两臂离两条线都差得远，所以不影响结论；但 W03–W08 或新方案一旦逼近门槛，这条会直接决定过不过。）
**建议：出一条 amendment，把脚注 2 与 NOTES §14.4 改写为「分母 = A-WhereA-1 A2 表中的逐图 hi 档字段 `fits.<readout>.eval.hi.soft_iou_minmax`」，删掉基于 0.83 的那段推论，或明确标注它只适用于 low 档并列表。**

**（c）配对检验的重采样次数与 A-5 文本不符（方向保守）。**
所有配对 p 值的下限恒为 `9.999000099990002e-05 = 1/10001`，即 **10,000 次重采样**；A-5 原文写的是「bootstrap，2000 次重采样」。方向上更保守，只是文档没跟上。**建议：A-5 相应段落改成 10,000，或注明「≥2000，实现取 10,000」。**

## 3. 「设计失败」结论的证据强度

### 3.1 最强的一条证据：所有增益都来自面积标定，没有一点来自形状

| step | W01 median soft-IoU | W01 grid 边界 F1 | W02 median | W02 grid 边界 F1 |
|---:|---:|---:|---:|---:|
| 500 | 0.4032 | 0.2898 | 0.5060 | 0.2732 |
| 2500 | 0.5133 | 0.3040 | 0.5274 | 0.3299 |
| 4975 | 0.5565 | **0.3186** | 0.5617 | **0.3302** |
| 全程变化 | **+0.153** | **+0.029** | +0.056 | +0.057 |

W01 的 median soft-IoU 涨了 0.153，**grid 级边界 F1 在 4975 步里只挪了 0.029**，且中间波动大于趋势；按这个斜率从 0.319 走到 gate 要的 0.75（= oracle 的 75%），需要约 **1.4×10⁵ 步 ≈ 29 个 epoch**。
W02 的两列同步（各 +0.056 / +0.057），所以对 W02 不能说「形状完全没动」；但**绝对水平同样只有 oracle 的 33.0%**，按其自身斜率外推到 0.75 也要约 **3.3×10⁴ 步 ≈ 6.6 个 epoch**，且最后 1475 步的净变化是 **−0.019**（0.3492 @4000 → 0.3302 @4975）。
两臂合起来的稳健表述是：**形状列停在 oracle 的 32–33%，最后 1000+ 步已无净进展**；对 W01 还能更强地说「增益全来自面积标定」。

配一个零参数归一化，量级更直观（同支撑、同 top-k）：

| 列 | 中心先验 | 模型 | oracle | **模型补上的差距** |
|---|---:|---:|---:|---:|
| grid hard-IoU 中位（W01） | 0.5179 | 0.5495 | 0.9893 | **6.7%** |
| grid hard-IoU 中位（W02） | 0.5179 | 0.5655 | 0.9909 | **10.1%** |
| grid 边界 F1 中位（W01/W02） | 0.1973 | 0.3186 / 0.3302 | 1.0000 | **15.1% / 16.6%** |

| 列 | 全 1 平凡掩膜 | 模型 | oracle | 模型补上的差距 |
|---|---:|---:|---:|---:|
| soft-IoU 中位（W01/W02） | 0.4103 | 0.5565 / 0.5617 | 0.9651 / 0.9759 | **26.4% / 26.8%** |

并且 **21.5%（W01）/ 17.5%（W02）的 local 样本，得分低于「整幅全 1」这个不看图不看指令的掩膜**（soft-IoU(min/max) 对全 1 掩膜恰好等于 `gt_mean`）。

### 3.2 「过覆盖 = 铺成近全局掩膜」——**这条描述在终局是错的，必须改**

需求文档说「预测面积 3.7× 于 GT，铺成近全局掩膜」。终局实测（generated/local，n=400）：

- `pred_mean` 分位 p10/p50/p90 = **0.182 / 0.536 / 0.630**；**没有任何一个样本 `pred_mean > 0.8`，只有 2.0% > 0.7**。「近全局」不存在。
- 整体面积比中位 **1.224（W01）/ 1.221（W02）**，不是 3.7×。3.7× 是 **step-1500 长尾子集**的数字。
- 真正的形态是**向数据集平均面积收缩（regression to the mean）**：

| GT 面积五分位 | W01 `pred_mean` 中位 | 面积比中位 | frac pred>gt | W02 面积比中位 |
|---|---:|---:|---:|---:|
| [0.006, 0.187) | 0.185 | **2.55×** | 0.99 | **1.77×** |
| [0.187, 0.349) | 0.401 | 1.54× | 0.79 | 1.47× |
| [0.349, 0.499) | 0.578 | 1.25× | 0.86 | 1.23× |
| [0.499, 0.501) | 0.611 | 1.22× | 0.90 | 1.22× |
| [0.501, 0.819) | 0.611 | **0.99×**（欠覆盖） | 0.45 | **1.00×** |

即：**小目标过覆盖 2–2.6×，最大目标反而欠覆盖**，预测面积几乎恒定压在 0.53–0.61。这是条件均值回归的标准指纹，不是「铺全局的平凡解」。

**并且过覆盖有一个交付数据无法排除的 loss 侧解释**：§5.5 的 `L_mask` 含 `0.25 × balanced_BCE`。balanced BCE 把正类按 `1/面积` 加权——GT 面积 0.10 时正负权重比约 9:1，**它本身就在为小目标上的过预测付钱**。长尾正是小目标区（长尾 `gt_mean` 中位 0.0995）。
**推论：把「过覆盖」直接当成「架构掉进平凡解盆地」的证据是过度归因**；现有数据同时兼容 (i) 条件均值收缩、(ii) balanced-BCE 的小目标正类上权、(iii) 平凡解盆地，三者签名相同。需求文档 §1.4 第 2 条要求新方案「说明什么机制阻止这个平凡解」——这个提法应改成中性的「阻止预测面积向数据集均值收缩」，并把 loss 侧的候选解释一并列出（一个便宜的判别实验：去掉 balanced BCE 或改成面积无关的加权，看小目标过覆盖是否消失）。

**读法**：整臂 Δ > 0 几乎全部由「中心先验本来就打不中」的类（偏心 0.175、小面积 0.139、复杂边界 0.323）贡献，那里的 Δ 是 +0.12～+0.15；而在**中心先验本来就强的三个大类**上，W01 三类全部打平（p 0.61–0.67），W02 只在居中类打平（p 0.119），大面积/紧凑两类虽显著但只有 +0.026/+0.038（相对基线 4–7%）。
这既比需求文档现在的写法（「居中类**输给**中心先验 Δ=−0.05 p=1e-4」）**更准确**，也依然**足够致命**——但两句话不是一回事，前者已经不成立（见 §4）。

### 3.4 W01 vs W02（Band vs CBand12）说明了什么

| 列 | W01 band | W02 cband12 | 读法 |
|---|---:|---:|---|
| median soft-IoU | 0.5565 | 0.5617 | **+0.005，等于没差** |
| p10 | 0.2358 | 0.2965 | +0.061，尾部明显更稳 |
| 长尾（softIoU<0.3）样本数 | 65（16.2%） | 43（10.8%） | 尾巴短了 1/3 |
| grid 边界 F1 | 0.3186 | 0.3302 | +0.012，形状几乎没变 |

| `s_std_ratio < 0.2` 的样本比例 | **33.5%** | **3.5%** | Band 有一个明显的 s 塌缩模式 |

## 5. 指令条件性的终局读数 —— 新方案的起点假设

这是本次审阅认为**最有价值的正面发现**：模型**确实在读指令**，但那条通路只承载得动一个标量。

### 5.1 指令确实进来了，进来的是「目标有多大」

`corr(pred_mean, gt_mean)` 逐 context（终局，local n=400）：

| context | W01 Pearson / Spearman | W02 Pearson / Spearman | `pred_std` 中位（W01） |
|---|---:|---:|---:|
| **generated（真实指令）** | **0.747 / 0.665** | **0.783 / 0.691** | 0.288 |
| gt（teacher 指令） | 0.815 / 0.742 | 0.846 / 0.758 | 0.274 |
| **shuffled（同图伙伴的真实指令）** | **0.167 / 0.188** | **0.159 / 0.150** | 0.273 |
| fixed_phrase（"the main subject"） | 0.040 / 0.066 | 0.180 / 0.191 | 0.332 |
| irrelevant_words | −0.037 / −0.012 | 0.144 / 0.129 | 0.321 |
| **null（无语言上下文）** | **0.035 / 0.002** | −0.104 / −0.078 | **0.016** |

- 换成**同一张图的另一条真实指令**，面积相关性从 0.67 掉到 0.19 —— 这不是图像显著性，是**指令特异**的信息。
- 去掉语言上下文（null），W01 的场直接退化成近常数（`pred_std` 中位 **0.016**，`pred_mean` 0.674），soft-IoU 中位 **0.4092**，而「全 1 平凡掩膜」的 soft-IoU 中位是 **0.4103** —— **数值上就是那个平凡解**。
- 三条负控制全部有降幅（shuffled 0.145/0.126、fixed_phrase 0.227/0.220、irrelevant_words 0.246/0.400），`fixed_phrase` 降幅**大于** shuffled —— 红线里那条「对全体样本相同的一句话」在这里没有冒充成功。

### 5.2 扣掉面积以后，指令条件性≈0

同图配对差分（`IoU(field_A, GT_A) − IoU(field_A, GT_B)`，再减去中心先验走同一流程的同一量）：

| 口径 | W01 | W02 |
|---|---|---|
| 全部配对（n=568 / 110 组），校准后 Δ | +0.0239（p 1.0e-4） | +0.0312（p 1.0e-4） |
| **面积均衡子集**（面积比 ∈ [0.5,2]，n=285 / 76 组），校准后 Δ | **+0.0032（p 0.460，CI95 [−0.0056, +0.0114]）** | **+0.0113（p 0.028，CI95 [+0.0013, +0.0207]）** |

全程轨迹（校准后、面积均衡口径）：W01 在 10 个 checkpoint 上是 −0.028 → +0.003，**除 step 500（负显著）外没有一个 checkpoint 显著**；W02 从 step 3500 起稳定在 +0.010~+0.012（p 0.015–0.076）。

**读法**：在**同一张图、面积可比**的两条不同指令之间，模型的场对「自己那条指令的目标」的偏好，比零参数中心先验多出来的部分是 **0.003 hard-IoU（W01，不显著）/ 0.011（W02，勉强显著）**。
**结论：指令→空间的通路只承载了目标的尺度/范围，几乎不承载目标的身份与位置。**

### 5.3 antonym 不变性（预期就是「不动」）

翻转指令里的明暗/冷暖/饱和方向词、主体短语不变：`|Δ(hard-IoU)|` 中位 **0.0000**、p90 0.0043/0.0042、signed p 0.30/0.46 —— **场完全不动，PASS**。
即 Where 场没有偷读颜色方向词。这条是干净的：它同时说明 §5.1–5.2 里观察到的那点指令依赖，**不是**颜色词造成的伪相关。

### 5.4 对新方案起点假设的直接含义

1. **不要从「模型完全不理解指令」出发立项**——它理解到了尺度层级（Spearman 0.67，且 shuffle 会打掉）。真正缺的是**空间指代**。
2. **新方案的最小可证伪判据应该直接打面积均衡的同图配对 Δ**：现方案是 +0.003 / +0.011；任何声称「解决了 grounding」的新机制，必须在这一列上给出量级更大的、面积均衡口径下的显著正 Δ。**这比 median soft-IoU 便宜、也更难作弊**（median soft-IoU 可以靠面积标定刷到 0.56）。
3. **中心先验必须逐层带**：整臂 Δ > 0 是被「中心先验自己弱的类」拉起来的（§3.3）。新方案的报告如果只给整臂 Δ，会重复同一个错误。

>
> **限定配置** —— Qwen3-VL-4B SFT `checkpoint-4976` 全冻结；`Q_where` 只读**最后一层**（`layer=-1`, `final_norm=true`）`<where>` token hidden + merger 前 `F_pre`；MetaCanvas `MC8-Joint`（8×8 = 64 queries）；connector 512/6 blocks/8 heads/FFN 2048，cross-attn residual gate 零初始化；输出为**全局 71 维** `(w₀, w_dir, α, ρ)`，无 dense logits；basis = Where-A `BA-3-Joint` Phi-64；readout ∈ {`R-Band`, `R-CBand12`}；`L_where` 按 §5.5 两段 schedule 原样；AdamW `lr 2e-4` / cosine→0 / warmup 3% / `clip 1.0`；effective batch 32；**1 epoch = 4975 optimizer steps**；159,215 训练样本（local 47.45%）；50/50 teacher/generated context；**单 seed**。
>
> **未通过的六项**：local median soft-IoU 0.5565 / 0.5617（gate 0.75）；相对逐图 oracle 57.9% / 58.2%（gate 85%）；p10 0.2358 / 0.2965（gate 0.55）；grid 级 boundary F1 / oracle 32.1% / 33.1%（gate 75%）；instruction-shuffle 降幅 0.1445 / 0.1259（gate 0.20）；`std(s_pred)/std(s*)` 中位 0.3863 / 0.4487（gate 0.60）。
> **通过的四项**：中心先验配对 Δ(hard-IoU) 及其 p（+0.038 / +0.057，p 1e-4）、global mask soft-IoU（0.99999，**全 1 平凡解**）、GT/generated context gap（0.019 / 0.038，两种上下文一样差）。
>
> **「边界清晰」明确否定**：grid 级 boundary F1 只到 oracle 的 **32.1% / 33.1%**，且最后 1000+ 步已无净进展（W01 4975 步全程仅 +0.029 而同期 median soft-IoU 上升 0.153 —— 增益全部来自面积/覆盖的标定；W02 末段 0.3492 @4000 → 0.3302 @4975）。
>
> **「指令依赖」部分成立、但只到尺度层级**：预测面积与 GT 面积的 Spearman 相关在真实指令下 0.665 / 0.691，换成**同图另一条真实指令**降到 0.188 / 0.150，去掉语言上下文降到 0.002 / −0.078（且场退化为近常数，`pred_std` 中位 0.016）——指令确实进入了模型。但在**面积均衡的同图配对**上，扣除零参数中心先验后的净 Δ 仅 **+0.0032（p = 0.460，W01）/ +0.0113（p = 0.028，W02）**：**扣掉面积以后，指令特异的空间指代≈0**。
>
> **结论的边界（必须一并写）**：
> 1. 只覆盖 8 臂中的 **2 臂**（`MC8-Joint × {Band, CBand12}`）。`MC16-Joint` / `MC16-SplitHead` / `MC16-DualCanvas` 共 6 臂**未跑**，因此 §5.2 原本要检验的两条假设——**canvas 分辨率/容量**、**冲突是否只发生在输出头**——**均未被检验**。本条不能写成「MetaCanvas 容量不足」。
> 2. 单 seed、单 lr、单 epoch；`max_grad_norm=1.0` 而实测 grad_norm 稳态 2.1–5.5（W01 前 1500 步 13–27），即**整个训练处于梯度裁剪区**，未做过 lr/clip 扫描。
> 3. `H_where` 只取最后一层；浅层未测（与 §2.4 发现三「词-视觉对齐在进 LLM 之前最强」直接相关）。
> 4. 主榜含 44% `winner_confidence = low`（D-B14 裁定保留）；normal-only 合规子集 median 为 0.5081 / 0.5406，**更低**，故该偏离不威胁本结论。
> 5. 判据按 amendment A-5 修订后的十行读；全程未产出任何 AUC。
> 6. `oracle` 表达上界不是瓶颈：逐图 oracle 天花板中位 0.965 / 0.976，`oracle_ceiling` 机制只解释 9–17% 的长尾。
>
> **可以据此写进论文的正面机制结论**：失败不是「读不出任何指令信息」，而是「**文本 hidden → 全局线性方向 w** 这条间接通路只承载得动目标的尺度，承载不了目标的身份与形状」；且 readout 表达力 ×12（Band→CBand12）在中位数上只买到 +0.005，证明瓶颈**在 readout 上游的映射**，不在读出函数族的表达力。

## 8. 对新方案立项的证据清单（可直接引用，均已独立复核）

**A. 现方案到底差多远（零参数归一化，全部落在未被优化的列上）**
1. 覆盖：模型只补上「零参数中心先验 → oracle」差距的 **6.7%（W01）/ 10.1%（W02）**（grid hard-IoU 中位，同支撑同 top-k）。
2. 形状：同一归一化下 **15.1% / 16.6%**（grid 边界 F1）。
3. **21.5% / 17.5%** 的 local 样本得分低于「整幅全 1」这个不看图不看指令的掩膜。
4. 十项 gate 过 4 项，过的四项分别是平凡解（global）、一致性（gt/gen gap）与被分层证伪的中心先验 Δ（§3.3）。

**B. 失败的机制指纹**
5. **形状列停在 oracle 的 32–33%**：grid 边界 F1 在 4975 步里 0.290 → 0.319（W01，同期 median +0.153，即增益全来自面积标定）/ 0.273 → 0.330（W02，末段 4000→4975 为 −0.019）；按各自斜率外推到 gate 要的 0.75 需 29 / 6.6 个 epoch。
6. **面积向均值收缩**：预测面积恒压在 0.53–0.61；GT 最小五分位过覆盖 2.55×，最大五分位欠覆盖 0.99×。
7. **readout ×12 无效**：Band → CBand12 中位 +0.005、形状 +0.012，只改善尾部（长尾 65 → 43）与 s 塌缩比例（33.5% → 3.5%）。
8. **表达上界不是瓶颈**：逐图 oracle 天花板中位 0.965 / 0.976；`oracle_ceiling` 只解释 9–17% 长尾、10–23% 深尾（阈值 0.7 provisional）。

**C. 指令条件性的真实起点（新方案不必从零开始）**
9. 指令**确实**进入模型，携带的是**尺度**：面积 Spearman 0.665/0.691（真实）→ 0.188/0.150（同图伙伴指令）→ 0.002/−0.078（无语言）。
10. 扣掉面积后**≈0**：面积均衡同图配对的中心先验校准 Δ = +0.0032（p 0.460）/ +0.0113（p 0.028）。
11. 场**不读颜色方向词**：antonym 翻转后 `|Δ(hard-IoU)|` 中位 0.0000、p90 0.004。
12. 无语言上下文时场退化为近常数（`pred_std` 中位 0.016），其 soft-IoU 中位 0.4092 = 全 1 平凡掩膜的 0.4103。

**D. 新方案必须自带的判据（否则会重蹈覆辙）**
13. **主判据用面积均衡的同图配对校准 Δ**，不要用 median soft-IoU——后者可以靠面积标定单独刷到 0.56 而形状毫无进展。
14. **中心先验必须逐几何类给**，整臂 Δ 会被「中心先验自己弱的类」拉成正的。
15. **三列缺一不可**（soft/hard-IoU + grid 边界 F1 + 中心先验），加 shuffled / fixed_phrase / irrelevant_words / antonym 四条控制——本次交付这一套是齐的，可以整体复用。
16. **预注册一次 lr/clip 扫描**（半天），否则「机制不匹配」与「优化不足」在新方案上同样分不开。

**E. 未被本次实验触及、因而不能在立项材料里当作已知的**
17. MC16 三种结构（容量 / SplitHead / DualCanvas）—— 6 臂全部未跑。
18. 浅层 `H_where` 读出 —— 从未测。
19. `active_primitive_bucket` 分层在 Where-B 侧为空（`evaluate.py` 未写），单活跃基元脆弱性在本阶段**零证据**。
