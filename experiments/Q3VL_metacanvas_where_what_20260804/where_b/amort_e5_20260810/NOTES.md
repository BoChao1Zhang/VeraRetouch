## 三、待主 agent 决策

### A.(高优先,阻塞 P3)P3 闭式投影层的修法

实测闭式 `logit` 域等权 ridge 比多起点全拟合低 **8.9-29.2 点**,而 P3 的预注册证伪阈值是 **3 点**。
即 **P3 按原规格开工,第一天就满足自己的证伪条件**。三个候选修法(都没自行采用):
1. 闭式层改用 GN 权重 `A^T Lambda A + eps I`(Lambda 取 amort_e1 REPORT 第 0 节口径),而非等权;
2. 闭式层的目标从 `logit(y_hat)` 改为 mask 域加权最小二乘;
3. 放弃闭式,改 1-2 步可微展开(仍可微,仍无需 GT)。

**本卡采用的保守默认是「照实报告、不改 P3 规格、等裁定」**,因此 P3 尚未提交。

### B. E5 双门都没触发,路线判定如何落账

登记判据是 `>=0.70 -> 精修问题` / `<=0.40 -> 从头预测`,实测 0.4478 落在空档。
本卡的建议读法(第 3.2 节)是**这个二分本身提错了**:解码-先验差分约 0 说明 w 空间不是战场。
需主 agent 确认是否接受「以 3.2 替代原二分」这一改判,还是坚持按 0.4478 落在空档记「未判定」。

### C. 是否补 cband12 档

本卡只跑 band。cband12 成本约 6 分钟(同管线换 readout)。**默认不跑,请裁定。**

### D. 中心先验是否进 P1 的输入通道

第 3.4 节实测中心先验在**每一个** area 档都不弱于相似度场。任务卡给 P1 规定的 dense 条件输入
只有「软化相似度场」。是否把零参数几何先验也并进去(代价约为零)属于设计变更,不自行拍板。
**保守默认:按任务卡原文只喂相似度场,并在 P1 里留一个消融行。**
