## 4. 本卡的保守默认(两可决策,留档不静默拍板)

| # | 决策点 | 采用 | 理由 |
|---|---|---|---|
| F1 | 训练规模 | S-train **20,000** | 文档 §3.6 写全量 ≈7 万;20k 是「六臂 + 单卡 2–5h」预算下的保守取值。**主 agent 2026-08-11 裁定 3:批准探针级 20k;若本探针过判据,全量臂再上 70k。探针数字不得当全量臂结果引用**——该约束已写进运行产物 `metrics.json::train.scale_deviation` |
| F2 | 条件用的名词来源 | **instruction** | 推理期 `<where>` 由模型自生成故可用,但探针里 GT `<where>` 是标签,用它建条件会高估。instruction 零泄漏 |
| F3 | `c*` 求解分辨率 | 半分辨率 | 本次运行 n=32 复测:全分辨率−半分辨率 soft-IoU 差均值 8.6e-5、最大 2.4e-4;提速 3.7× |
| F4 | $\Lambda$ 的 $\|A\|^2$ | **整臂常量 256.0** | 取自 Gate 0 case B 实测 `eig_max` 中位。用逐图 $\|A\|^2$ 会引入逐图归一化(纪律灰区),整臂常量规避 |

| F7 | 中心先验如何评 | **直接在网格上评,不穿 $A_I$ 往返** | 穿算子往返会把边缘吸附借给基线,使这条强制基线变成与其它卡不同的对象 |

## 5. 实现中修掉的两个自身 bug(记录)

1. **`collect_posterior` 静默丢样本**:批次跨两种网格形状时,原实现只保留第一个样本、
   **丢弃其余**,判据 7(家族模式召回)与判据 9(c 空间 TARP)因此跑在被截断且形状有偏的
   子集上(pilot 实测 24 个样本只进了 10 个)。改为**按形状分组迭代**,复测 24/24 全进。
2. **采样器逐 K 串行**:K=16 条轨迹逐条跑,小张量下墙钟被 kernel 启动次数支配,
   评测阶段慢约一个数量级。改为 K×B 一次成批,pilot 从 >5 min 降到 195 s。

另:`pkill -f "run_fafm_probe"` 匹配到**正在执行它的那条 shell 自己**,返回 `exit 144`
(CLAUDE.md D-20 记载的同一根因,本轮第五次表面形态)。已改为 `ps` 取 PID 后按 PID kill。

## 6. 预注册判据(结果到达前锁定,不得事后改)

九条判据与 CFG 选择规则逐条照搬文档 §3.6,已写死在
`q3vl/whereb/scripts/run_fafm_probe.py` 常量与 `criteria` 段:

1 vs 中心先验 Δ≥+0.05 p<0.01(证伪 <+0.03)｜2 vs 回归直出 Δ≥+0.03 且回归面积比 >1.2 而 FAFM ∈[0.85,1.15]
｜3 面积 $W_1$(A) ≤ 0.5 $W_1$(C)｜4 指令条件性:对三条负控制配对差分均 >0 且 p<0.01
｜5 grid 边界 F1 ≥ 中心先验,语义族 ≥ +0.10｜6 分家族每族 ≥ 中心先验｜7 家族模式召回 ≥70%
｜8 步数-多样性曲线(记录性)｜9 c 空间 TARP 最大偏离 ≤0.10。
**CFG 规则**:$g\in\{1,1.5,2\}$,在通过 #3 的档位中取 #4 最大者;全不过 #3 则 $g=1$。

**判据 2 是双案共用裁决**:它同时是方案 A 的 E5(同条件同潜空间下,分布估计 vs 条件均值回归)。

**判据 6 的读法(主 agent 2026-08-11 裁定 1,强制)**:**通过线不收紧**——预注册门在出数后不改,
该纪律双向适用。但每个家族必须**以它自己的 Gate 0 天花板为分母**读,并把**颈部税单列**:

| family | Gate 0 天花板 | 颈部税 |
|---|---|---|
| linear | 0.9990 | 0.0010 |
| band | 0.9971 | 0.0029 |
| radial | 0.9937 | 0.0063 |
| **semantic** | **0.8949** | **0.1051** |

semantic 若误用全体天花板 0.9967 当分母,等于把冻结算子在模型介入之前就收走的 0.1051
记到模型头上——**把天花板误读成失败**。已写死进 `run_fafm_probe.py::GATE0_FAMILY_CEILING`,
输出列为 `frac_of_ceiling` 与 `neck_tax`。

## 9. 与 P1 / P3' 的交叉复验(主 agent 2026-08-11 指示)

Gate 0 得到的**最强单一发现**是:**瓶颈是「用什么坐标表示形状」,不是冻结算子、也不是粗分辨率**。
同一批 semantic 样本、同一个 $U_I$、同一 H/16 网格,只换粗场来源:

| 粗场来源 | semantic 上界 |
|---|---|
| 自由岭解 $c^*$(B 案颈部) | **0.8949** |
| 完整潜码多起点 L2(A71p) | 0.7790 |
| Ncut 段子集 OR(C 案) | 0.5812 |
| 71 维码多起点 L2(A71) | 0.5863 |
| 71 维码经 $C_\varepsilon$(A71 判据档) | 0.5279 |

**另一 agent 的 P1 / P3' 双臂是这条发现的独立复验**,且方向完全同构:

- **P3'(网络直出场 → 直接 guided upsample,完全不经 Phi)** ≈ 本卡的「自由粗场」一侧;
- **P1(网络出 w ∈ R^71 → 穿 D 渲染,输出空间损失)** ≈ 本卡的「71 维码」一侧。

本卡是**零训练的表达力上界**测量,P1/P3' 是**同一对表示在可学条件下的实测**。
两者的自变量相同(自由场坐标 vs 71 维低维码),因变量都按分家族 soft-IoU 报,
所以**分家族结果可以直接对表**:

- 若 P3' 的 semantic 档显著高于 P1,则本卡的上界排序在可学设定下**被独立复现**,
  「表示选择是瓶颈」从上界命题升级为端到端命题;
- 若两臂 semantic 档接近,则说明**可学性而非表达力**才是当前的实际限制,
  本卡的上界差距在 20k/探针规模下尚未成为约束——这会同时改写 B 案全量臂的优先级论证。

**读明早结果时两处对表**:本卡 `metrics.json::criteria.6_per_family`(带 `frac_of_ceiling`)
对 P1/P3' 各自 REPORT 的分家族表。注意两侧口径差异:本卡是上界(无训练、知道 GT),
P1/P3' 是真实预测——**不可直接比绝对值,只比「同一表示在两侧的相对排序是否一致」**。
