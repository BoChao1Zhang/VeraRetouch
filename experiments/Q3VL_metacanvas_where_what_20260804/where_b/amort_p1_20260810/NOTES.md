## 2. semantic `.cgt` 是真轮廓,不是椭圆近似

**定量检验**(比肉眼可靠):对每个二值化掩膜拟合**矩匹配椭圆**(同质心、同二阶矩、**同面积**),
报 IoU(掩膜, 拟合椭圆)。radial/band 本来就是按椭圆生成的,是**阳性对照**,必须接近 1。

| family | n | **IoU vs 拟合椭圆** | 软边带占比 | 面积中位 |
|---|---|---|---|---|
| radial | 100 | **0.9899** | 0.257 | 0.290 |
| linear | 111 | 0.9028 | 0.867 | 0.730 |
| band | 108 | 0.8844 | 0.232 | 0.511 |
| **semantic** | **80** | **0.6983** | **0.0476** | 0.169 |

- 阳性对照成立(radial 0.990);
- **semantic 比 radial 低 29 个点**,且**软边带只有 4.8%**(几何族 23–87%),面积也最小(0.169);
- 机制侧印证:`canonical_masks.py:79-87` 的 `_semantic_alpha` = 对**硬实例掩膜**做高斯模糊后
  **再乘回硬掩膜**,所以它是被约束在实例轮廓内的软边silhouette;而 radial/band 是
  `subject_geom.py` 用实例掩膜的 PCA 主轴生成的**椭圆**,linear 只用 bbox 生成斜坡。

**结论:语义头可以直接用 `.cgt` 当监督,不需要 SAM3 伪标签改道。**
可视化 20 张在 `viz_masktype/semantic_*.png`(三联:原图 / `.cgt` alpha 固定 0..1 色标 /
0.05-0.50-0.95 等值线)。抽检样例呈现清晰的动物四肢与尾巴轮廓,等值线三线近乎同心且贴合。

**同时这条也正面支持「放弃共享主干」的裁定**:几何族是大支撑、宽软边的平滑场
(面积 0.29–0.73、软边 23–87%),semantic 是小支撑、锐边的 silhouette(面积 0.17、软边 4.8%)。
两者的梯度需求确实相反。

## 3. 零训练类型词路由的可行性(`<where>` 文本)

**规则如何来的(反过拟合纪律)**:关键词表由 **GT** `edit scope:` 子句按
「族内出现率 − 族外出现率」的 lift 导出,**冻结后**原样套到**模型生成文本**上。
禁止用预测文本调表(那是「枚举到阳性」)。表见 `where_typeword_router.json:keywords`。
最强的几个:radial `oval` (0.84/0.00)、`falloff` (0.80/0.00);linear `toward` (0.93/0.00)、
`spanning` (0.75/0.00);band `both` (0.91/0.00)、`edges` (0.77/0.00);
semantic `within` (0.91/0.00)、`stays` (0.91/0.00)。

### 判读(这是本节的要点)

1. **架构真正需要的那个决策是「语义 vs 几何」二分,而它在生成文本上是 396/396 = 100.0%**:
   semantic 列除了 77 个真 semantic 之外**一个误入都没有**,semantic 行也**一个漏出都没有**。
2. **74.2% 的四分误差全部发生在三个几何族内部**(radial↔linear↔band 互串)。
   而按已裁定的架构,**三个几何族共用同一条几何路径** —— 这类误差对路由**不产生后果**。
3. **这与 DELTA §七「local 逐字一致 0/30」的降级不矛盾,而是正交**:逐字复现是极高的 bar,
   **类型词是极低的 bar**,实测差距正是如此(0/30 逐字 vs 100% 类型二分)。
   主 agent 的假设(「类型级可能远高于逐字」)**被证实,且比预期更强**。

**结论:零训练类型词规则路由对二分完全够用,可以直接起步**;GT `mask_type` teacher-forcing
与软路由兜底仍建议保留,但按本数据它们是保险而非必需。

## 7.2 换主体配对项的裁定(取代已撤回的 antonym 损失)

## 7.3 P3' 的依据(为什么砍掉闭式投影、改直出场)

- **E5 §3.3**:闭式 `logit` 域等权 ridge 投影相对多起点全拟合落差 **8.9–29.2 点**,
  而 P3 的预注册证伪阈值是 **3 点** —— **零训练、输入是良性场的条件下就已触发**。
  最刺眼的一档是中心先验:Phi-71 前 5 列(geo5)本可精确表达的几何场,闭式只还原到 0.2248,
  全拟合能到 0.5163。故退化不是「场落在 D 值域外」,而是**等权 logit 最小二乘与 soft-IoU 度量失配**。
- **E2**:凸化(Tikhonov)与 oracle 天花板结构性绑定,**修权重/换域是在死路上优化** ——
  这是主 agent 不采纳「①带 GN 权重 ②改 mask 域 ③展开」三个修法的理由。
- **E5 §3.2**:D 本身**不是**瓶颈(解码−先验配对 Δ = +0.005/0.000/0.000,拟合对先验 IoU 0.92–0.98)。
- **⇒ P3' 定义**:网络**直出 ŷ(H/16)→ 直接 guided upsample 到交付分辨率,完全不经 Phi**。
  与 P1(网络出 w → D 渲染,输出空间损失,网络自己找盆地,YOLACT 模式)构成 A/B,
  **判别 Phi 中间层在前馈链路里是资产还是负债**。
  「1–2 步可微展开拟合」记为 P1 的**可选变体**,不单独立臂。
- **P2 缓行**,排在 P1/P3' 结果之后(E5 §3.2 精修对象无信息可挖 + §3.5 最好零训练 w₀ 0.5163
  低于 W01 现有 0.550,两条独立理由)。

## 7.4 **训练缓存前提:75k 训练图的 F_pre / 相似度场缓存不存在**(实现前必读)

E1 只缓存了 **V_where 的 400 图**(`/home/bc/data/runs/where_b/amort_cache_20260810`,879 MB)。
**train 的 75,544 条 local 没有任何缓存。** 两件事必须分开看,否则会做无用功:

| 需要的东西 | 训练期现状 | 结论 |
|---|---|---|
| **F_pre**(H/16, 1024) | `FrozenVLM.encode` **每 batch 现算**(`hiddens.py:157`,`EncodeResult.f_pre`) | **不是阻塞项**,任何 split 都拿得到,无需缓存 |
| **merger 输出**(H/32, 2560) | **没有任何 hook 捕获它** —— `EncodeResult` 只有 `f_pre` 与 `h_where`;`FPreHook` 挂在**最后一个 vision block(merger 之前)** | **这是真正的缺口**。相似度场(P1 的唯一已证空间条件通路)依赖它 |

**正确修法(推荐)**:在**同一次前向**里给 merger 再挂一个 hook,与 `FPreHook` 并列。
merger 输出本来就在这次前向里被算出来(它就是喂给 LLM 的 image embedding),只是没被捕获 ——
所以**不需要第二次视觉前向,符合 protocol 2.3**。改动落在 `q3vl/whereb/hiddens.py`
(`EncodeResult` 加一个字段 + `FrozenVLM.encode` 加一个 hook)。

**不要走预计算缓存那条路**:按 E1 缓存的实测密度(879 MB / 400 = **2.2 MB/样本**),
75,544 条约 **166 GB**,且要多跑一遍视觉塔。相对「加一个 hook」毫无收益。

**名词 embedding** 侧无缺口:`run_amort_e5.py::load_embeddings` 已实现从 safetensors 直读
`model.language_model.embed_tokens.weight`(CPU,`tie_word_embeddings=True` 已核实);
主体名词解析复用 `run_pw5_fpresim.py::subject_nouns`(V_where 400/400 解析成功)。

**mask_type GT 标签**同理不需要缓存:`MaskResolver(suffix=".vrmeta.json")` → `slot_id`,
全量 75,544 条现取 **1.2 分钟**(48 线程)。见 §1 首段与 §5-A。

## 7.5 风险节:符号规范化的活跃翻转边界(第 0 项新发现)

`w_dir` 的符号规范化以「绝对值最大系数为正」为轴。当前两大系数接近时该轴是掷硬币:
**3.92%** 的 train 目标坐在「间距<1.05 **且** 次大系数反号」的活跃翻转边界上
(放宽到间距<1.20 为 **13.9%**)。这些样本上输入的无穷小扰动会翻转全部 71 维目标符号,
使 `L_dir = 1 − cos` 从 0 跳到 2。

- **P1/P3' 的监督全在输出空间,mask 对该翻转天然不变 ⇒ 自动免疫,无需处理。**
- **但若日后加入任何 w 空间辅助项(如 `L_dir`),必须先排除这批样本**,或改用符号不变形式
  `1 − |cos|`。证据与普查代码:`amort_e2_20260810/config/item0_wdir_canon_audit.json`、
  `q3vl/whereb/scripts/check_wdir_canon.py`。
- 附带已核实的阴性结论:符号规范化在 oracle 写入侧与训练读取侧**逐字一致**
  (train 75,544 + 75,543 + V_where 400,三项检查 100%,最大偏差 5.55e-16),**不是病因**。
