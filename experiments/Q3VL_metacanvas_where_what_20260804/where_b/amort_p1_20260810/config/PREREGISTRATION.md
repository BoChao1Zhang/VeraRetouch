## 0. 这一对臂要回答的问题

**Phi-71 中间层在前馈链路里是资产还是负债？**

E5 已证 Phi-71 **不是瓶颈**（把任何场交给它，解码−先验配对 Δ = +0.005/0.000/0.000，
拟合对先验 IoU 0.92–0.98）。但「能忠实复现别人给的场」与「帮不帮一个必须**自己产生**场的
网络」是两件事，后者从未测过。P1 走 `w(71) → D`，P3' 完全不经 Phi，其余（数据、条件、loss、
判据、预算）逐项相同 ⇒ 差异只能归因于这一层。

## 1. 口径（先钉死，避免事后换算）

**主列 = matched-area top-k IoU**，且 **population = normal-only**
（`winner_confidence == "normal"`）。

**口径修订（2026-08-11，实现审阅 U7）**：CLAUDE.md 数据纪律规定 `low` **不进评测 GT**，
而 V_where local 里 **176/400 = 44.0% 是 low**。low 层 GT 面积更大 ⇒ 随机地板更高 ⇒
**每一个 IoU 列都被系统性抬高**。此前全项目引用的都是 pooled 数，必须按 normal-only 重算：

| 参照 | pooled（此前引用） | **normal-only（本卡口径）** | 来源 |
|---|---|---|---|
| 随机地板 `a/(2−a)` | 0.2582 | **0.2254** | 本次由原始掩膜复算 |
| 中心先验（零参数） | 0.5088 | **0.4853** | 同上（W01 自带列 0.4857，互校差 4e-4） |
| 中心先验 grid 边界 F1 | 0.1994 | **0.2276** | 同上 |
| **W01（generated，部署档）** | 0.5333 | **0.4874** | W01 `per_sample.jsonl` 回接 manifest |
| **W01（gt）** | 0.5500 | **0.5109** | 同上 |
| oracle 天花板 | 0.9737 | 未重算 | E5（pooled） |

pooled 数复算与 E5 发布值**逐位一致**（0.5088 / 0.2582 / 0.1994），故差异纯粹来自口径而非实现。

> **这条修订本身改变了病灶的量级**：E3 的「gt 只比中心先验高 +0.033」是 pooled 口径；
> normal-only 下 **W01(generated) 0.4874 vs 中心先验 0.4857 = 仅 +0.0017**，
> gt 档也只有 +0.0252。**现役头相对零参数先验的优势基本为零**，比 E3 的叙述更严重。

裸 soft-IoU 是**另一个量**（同一中心先验场 pooled 为 0.4548），并列上报为 `soft_iou_raw`，
**不得替代主列**。

## 2. 预注册判据

### 2.1 硬门（checkpoint 选择的前置，三条全过才可选）

| 门 | 阈值 |
|---|---|
| 面积比中位 `pred_area / gt_area` | **∈ [0.8, 1.5]** |
| 换主体配对差分 `Δ_shuffle` | **> 0** |
| antonym 不变性 `|Δ|` | **≤ 0.05**（只报不训） |

选优量 = **median top-k IoU**（local）。**禁用 val loss**（红线）。

### 2.2 晋级判据（E3 交出的可直接复用的证伪列）

**若训练后 `corr(输出, 中心先验) > corr(输出, GT)` 仍成立 ⇒ 该臂与 W01/W02 同病，不得晋级。**
（NOTES §7.1 登记；W01/W02 实测 0.643/0.608 vs 0.469/0.525。）

### 2.3 有意义的门槛（本卡自设，写在前面）

（全部 normal-only 口径）

| 档 | 含义 |
|---|---|
| top-k IoU 中位 **≤ 0.4853** | 打不过零参数中心先验 ⇒ **本处方失败**，与 W01/W02 同类 |
| **0.4853 < x ≤ 0.4874** | 赢了中心先验但没赢现役失败头（两者只差 0.002，实际是同一档） |
| **> 0.4874** | 超过 W01(generated) ⇒ 路线成立 |
| **> 0.5109** | 超过 W01(gt) ⇒ 更强的成立 |
| 关键辅助列 | 与中心先验的**配对 Δ 及 p 值**必须并排；单看绝对值不算数 |

> normal-only 下 W01(generated) 相对中心先验只有 **+0.0017**。
> 因此**本卡真正要看的不是绝对值，而是 `Δ vs 中心先验` 能否显著为正**——
> 这个门槛比 pooled 口径下的 +0.033 更低，但也更诚实：它不再被 low 层的地板抬升掩盖。

### 2.4 A/B 判读（P1 vs P3'）

- 两臂同 seed、同数据、同 loss、**同步数**（`--max-steps` 相同；审阅 U4：
  等墙钟 ≠ 等训练量，P1 多一段 float32 `predict_fields`，同墙钟下步数更少且停在
  cosine 调度的更早位置，会把吞吐差异混进「Phi 是资产还是负债」的结论）；
  墙钟仅作兜底，`steps_trained` 两臂不等即**不得直接比较**；
- 判据 = 两臂 median top-k IoU 的**同图配对差分** + p 值；
- **Phi 是负债** ⇒ P3' 显著高于 P1；**Phi 是资产** ⇒ P1 显著高于 P3'；
- 差分不显著 ⇒ 结论是「该层在前馈链路里既不帮也不拖」，**这也是一个可交付结论**，
  且直接决定 What 侧要不要继续维护 `(w*, ρ*)` 这条 latent 接口。

### 2.5 强制并排列（每一行都必须带，缺一即判据不完整）

中心先验列 ｜ 随机地板 `a/(2−a)` 列 ｜ area 分层（<0.15 / 0.15–0.30 / 0.30–0.45 / ≥0.45）
｜ mask_type 分层 ｜ 换主体配对差分 ｜ antonym 不变性 ｜ `corr(中心先验)` vs `corr(GT)` 配对差

**area ≥ 0.45 档单列**：占 V_where 的 47.3%，随机地板已 0.527，可判别区间仅 ~0.10 宽
（E1 审阅 R5 + E5 §3.4 两次独立复现）。**该档的高分不构成任何主张。**

**area < 0.15 档是专门监控分层**：E5 实测这是唯一「各方法差距判据能看见、且当前全体方法都失败」
的区间（相似度场 0.042 / 0.007，低于随机地板 0.043）。

### 2.6 语义头（m_sem，一等交付）

- semantic 子集（V_where local 占 20.1%）**单列**：top-k IoU / 边界 F1 / 中心先验 / 随机地板；
- 路由混淆矩阵（family × head）实测上报，**不假设 100%**——NOTES §3 的 396/396 是在

## 3. 预注册的失败画像（先写下来，免得事后合理化）

1. **过覆盖中心团**：面积比 > 1.5、`corr(中心先验)` 高、换主体 Δ→0 ⇒ 与 W01/W02 同病；
2. **塌缩到空**：面积比 < 0.8 且持续下降 ⇒ 假指令零掩膜项权重过大（`w.fake=0.20` 需下调）；
3. **只在大目标上得分**：≥0.45 档好看、<0.15 档在地板 ⇒ 与 E5 的相似度场同病，
   说明头学到的是「编辑衰减区的平均形状」而不是定位；
4. **分离项打不动**：`Δ_shuffle` 不随训练上升 ⇒ 三元组 margin 形式无效，
   需改为双前向的真配对（成本翻倍），记为下一轮。
