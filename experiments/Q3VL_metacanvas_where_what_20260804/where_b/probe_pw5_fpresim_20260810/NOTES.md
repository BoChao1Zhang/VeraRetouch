## 三、决策(保守默认)

| # | 决策 | 取值 | 理由 |
|---|---|---|---|
| P1 | 名词解析 | `subject:` 从句 → 逗号/and 切分 → 去固定停用词 → 取**中心词**(英语 NP 中心在后) | `<where>` 有极规整的 `subject: …; edit scope: …` 结构,不需要 POS tagger。**刻意不用可调抽取器**:query 侧的可调旋钮就是「枚举到出阳性」的路径 |
| P2 | 多 token 词 | 均值池化 | 292 个主体名词里 39 个是多 token。逐词 token 数已落盘,可复核 |
| P3 | 目标名词取哪个 | `subject:` 的**第一个**中心词 | 多主体样本(如「教堂、树木、山坡房屋」)取第一个,不做「选最像的那个」——那是事后挑选 |
| P4 | 对照词 | ①跨图真实主体名词(同分布,**最强**)②无关名词表 | 只用无关词会让 Δ 被「词频/常见度」而非「指代」解释;跨图对照与目标同分布,把这条解释关掉 |
| P5 | 两种基底读法 | `dot` 与 `cosine` 并排,**不指定哪个正确** | PROPOSAL §4 原卡明令「各自诚实标注」。见 REPORT §1 的基底错配说明 |
| P6 | 离群格 | 全格 / 剔高范数离群格两版并排,沿用 E1 的 median+3·MAD | 与 E1 同一常量,两臂不漂移 |

## 四、待主 agent 决策

### A. 基底错配无法在本卡内解决(结构性)

merger 输出住 LLM **输入**空间,unembedding 正常作用于**输出**空间。tied 矩阵让二者共用一个矩阵,
不让它们成为同一空间。本卡只能给「用 tied 矩阵在输入空间做近似」这一个读数,**它是 C 案规格本身
写的那个基底**,所以对 C 的可行性判断有效;但它**不是** RO-2 当年那条 logit-lens 通路的严格复现。
