## 要验证的结论

如果这个实验成功,我们就能说 **merger 输出(2560 维,H/32 —— 即方案 C 打算打分的那个基底)上,
`<where>` 名词与图像格的相似度带有词特异的空间定位信息**;失败就不能说这句话,也就不能假定
方案 C 的零训练打分段有可用的落点。

## 为什么需要验证它

**这是方案 C 自己的 P0,不是 E1 死后的安慰奖。** PROPOSAL §7 的切换条件写明,C 修复版的前提是
「零训练段的打分基底显式改为 merger 输出(2560 维,H/32)或 W_v 投影后空间」,并且「若 P-W5 旁通道
已存活,其数据直接入 C 修复版的 P0」。不跑它就切 C,等于对着 C 唯一的可行性读数闭着眼睛开工。
它同时是本战役唯一**预先收集好**的第二读出源 —— E1 只证伪了 attention 一条通路。

## 怎么验的

V_where 400 条 local 样本,每张过一次**视觉塔 + merger**(无需 LLM 前向,24 秒跑完全集),得到
每格 2560 维;与 `<where>` 的 `subject:` 从句解析出的**目标名词** embedding 做相似度,得空间场;
用面积匹配 top-k 的 grid soft-IoU 打分,并与**同图内**的两种对照词(另一张图的真实主体名词 /
无关名词)做配对差分,同时并排中心先验列与 `a/(2−a)` 随机地板列。

## 1. 设置

| 项 | 值 |
|---|---|
| 基底 | `model.model.get_image_features()` 的 **merger 输出**(2560 维,H/32 网格)——LLM 实际收到的那个张量 |
| 词向量 | `get_input_embeddings().weight`(151936×2560);**实测 `tie_word_embeddings=True`**,故它同时是 unembedding |
| 名词解析 | `<where>` 的 `subject:` 从句 → 逗号/and 切分 → 去停用词 → 取**中心词**(英语 NP 中心在后)。400/400 样本解析成功,得 292 个不同主体名词 |
| 多 token 词 | 均值池化,逐词记录在 `metrics.json:multi_token_words` |
| 对照词 | ①**跨图对照**(另一张图的真实主体名词,同分布、无指代——最强对照)②无关名词表(keyboard/volcano/…) |
| 支撑 | 两版并排:全格 / 剔除高范数离群格(Registers 2309.16588 配方,同 E1 的 median+3·MAD) |
| 成本 | 400 样本 **24 秒**,无需 LLM 前向 |

### 基底错配的诚实标注(按 PROPOSAL §4 原卡要求)

merger 输出住在 LLM 的**输入**空间,而 unembedding 通常作用于**过完 36 层 + final norm 的输出**
状态。`tie_word_embeddings` 让两者共用**一个矩阵**,但**不**让它们成为**同一个空间**。因此两种读法
并排给出,**不指定哪个是正确的**:

- `dot` —— 原始 `merger_out · E[noun]`(logit-lens 读法);
- `cosine` —— 两侧各自长度归一(表征相似度读法)。

n=400,配对检验为**同图内** target vs control。

|---|---|---|---|---|---|---|---|---|
| 全格 | `dot` | 0.3410 | 0.3026 | 0.2761 | **+0.0211** | 1.4e-07 | +0.0316 | 4.7e-13 |

## 2b. 可视化(8 张,`viz/`)

六联:输入 / GT(merged grid)/ **目标名词相似度场** / **同图对照词场(共用色标)** / 目标 top-k vs GT /
中心先验 top-k。色标只取有效格,叠图走 `viz.grid_to_img` 严格逆映射,两个相似度联**共用色标**
(E1 审阅 N4)。

**`success_sft_f22c9651`(枯树 + 星轨,16×24)是本卡最有信息量的一张,它同时展示了信号与问题**:
目标名词 `tree` 的相似度场**准确地亮在树上**(树干与枝条的格清晰点亮),对照词 `deck` 的场没有
任何对应结构 —— 目标 0.445 vs 对照 0.106。**词特异定位在这张图上是肉眼可见的、毫不含糊的。**
但中心先验仍以 0.541 胜出。

**原因值得单独记一条,它不是本卡的缺陷而是任务口径的问题**:本战役的 GT 不是**物体掩膜**,而是
**编辑衰减区**(该样本 GT 是一个覆盖画幅大半、以主体为中心的柔和椭圆 falloff)。相似度通道找到的是
**物体**,判据要的是**编辑区**。两者在大面积柔和 falloff 样本上系统性错位 —— 这正是随机地板
0.257、中心先验 0.459 都能跑赢一个「真的找到了树」的场的机制。

> **这条对 C 案是关键情报**:C 若要用这个基底,**要么**改判据口径(把物体定位与编辑衰减区解耦,
> 例如让空间头只出物体先验、由 Phi/falloff 段负责衰减形状),**要么**接受它在 falloff 类样本上
> 结构性打不过中心先验。**继续用现口径直接开 C,会重演 E1 的失败画像。**

## 3. 结论

1. **词特异定位信号在 merger 基底上确实存在,统计上很扎实**(Δ=+0.021,p=1.4e-07,四读法一致,
   且最强对照是同分布的跨图真实主体名词)。**这是本战役第一次在非 attention 通路上拿到方向明确、
   带同图配对与随机地板的词特异证据。**
2. **但它的量级远不足以支撑一个交付级定位头**。词特异性只占 +0.021,而该场整体要追平一个零参数
   中心先验还差 **0.118** —— 缺口是词特异信号本身的 **5.6 倍**。换言之:这条通路里「哪个词」是
   可读的,「这个词在哪」基本靠不住。
3. **与 E1 的图像高度一致,机制相同**:两条通路都表现为「真实但极小的语义特异性 + 被几何先验完全
   支配的绝对定位」。E1 的 attention 通路 Δ_shuffle=+0.012(分离子集,p=0.004),本卡的相似度通路
   词特异 Δ=+0.021 —— **同一数量级**。这不像两条独立通路各自失败,更像一个共同上限。
4. **词特异性是真的,但被判据口径吃掉了一部分**(见 §2b):相似度场找到的是**物体**,判据要的是
   **编辑衰减区**;在大面积柔和 falloff 样本上二者系统错位。这意味着 +0.021 是词特异信号强度的
   **下界**,而不是它的全部 —— 但也意味着**在现判据口径下**,这部分信号拿不到分。
5. **对方案 C 的读数(本卡的真正用途)**:C 的零训练打分段**有信号可打,但打不过中心先验**。
   若 C 按现规格开工,它的空间头将从一个比中心先验弱 0.118 的基底出发 —— 且按 E1 审阅 R5 的发现,
   **C 会在 area≥0.45 的那半样本上因为与 C 无关的原因(随机地板 0.527 高于任何被测场)显得失败**。

**判据完整性**:无任何 AUC;词特异 Δ 为同图内配对(未退化为池化排序);中心先验列与随机地板列
均已并排。本卡**无否决权**,以上为情报读数。

---

## 4. 建议下一步

1. **C 案开工前必须先重设判据,而不是先写代码**。E1 审阅 R5 已证明现行 P2 门槛(+0.10)在
   area≥0.45 的一半样本上算术不可达;本卡进一步显示 C 的基底起点比中心先验低 0.118。
   **建议:所有后续臂的判据表必须按 area 分层,并强制并排 `a/(2−a)` 随机地板列。**
2. **若仍要推进 C,建议先做一次「词特异性上探」而不是直接开训**:本卡用的是零训练的原始相似度;
   在 merger 输出上加一个小的可学投影(把词向量投到视觉侧,而不是硬拿 tied 矩阵当桥)可能把
   +0.021 放大,这是 C 唯一有据可依的杠杆。**在没有这个上探数字之前,不建议开 C 的全量臂。**
3. **基底错配值得单独一测**:本卡只能用 tied 矩阵在 LLM 输入空间做近似。若做上探,应同时测
   `W_v 投影后空间`(PROPOSAL §7 并列的另一个候选),两者哪个更适合打分目前**没有数据**。
