## 要验证的结论
如果这个实验成功,我们就能说方案 B 的**颈部构造成立**——冻结引导上采样 $U_I$ 对信号严格线性(于是 $c^*=(A_I^\top A_I+\varepsilon I)^{-1}A_I^\top y$ 是闭式唯一解、条件数由 $\varepsilon$ 显式封顶),且 H/16 粗场经该算子渲染回全分辨率后保得住 GT 场(整体中位 soft-IoU ≥0.93、每家族含语义轮廓 ≥0.88);失败就不能说粗场颈部够用,必须回退全分辨率场扩散(DPF 路线)。

## 为什么需要验证它
方案 B 全部闭式主张都挂在这两件事上:线性性 H1 撑起 $c^*$、$\Lambda$ 度量与谱界(即论文主张「我们构造性地废掉了 $8\times10^5$ 的病态目标」),颈部上界撑起「粗场表达力不低于经 $\varepsilon I$ 投影的 $D$」。不做等于把三 lens 一致评为 best 的方案押在两个没测过的前提上;审稿人会直接问「guided filter 的系数依赖被滤信号吗」「32×32 装得下语义轮廓吗」——正是 G0a/G0b。

## 怎么验的
零训练零模型前向。G0a:S-train local 随机 256 图,各画两组随机粗场(均匀 [0,1] 档与零均值高斯档),测相对叠加残差,并用 $\langle Ac,r\rangle=\langle c,A^\top r\rangle$ 断言伴随实现。G0b:同 seed 抽 S-train local 1000 图,显式构造 $A_I^\top A_I$(1536×1536,把单位阵推过算子)→ 精确 Cholesky 解 $c^*$ → 渲染 $\mathrm{clip}(A_Ic^*,0,1)$ → 与 GT 比;$\varepsilon$ 扫 {1e-4,1e-3,1e-2},家族标签取自 `.vrmeta.json` 的 `slot_id`。

## 2. 预注册判据 vs 实测

### G0a 线性性(H1)

| 判据 | 预注册通过线 | 实测 | 判读 |
|---|---|---|---|
| 相对叠加残差中位(四档最差) | ≤ **1%** | **4.67e-16** | **PASS**,超出 13 个数量级 |
| ├ 均匀 [0,1] 档 | — | 2.29e-16(p90 3.13e-16) | |
| └ 高斯档(测抵消) | — | 4.67e-16(p90 6.46e-16) | |
| 伴随恒等式误差 | — | 1.19e-15(p90 8.04e-15) | 实现正确 |

$U_I$ **严格线性**,非近似线性。机理可解析论证:快速引导滤波系数 $a=(\overline{Ip}-\bar I\bar p)/(\mathrm{var}(I)+\epsilon)$、$b=\bar p-a\bar I$ 中每个含 $p$ 的项都对 $p$ 线性,而 $\mathrm{var}(I)$ 只含引导图,故 $q=\bar aI+\bar b$ 是 $p$ 的线性算子;$U_I(0)=0$ 实测恒为 0(纯线性无仿射项)。**文档预备的「固定引导线性化 $A_I$」后备路径无需启用**,§3.2 相应的线性化代价核算可删。

### $\varepsilon$ 敏感性与谱

| $\varepsilon$ | 全体 soft-IoU 中位 | $\mathrm{cond}=(\sigma^2_{\max}+\varepsilon)/(\sigma^2_{\min}+\varepsilon)$ 中位 |
|---|---|---|
| 1e-4 | 0.9967 | 2.47e6 |
| **1e-3(主)** | **0.9967** | **2.56e5** |
| 1e-2 | 0.9965 | 2.56e4 |
| 未正则 | — | 4.63e7(`eig_min` 中位 6.06e-6,`eig_max` 中位 256.0) |

**这是方案 B 对约束 2 核心主张的直接数字**:未正则条件数中位 4.6e7,而 $\varepsilon$ 确实按 $\sigma^2_{\max}/\varepsilon$ 封顶——$\varepsilon=10^{-3}$ 压到 2.56e5(低于杀死 $x\mapsto w^*$ 的 $8\times10^5$),$10^{-2}$ 压到 2.56e4,**而重建上界几乎不动(0.9967→0.9965)**。「换坐标系让病态构造性消失」不再是论证,是实测。

**消费建议(整臂常量,禁逐图)**:$c^*$ **不住在 [0,1]**,超四成格在 [0,1] 之外。任何按「它是掩膜所以夹到 [0,1]」处理 $c$ 的下游会**静默**毁掉岭解——正是契约第二种失败模式(值仍在锚点域内、孤儿检查全程沉默、但轴已经没了)。渲染必须写成 $\mathrm{clip}(A_Ic,0,1)$:**clip 场,永不 clip 坐标**。B 案探针臂读 scache 必须显式断言该域。

## 4. 结论

1. **G0a PASS,且是最强形式**:$U_I$ 严格线性(4.7e-16),H1 成立,后备线性化路径可永久删除。
2. **G0b PASS**:整体 0.9967 远超 0.93;三个几何家族 0.993–0.999。
3. **唯一吃紧处是语义轮廓:0.8949,仅高于 0.88 线 0.015,p10 已掉到 0.7269**。判据按中位写、中位过线,按预注册**放行**;但这是方案 B 的天花板税,与「小面积档 0.9021」是同一批样本。文档 §3.7 把「粗场颈部对语义轮廓的上界」列为二号风险——**实测证实风险真实存在,只是未触证伪线**。
4. **$\varepsilon$ 不是敏感旋钮**:三档重建差 2e-4,条件数差两个数量级。可按条件数自由选 $\varepsilon$,不必担心买掉上界。
5. **方案 B 训练臂获准开启**,无需升 48/64 网格重测。

## 5. 建议下一步

1. **开 B 案 FAFM 探针训练臂**(六臂对照 + 九条预注册判据),粗场用原生 H/16,$\varepsilon=10^{-3}$,渲染 $\mathrm{clip}(A_Ic,0,1)$。
2. **判据 #6「分家族每个家族 A ≥ B」在 semantic 档要以本卡 0.8949 当天花板读**,不能用全体 0.9967,否则会把颈部税误记成模型失败。建议探针 REPORT 对每家族并排「天花板 / 实测 / 占天花板比例」。
3. **$c^*$ 值域断言进探针配置**(§3),训练管线断言生数据住在 [−48.96, +69.59]。
4. semantic 的 p10=0.727 单列监控;若探针 semantic 档明显低于其它家族的天花板达成比例,再考虑文档预告的局部 latent token 后备(Locality-Aware GINR / AROMA)。
