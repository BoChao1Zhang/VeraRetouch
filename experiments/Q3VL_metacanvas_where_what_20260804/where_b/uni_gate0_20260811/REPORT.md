## 三条跨案结论(比单案判读更有价值)

**1. 限制不在冻结算子 $U_I$,也不在粗分辨率,而在「用什么坐标表示形状」。**
同一批语义轮廓样本、同一个 $U_I$、同一个 H/16 粗网格,只换粗场的来源:

| 粗场来源 | semantic 上界 |
|---|---|
| **自由岭解 $c^*$(B)** | **0.8949** |
| 完整潜码多起点 L2(A71p 上界) | 0.7790 |
| Ncut 段子集 OR(C,oracle 选择) | 0.5812 |
| 71 维码多起点 L2(A71 上界) | 0.5863 |
| 71 维码经 $C_\varepsilon$(A71 判据档) | 0.5279 |

**自由粗场 > 完整低维潜码 > 离散段支撑 ≈ 71 维潜码**。这条排序是本轮最强的单一发现,直接支持文档 §5 把 B 的生成变量放在颈部的选择,也解释了 A/C 为何在同一个家族上一起挂。

**2. 「$\varepsilon$ 正则驯服病态」被两条机理不同的证据独立证实。**
A 的 E0b 扰动实测:放大 ≤7.7(对照杀死 $x\mapsto w^*$ 的 $8\times10^5$)。B 的谱:未正则 $A_I^\top A_I$ 条件数中位 4.63e7,$\varepsilon=10^{-3}$ 压到 2.56e5、$10^{-2}$ 压到 2.56e4,**而重建上界只从 0.9967 动到 0.9965**。两者可在论文里并列引用。**即使 A 案整体不开臂,E0b 这条结论应单独保留。**

**3. 语义轮廓家族是三案共同的最难点,且难度可量化。**
三案的轮廓门分别是 0.75 / 0.88 / 0.80,实测 0.5279 / 0.8949 / 0.5722——**只有 B 过,且只富余 0.015**。文档 §6.3 第 7 条把「轮廓家族承载」列为三案三押注,本轮的答案是:**押粗场 + $U_I$ 边界吸附的那一注赢了,押全局低维码与押段支撑的两注都输了。**
