## 要验证的结论
如果这个实验成功,我们就能说方案 A 的**规范化算子 $C_\varepsilon$ 站得住**——(E0a)$D_I$ 对 $w$ 线性从而闭式码与 $1/(2\sqrt\varepsilon)$ 解析界可用;(E0b)规范码对场扰动的放大有界(中位 ≤50,对照杀死 $x\mapsto w^*$ 的 $8\times10^5$);(E0c)规范码穿 $D$ 重建的上界够高(全体 ≥0.85、轮廓 ≥0.75)。失败就不能说「把病态搬到一个 $\varepsilon$ 与一条确定性算法路径上」这条主张成立。

## 为什么需要验证它
方案 A 的身份就是「规范化」:它绕开约束 2 靠的不是换坐标系(那是 B),而是「共享初始化 + $\varepsilon I$ 近端 + 固定步数」让 $y\mapsto u$ 单值且良态。§6.3 未消解分歧第 1 条直接写明,若这条不成立,A 就退化成「背着 71 维瓶颈的 B」。审稿人会问「你的 $u$ 到底能不能表示 GT 场、扰动放大多少」——正是 E0b/E0c。

## 怎么验的
零训练。V_where local 全体 n=400(S-val 源)。$C_\varepsilon$ 实现为**固定 60 步阻尼 Gauss-Newton(LM)**,从**整臂常量**(已发布 oracle 潜码的 medoid)出发,目标 $\|D_I(w)-y\|^2+\varepsilon\|w-w_0\|^2$(**L2,禁 IoU 作优化目标**),$\varepsilon$ 扫 {1e-3,1e-2,1e-1}。E0a 用 n=256 的**中心化**叠加残差并逐级分解;E0b 给 $y$ 加 1%/5% 场幅扰动重跑测放大;E0c 报重建 soft-IoU。另设**同目标同求解器的 8 重启对照臂**,把「规范化代价」与「L2 目标代价」分开。

### 代价分解(本卡的关键诊断)

对照臂 = **同目标同求解器**的 8 重启。三层账:

| 量 | A71 | A71p |
|---|---|---|
| 已发布 oracle(soft-IoU 目标,18 重启) | ~0.97 | ~0.97 |
| 多起点 L2 上界(同求解器) | 0.7421 | 0.9343 |
| $C_\varepsilon$(单一共享初始化 + 近端) | 0.7052 | 0.9314 |
| **规范化代价**(上界 − $C_\varepsilon$,均值) | **0.058** | **0.162** |

**两个独立的失败机理,方向相反,都指向不开臂**:

1. **A71:71 维码本身装不下。** 多起点上界只有 0.7421——**给它 8 次重启、去掉近端项,仍到不了 0.85 判据线**。规范化只花了 0.058。**瓶颈是文档字面的 $\mathbb R^{71}$ 码在 L2 目标下的表达力**,与 Spatial Functa 的硬负结果(全局低维 modulation 装不下复杂空间结构)同型——文档 §2.7 自列为一号风险。
2. **A71p:给够自由度后,坏掉的是规范化本身。** 完整潜码的多起点上界 semantic 能到 **0.779**,而 $C_\varepsilon$ 只有 **0.196**——共享初始化 + 近端在轮廓家族上把解推进了错误盆地。**这恰恰打的是方案 A 的身份主张**(「共享初始化把多盆地对齐为可比单盆地」),不是它的某个工程细节。

## 3. 结论

1. **E0a FAIL** → 线性特例与其全部解析主张按预注册**永久退役**。
2. **E0b PASS** → 「确定性规范化能驯服病态」**成立**,放大 ≤7.7 对 $8\times10^5$。这是方案 A 值得被记住的贡献。
3. **E0c FAIL,且轮廓家族 0.5279 < 0.60 证伪线** → 按预注册**判死「71 维潜码承载轮廓」**。
4. **按预注册与任务卡,方案 A 的训练臂本轮不开,且门槛不得放宽以复活。**
5. 对 §6.3 分歧 1 的裁定:裁决器是「E0b ≤50 **且** E2 家族涌现达标」才算 A 的独立价值成立。**E0b 过了,但 E0c 先挂了,E2 根本没机会跑**。所以分歧 1 的结论是:**A 的独立身份未被证成**——不是因为规范化不稳,而是因为它要规范化的那个 71 维码装不下答案。

## 4. 建议下一步

1. **A 案训练臂不开**。文档 §2.6 为 E0c 失败预备的升级路径(学习残差编码器 → 空间 latent token)**属于另立实验**:它改变 $u$ 的维度与性质,「71 维规范码」的主张随之失效。
2. **E0b 的结论应当被 B 案继承引用**:它独立证明了「$\varepsilon$ 正则 + 确定性算法」这一族做法能把 $8\times10^5$ 压到个位数,与 B 卡从谱的角度得到的同一结论(4.6e7 → 2.56e4)互为佐证,两条证据机理不同(A 是扰动实测,B 是谱界),可在论文里并列。
3. 若日后重启 A,**先修表达力再谈规范化**:A71p 的多起点上界(semantic 0.779 vs A71 0.586)已经量化了「放开 $\rho$ 值多少」,而 A71p 的规范化崩塌(0.779→0.196)则量化了「放开之后规范化要重做」。这两个数是重启该方向的起点。
