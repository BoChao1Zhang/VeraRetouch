## 要验证的结论

如果这个实验成功,我们就能说 **Phi-71 逐图拟合的内层 Hessian 谱良好、解唯一** —— 那么 M1
(多模态/条件均值塌缩)的前提不成立,P4 生成式整线可以撤销;失败就不能说这句话,反过来会指认
**回归目标 w\* 本身病态(M2)**,修复方向从「换架构」变成「修目标」。

## 为什么需要验证它

W01/W02 的四个死因假设(M1 均值塌缩 / M2 目标病态 / M3 照抄先验 / M4 条件未接入)**表型完全相同、
修复方向完全相反**。这是四个里唯一一个**不用训练、不用 GPU、当天出数**就能判别的:M1 要求解流形
近奇异,M2 要求 `dw*/dx = −H⁻¹B` 因 H 病态而爆炸 —— 两者都由同一个可直接测量的对象
`A_xᵀΛA_x` 决定。不做就等于在没有多模态证据的情况下白做生成式头(MCQ→MetaCanvas 已经交过一次
未诊断换头的学费)。

## 怎么验的

对 V_where 全部 400 条 local 样本重建 Phi-71 设计矩阵(需先补一次视觉塔前向,见下),在 Where-A
已落盘的 oracle 解处计算内层 Gauss-Newton Hessian 的谱:条件数、近零特征值个数、有效秩;
另报 oracle w\* 的逐维跨样本方差,以及**已在盘但从未被读过的多起点重启损失谱**。

## 0. 两条必须先纠正的前提(否则数字无法复现)

1. **E1 不是纯 CPU**:任务卡与 REQUIREMENTS §2.2 都称 Where-A 的 `F_pre` 缓存现成。
   **实测不存在** —— `where_a-20260805/` 只发布了 `basis/ maskviews/ oracle/`,NFS 与本地都没有
   任何 F_pre 缓存。设计矩阵没有它重建不了。故先补跑一次视觉塔前向(400 图 **57 秒**,frozen、
   SFT 不变),把 `B(F_pre)`、`img_low`、merger 输出落盘成本地缓存;**此后 E1/E5 才真的是纯 CPU**。
2. **Where-A 的 oracle 不是「逐图加权最小二乘」**。读 `q3vl/where/oracle.py::_forward` 与已落盘
   记录(`objective: "soft_iou_minmax"`, `n_starts: 18`):它是**对 soft-IoU 的多起点非线性拟合**,
   变量是 `(w_dir, w0, alpha, rho)`:

   ```
   q = w0 + alpha * (phi @ w_dir);   s = 3*tanh(q/3);   m = readout(s, rho)
   ```

   处方文档的「逐图 LSQ」是理想化说法。**严格成立的部分**是:`m` 对 `w_dir` 的依赖只经过
   `phi @ w_dir`,所以 `w_dir` 方向上的 Gauss-Newton Hessian **确实**是 `AᵀΛA`,其中

   > `Λ = diag[ ( dm/ds · sech²(q/3) · alpha )² ]`,在 oracle 解处取值。

   本卡因此分开报两个条件数,**不可混用**:**结构条件数** `cond(ΦᵀΦ)`(基底自身)与
   **有效条件数** `cond(ΦᵀΛΦ)`(oracle 实际求解的那个问题)。

| 有效秩(共 71) | 71 | — | — | min 70 |
| Λ 非可忽略的格占比 | 0.284 | — | — | — |
| oracle w\* 逐维 std(`w_dir`,单位方向) | 0.049 | — | — | 0.442(min 0.030) |
| **oracle w\* 逐维 std(`w_raw`,字面 w\*)** | **1.146** | — | — | 17.14(min 0.719) |

分布尾部:
- **有效条件数 <1e2 的样本占 0.00%**(登记门槛),>1e6 占 **42.8%**,>1e8 占 **8.0%**;
- 至少 1 个近零特征值的样本占 **11.2%**;有效秩 <71 的占 **3.8%**;
- Spearman(有效条件数, oracle IoU) = **−0.521** —— 越病态,oracle 拟得越差,机制自洽。

### 多起点地形(已在盘、零成本、从未被读过的证据)

每条 oracle 记录都存了 18 次重启的 `start_losses` 与 `best_start`:

- 最好—最差损失跨度中位 **0.5206**(soft-IoU 尺度,即从 0.97 到 0.45);
- **落在最优解 1% 以内的重启次数中位 = 1**,即 **18 次里只有 1 次**找到最好盆地;
- **85.8% 的样本只有唯一一次重启**能进最优 1% 邻域;绝对 0.005 邻域内中位 3 次。

**这是本卡最直接的地形证据**:逐图目标函数**高度非凸、多盆地**,且盆地质量差异极大。

### w\* 作为回归目标有多难(逐维变异系数)

字面 w\*(`w_raw`,未归一化,行范数均值 22.9)的逐维跨样本统计:

- 逐维 |均值| 中位 **0.108**,逐维 std 中位 **1.146**;
- **变异系数 CV = std/|mean| 中位 10.66,且 71 维中 100% 的维度 CV > 1。**

**没有一个维度的跨样本均值能盖过它自己的散布。** 一个学 `E[w*|x]` 的 L2 回归器,其可预测的
「中心」在每一维上都比噪声小一个数量级 —— 这与 §2-2 的病态条件数是同一件事的两种度量,
且**直接解释**了 W01/W02「输出对 x 近乎无方差」的观测:条件均值本身就接近一个常数向量。

## 2. 判读(对照登记判据)

> 登记门槛:**条件数中位 <1e2 且无近零谱 ⇒ M1 降级、P4 生成式整线撤销。**

| 腿 | 实测 | 结论 |
|---|---|---|
| 条件数中位 <1e2 | **8.36e5**,超门槛 **4 个数量级**;满足该门的样本 **0.00%** | **FAIL** |
| 无近零谱 | 中位 0 个、有效秩中位满秩 71 | **PASS(中位口径)** |
| **合取门** | — | **M1 未降级** |

**但两条腿分裂,必须分开读 —— 这是本卡的真正信息**:

1. **M1 的严格前提(近奇异 ⇒ 解流形真多模态)在中位样本上并不成立**:满秩、零个近零特征值。
   只有 **11.2%** 的样本出现近零谱、**3.8%** 掉秩。**「w\* 有连续等价解流形」不是普遍现象。**
2. **但问题严重病态(1e5–1e19)**,这正是 **M2** 的机制:DDN 的 `dw*/dx = −H⁻¹B` 在
   `cond(H)~1e6` 下意味着输入的微小变化被放大约 10⁶ 倍传到 w\* —— **x↦w\* 极不光滑,回归它
   等于拟合噪声**,而这**不需要**任何多模态就能产生与观测一致的塌缩表型。
3. **多起点地形独立佐证 M2 而非 M1**:18 次重启只有 1 次进最优盆地、跨度 0.52 —— 目标函数的
   崎岖是**优化难度**,叠加病态 Hessian,使得「同一 x 的 w\* 落在哪」带有强烈的**求解器路径依赖**
   成分。这种噪声对回归器而言与真多模态**不可区分**,但修复方式完全不同(正则化 vs 生成式头)。
4. **结构条件数本身已达 3e5** —— 即**在任何加权之前**,Phi-71 的 71 列就高度共线。这是**基底设计
   层面**的发现,不是数据问题。
5. **额外的精确多模态源(非渐近,而是代数上的)**:`latent.sign_index` 表明 `w_dir` 是**归一化方向**
   且符号被事后规范化。`(w_dir, alpha) → (−w_dir, −alpha)` 是解集的**精确 2 重对称**。若训练期没有
   **逐字一致地**施加同一规范化,w 空间回归器看到的就是一个人为的双峰目标 —— 这是**零成本可查的
   工程隐患**,应在 E2 前先核对。

6. **独立复核**:本卡的结构条件数由另一路独立实现(CPU fp32 端到端重跑 Where-A 链路)得到
   `phi_gram_cond = 3.33e5`,与本卡的中位 **3.01e5** 一致;该路同时把已发布 oracle 的解码 IoU
   复现到 ~1e-5 残差。**数字不是单点实现的产物。**

**一句话判读**:**M1 不降级(门槛未过),但证据主要指向 M2 而非 M1** —— 病根更像「目标病态 +
求解器噪声」,而不是「解流形真多模态」。**E2(Tikhonov 重算 oracle)因此是当前性价比最高的一步**,
它正对 M2;**P4 生成式整线不应据本卡启动**(M1 的正面证据仍缺,那是 E4 的事)。

## 3. 建议下一步

1. **E2 优先级上调为诊断包第一位**(原排序在 E3 之后)。本卡把 M2 从「并行嫌疑」抬成主嫌:
   `cond ~ 1e6`、Spearman −0.52、多起点地形崎岖,三条独立证据同向。E2 的 Tikhonov 正则**同时**
   治条件数与求解器路径依赖,且是唯一「改一行 oracle 脚本」的修复。
   **λ 扫描建议按有效条件数定标**(如令 `λ = c·λ_max/1e3` 使 cond 降到 1e3 量级),而不是盲扫。
2. **E2 前先做零成本核对**:训练侧 `w_dir` 的符号规范化是否与 oracle 落盘时**逐字一致**。若不一致,
   W01/W02 的回归目标里混着人为双峰,这本身就足以解释塌缩,且修复成本是**一行**。
3. **P4 生成式线保持冻结**,等 E4;本卡**不构成** M1 的正面证据(反而弱化了它的前提)。
4. **给基底设计的一条独立建议**:结构条件数 3e5 说明 Phi-71 的列高度共线。若 E2 的正则化有效,
   应顺带评估**对基底本身做一次正交化/白化**(不改变张成空间,故不动 oracle 上限 0.97),这会
   同时降低结构与有效条件数,且对所有下游臂(P1/P3 的 WLS 投影层)都受益。
5. **判据纪律沿用 E1(attention)审阅结论**:后续所有臂的评测必须并排随机地板 `a/(2−a)` 与
   中心先验列,P2 门槛按 area 分层重设计。
