## 要验证的结论

如果这个实验成功,我们就能说 **SFT checkpoint-4976 的 `<where>` token 对 image token 的 attention,
经 sink 排除后本身就是一个指令条件的空间定位场,新头只需把它读出来而不必生成它**;失败就不能说
这句话 —— 也就不能把方案 B 的整条通路建立在「信号已经存在、只待读出」这个前提上。

## 为什么需要验证它

这是方案 B 的**唯一地基**,也是全战役最大的未测变量:论文要主张「指令条件的空间对应关系已存在于

W01/W02 已经失败过一次的方式。

### 登记完成标准的结算(B3-1)—— **FAIL,但含义有限**

P-W1 登记的完成标准是「sink 判据在分辨率分层间稳定,**sink 集合 Jaccard ≥ 0.8**」。原始交付给的是

(例如 pad 格,它们**确实**在固定位置)设计的。本卡的规则是**逐图自适应**的(每张图用自己的

规则真正依赖的量(sink 占比、质量占比)跨分辨率极稳定(极差 0.021 / n≥10 形状 0.113–0.125)。

**另须显式记录**:交付的**指令不变性 Jaccard = 0.712(p10 0.556)< 0.8**。它衡量的是「换指令后

## 7. 结论

1. **本卡的核心结论是否定的**:SFT checkpoint-4976 的 `<where>`→image attention,经 sink 排除后
   **不构成指令条件的空间定位场**。三个 query 池全部同时踩 P2 与 P3 两条作废线;按 DELTA 裁定 4/5,
   raw 臂的三个池**全部作废**。
2. **两个失败是独立的**,任何一个单独就足以否定:输给零参数中心先验(Δ=−0.029~−0.049,
   p_FWER≤5e-4);且**几乎不随指令变化**(Δ_shuffle≈+0.002,p_FWER≥0.195)。
   **措辞按 E1b/B2 收紧**:不是「没有指令信息」——在 partner 目标真正分离的子集上
   `where_content` 的 Δ_shuffle=+0.012 且 **p=0.004**,信息可被检出;
   但它**比门槛低 6.7 倍**,且 partner 重叠已被排除为成因。准确说法是
   **指令信息存在但小到不可用**。更精确的机制见 §6b/B1 的 P4:
   **该通道对「有没有指代表达」有反应(P4 在小目标上 Δ=+0.131 过门),对「指代哪一个」没有** ——
   它是物体性闸门,不是 grounding。
3. **query 池不是决定性变量(与 RO-3 在旧模型上的结论相反)**。三池的 P1 落在 0.422–0.434 的
   0.012 带宽内,`where_content` 与 `instr_text` 选出的最强头**是同一个 (L18, H5)**。
   DELTA 裁定 6 的「`<where>` 池失格则 instr 池顺位」在这里无从执行:instr 池是三者里最差的。
4. **sink 排除本身是可靠的、必要的、且已定稿**,但它有 12% 的 GT 质量代价,把天花板压到 0.729。
5. **可学融合补不上这个缺口**:27k CNN 的 Δ_shuffle 只有 +0.014。
6. **SFT 的语言侧成功没有传导到 attention 侧**:同一 checkpoint 的 `<where>` 文本 token-F1
   p50=1.0、53% 逐字命中(REQUIREMENTS §2.1),但它说对区域时,并没有在 attention 上看向那里。

**判据完整性声明**:本报告全部空间判据为 grid soft-IoU + grid 边界 F1 + 中心先验列三件套,
未产出任何 AUC;三件套负控制(shuffled / 中心先验)内建为判据列而非附录。
