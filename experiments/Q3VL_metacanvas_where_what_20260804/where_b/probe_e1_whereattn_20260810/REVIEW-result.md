### 1.3 FWER 口径的两点说明(均不影响裁决)

- **家族大小是 3 不是 4。** DELTA 裁定 4 登记的是「4 组合(2 臂 × 2 池)进同一 max-stat 零分布」。
  本卡只跑 raw 臂,家族退化为 3 池。家族变小 = 校正**变松**,只可能让通过更容易;三池仍全 FAIL,
  故不构成误判否定。**但推论是:若日后补跑差分臂,其 p 值不能事后并入这份已发布的 3 池零分布**
  —— 那是事后扩家族,必须另开家族或明确标为家族外探索列(见建议 (b))。
- **统计量用 max-|z| 是双侧的。** P2 的观测 z 为负(−5.29 / −3.73 / −4.64),双侧 p_FWER ≤5e-4
  支撑的是「显著地**更差**」。这个用法只用于判 FAIL,不用于晋级,方向上无问题;REPORT 把它读作
  「不是差一点,是反向输」是正确的。

## 二、否定结论的稳健性(逐条排查「会误判否定」的路径)

这是「方案 B 作废」级裁决,以下五项是我自己另做的检验,不是复述 REPORT。

### R1 · sink 排除有没有把信号本身排掉 —— **pass,且我给出了 REPORT 没做的直接证据**

REPORT 只给了「代价对称」(12% 格带走 12% GT 质量)这个**总量**论证。总量对称不排除
「被排掉的恰好是那 12% 带信号的格」。我按逐样本 `gt_mass_in_sink` 四分位重切 OOF:

| 分层 | n | gt_mass_in_sink 区间 | P2 Δ中位 | P3 Δ中位 | P3 frac>0 | P1 中位 |
|---|---|---|---|---|---|---|
| Q1(掩膜代价最小) | 47 | 0.001–0.095 | **−0.1267** | +0.0114 | 0.617 | 0.4531 |
| Q2 | 47 | 0.095–0.113 | −0.0418 | +0.0026 | 0.553 | 0.4400 |
| Q3 | 47 | 0.113–0.148 | −0.0146 | −0.0030 | 0.447 | 0.4497 |
| Q4(掩膜代价最大) | 48 | 0.148–0.695 | +0.0351 | +0.0051 | 0.500 | 0.3512 |

**掩膜代价最小的那一档,P2 反而最差(−0.127),P3 也只有 +0.0114** —— 没有任何一档在「解除掩膜
代价」后恢复出指令条件性。按 `sink_frac` 分层结论相同。

结构上还有一层保险,方向是对的:**合取规则只排除在 gt 与 shuffled 两档下同时超阈的格**,
即「只在真指令下亮」的格按定义被**保留**。NOTES D3 明写了这个理由,我确认它成立。

**结论:「sink 排除吃掉了信号」这条误判路径,在交付数据内被关闭。**

**没关掉的那一半见 B2:场动了,但没有证据表明 partner 指的是不同的地方。**

### R4 · fit/OOF 自建切分是否 effect-blind —— **pass**

- 分组键 `source_image_id`,**组绝不拆分**(896 条只出自 162 张源图,逐样本切会把同一张照片的
  近重复放到两侧)✓;
- 组定序用旁表**自己发布**的规则族 `sha1("verasplit-v1:"+source_id)` —— 一个与效应完全无关的

- 判据数字全部来自 OOF(§1.2 已逐条验证),选头与逐头 (μ,σ) 常量均在 fit 折上定(NOTES D5),
  k=3.0 沿用 RO9b 常量未调参 ✓。

**切分不是效应盲的风险为零。** 且 P2/P3 都是同图配对检验,对切分方式本就不敏感 —— NOTES A 的
自评正确。旁表落后 3 个 build(g4/l5/l6 join 不上)已上报待裁,处置得当。

### R5 · 面积匹配 top-k 用了 GT 面积 —— **不会造成误判否定,但抬高了对照列,且暴露一个未报的地板**

**(i) 对 P3 完全免疫。** 同图、同 k、同支撑,gt 与 shuffled 两臂的 k 逐字相同,k 在配对差里
整体消掉。**本卡最致命的那条失败(Δ_shuffle≈0)与 oracle-k 无关。**

**(ii) 对 P2 是「对我方更苛刻」而非更宽松。** 径向单调的中心先验拿到 oracle 面积预算,会画出
一个大小恰好正确的居中团块 —— 这正是该基线的最好情形,而**生产链路里它拿不到**(k 要由面积头
预测)。所以「输给中心先验」比生产口径下的对比更狠,不可能成为误判否定的来源;反过来,
−0.03/−0.05 也**不应**被当作生产口径的差距去引用。

**(iii) 新发现 —— 判据的随机地板没有报,而且很高。** 面积匹配 top-k 下,同支撑随机场的
soft-IoU 期望是 `a/(2−a)`(a = GT 面积占比;硬掩膜推导,软 GT 同式)。本 OOF 集 `area_frac`
中位 **0.466**,且 **51.3% 的样本 area≥0.45**:

| area 档 | n | 随机地板中位 | 场 | 中心先验 | oracle | 场<地板 |
|---|---|---|---|---|---|---|
| <0.15 | 29 | 0.050 | 0.331 | 0.208 | 0.625 | 0.0% |
| [0.15,0.45) | 63 | 0.167 | 0.361 | 0.448 | 0.761 | 0.0% |
| **≥0.45** | **97** | **0.527** | **0.469** | 0.492 | 0.623 | **53.6%** |

- 全集:地板中位 **0.304**;`where_content` 的 P1 中位 0.433 只高出 **+0.119**(p=2e-11),
  中心先验高出 +0.104。
- **在占一半样本的 ≥0.45 档里,随机地板(0.527)高于场(0.469)也高于中心先验(0.492)**,
  53.6% 的样本得分**低于随机**;该档 oracle 仅 0.623,即整个可判别区间只有 ~0.10 宽。
- Spearman(area_frac, 场得分) = **0.649**。REPORT 自己对 success 案例的读法(「大面积目标上谁都
  能得分」)就是这件事,这里把它量化了。

**双向后果**:① 它**加强**否定(场在一半样本上连随机都不如);② 它同时说明
**P2 的 +0.10 门槛在这一半样本上接近算术不可达**(该档 oracle−中心先验 = 0.131,要求场吃掉
95% 的 oracle 余量),因此按池汇总的 P2 中位被 eval 混合结构系统性拉向 FAIL。这**不救** raw 臂
(P3 在所有分层里都死,且与混合结构无关),但**它意味着同一套判据搬去评方案 C 时,C 也会因为
与 C 无关的原因「失败」**。这是本审阅对计划最重要的一条修改建议(见 §五-2)。

### R6 · 最有利的分层能不能救回来 —— **pass,救不回来**

唯一超过 P2 门槛的分层是 area<0.15(Δ=+0.126 ≥ +0.10)。但:p=0.024 未及 α=0.01;非预注册分层;
n=29;**且其 Δ_shuffle 只有 +0.0102(p=0.055),比 P3 门槛低 8 倍**。
**交付数据里不存在任何一个同时过两条腿的子群。** REPORT §5 把这一步做出来并自我否定,是本卡
最见功底的地方。

## 四、逐项 pass / blocker / nit

### Blocker(须补,均**不翻转**裁决)

**B1 · 登记判据 P4 缺席、P5 的随机 top-k 守卫列缺席。**
PROPOSAL §4 P-W3 预注册了 P1–P5 五条;DELTA §三 明确「**P4(vs 固定短语场)判据保留**,兼作
差分臂的存在性检验(固定短语档前向本来就要跑)」。交付里 P4 **完全没有**,P5(边界 F1)有数字
但**没有**登记要求的「随机 top-k 守卫列(同支撑同 k)」。按 CLAUDE.md 红线,grid 边界 F1
没有守卫列时主要在测边界长度(同支撑同 k 的随机 top-k 曾得 0.0394,高于中心先验的 0.0327)。
→ 现状下 §3 那行「边界 F1 +0.012(p=0.020)」**不可解释**,须标注「守卫列缺失,结论待补」。
*影响范围*:不动 P2/P3 的裁决;但 P4 恰好就是建议 (b) 要跳过的那次前向。

**B2 · P3 缺正对照:没有出示「shuffle partner 确实换了目标区域」的证据。**
partner 取自**同一** `(source_image_id, render_mode)` 组,即**同一张照片**。若组内成员的目标区域
彼此相同或高度重叠,那么**即使是一个完美听指令的场,Δ_shuffle 也会 ≈0** —— 这是唯一一条
R1/R2 没能关掉的误判否定路径,而交付里没有任何数字能界定它。R2 证明了「文本真的换了、场真的
动了」,但证明不了「换过去的指令指向别处」。
→ **补法很便宜且不用 GPU**:对 189 对 OOF 配对,报「本样本 GT 与 partner GT 的 soft-IoU / 质心
距离」分布,并在「配对目标确实分离」的子集(如 pair-GT IoU < 0.3)上重跑 P3。
*影响范围*:**不威胁「raw 臂作废」**(P2 完全不碰 shuffle 臂,自己就是显著的负值);

## 五、对计划的修改建议

### (a) raw 臂作废是否成立 —— **成立,且不依赖上述任何 blocker**

1. **P2 输在符号上,不是输在门槛上**:Δ = −0.0398 / −0.0290 / −0.0489,三池 FWER 全部显著
   (≤5e-4)。负的 Δ 只会被缺失的对照变得更负,不会变正;且 **P2 根本不碰 shuffle 臂**,B2 对它
   无效。
2. **P3 差一个数量级**:+0.0017 ~ +0.0025 对 +0.08 的门,frac_positive 0.51–0.56。
3. **DELTA 裁定 5 删掉了灰区**,此处没有裁量空间;DELTA §六 写死的唯一刹车正是
   「E1 三池全踩作废线(P2/P3 联合 FWER 下)」—— 发生的就是这个。
4. 我另外验证了:**没有任何分层、任何 sink 代价档、任何 query 池同时过两条腿**(R1/R6),
   且场在**一半样本上低于随机面积匹配 top-k 地板**(R5)。

**两条必须随裁决一起记录的限定**:
- 作废的是「**本 eval 混合、本判据口径下的 raw attention 读出**」。R5 表明 P2 的 +0.10 门在占
  51% 的大面积档上接近算术不可达 —— 这不救 raw 臂(P3 是绑定性失败且与混合无关),但**不得**
  被后续引用为「我们做了一次 +0.10 可达的公平比较」。
- **「raw 臂作废」≠「方案 B 整体作废」**。DELTA 裁定 1/4 把差分写成与 raw **平级**的对称臂、
  家族为 4 组合;DELTA §六 又把刹车写成「E1 三池全踩 → 切 C」。**这两处互相打架**,本卡跑的是
  6 个登记组合里的 3 个。本卡把这个分叉交回主 agent 而不自行拍板,处置**正确**;
  → **建议主 agent 在 DELTA changelog 里显式消解裁定 1/4 与 §六 的冲突,再谈「整体作废」。**

### (b) 差分臂「不值得跑」的推理是否闭合 —— **不闭合。建议跑那 6 分钟,作为证伪补丁存档**

REPORT 的三段论是:Δ_shuffle ≈ 0 → S(instr) ≈ S(fixed) → S(instr) − S(fixed) ≈ 零场。三处断裂:

1. **用 shuffled 臂替换了 fixed_phrase 臂。** 这是两个不同的上下文。Δ_shuffle≈0 说明场对
   「**换成哪一条**指令」不敏感;它**不**说明场对「真指令 vs 一条无指代的固定短语」不敏感——
   后者差的不止是指代对象,还有长度、句法、有没有名词。支撑二者等价的唯一证据是 RO9c §4.2 的
   `reg_a − fixed ≤ 0`,那是**另一个模型 + AUC 口径**(按红线只限排序)。
2. **推的是分数相等,不是场相等。** 两个 soft-IoU 相同的场可以逐格差很多,差分场并不被两个标量
   之差钉住。我实测:`|Δ_shuffle|` 中位虽只有 0.017,但 p90 达 0.107、最大 0.32(R2)——
   **场明显不是同一个场**,「差出来接近零场」没有被测量支持。
3. **P4 是登记且被 DELTA 显式保留的判据**(B1)。在正要据此杀案的节点上,靠推断跳过一条登记
   判据,会让预注册矩阵在最关键处留缺口。

**成本/收益极不对称**:`--arms gt,fixed_phrase` 复用本卡全部分析代码,约 6 分钟前向;一次性
同时结清 B1 的 P4 行、给出 P4 要求的偏心/小目标子集对比、并把「新模型上 instr−fixed 到底是不是
零」这个问题从「引用旧模型 AUC」升级为实测。

**执行约束**:补跑结果**必须标为家族外一次性证伪列**,其 p 值**不得**并入已发布的 3 池 WY 零
分布(那是事后扩家族)。它的用途是存档与堵口,不是复活分支 —— 这一点 REPORT 的措辞已经对了。

### (c) 切 C 案前 P-W5 是否必要 —— **必要。但理由要比 REPORT 写的更强一条**

REPORT 的理由(「只证伪了一条通路,不该按『信号不存在』去改方案」)成立,但还不是最强的:

**最强的理由是 P-W5 就是方案 C 自己的 P0。** PROPOSAL §7 的切换条件白纸黑字写着,C 修复版的
前提是「零训练段的打分基底显式改为 **merger 输出(2560 维,H/32)或 W_v 投影后空间**」,并且
「**若 P-W5 旁通道已存活,其数据直接入 C 修复版的 P0**」。而 P-W5 测的正是
**F_pre × `<where>` 名词 unembedding 的词特异性**——即 C 赖以打分的那个基底上到底有没有词特异
信号。**不跑 P-W5 就切 C,等于对着 C 唯一的可行性读数闭着眼睛开工。**

成本侧支持:登记 ~0.5h、无否决权、F_pre 对 SFT 不变(WA-P4b 实测 diff=0)、Where-A 缓存现成,
**不需要新前向**。且它是本战役唯一**预先收集好**的第二读出源。

**两条执行约束(由本卡的发现直接推出)**:
1. 必须带上 R5 的**随机面积匹配 top-k 地板列**,否则它的绝对值会和本卡的 P1 一样不可解释;
2. 「词特异 Δ」必须是**同图内配对**(目标名词 vs 对照词),这是登记口径,且不得退化成只报一个
   池化排序 —— RO-2 纪律已经说过 Δ_shuffle>0 不足以证词特异。
