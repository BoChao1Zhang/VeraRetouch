## 三、这个负结果对三条腿各自的影响

PLAN §0 的因果链：`编码（有信息）─腿A 探针证明─▶ 传输（读出口太窄）─腿B 换读出口+渲染器─▶ 落地─腿C 分区指标`。

### 腿 A（探针证明信息在表征里）：**几乎无损，但少了一个「免费证据」**

- G1 测的是**读出口**（attention 场），不是**表征里有没有**。腿 A 的载体是 PR-1/PR-3 探针，
  与 RO-9 是两条独立通路。**H1（颜色）完全不受影响；H2（空间信息在表征里）未被触及**（详见 §四）。
- 损失：原来指望 RO-9 当「零成本的腿 A 旁证」（emergent 注意力已经会指位置 ⇒ 表征里显然有空间信息）。
  这条**没了**。腿 A 的空间侧现在**必须**靠 PR-3 空间探针独立立起来，不能借 RO-9 的图说事。
- **连带影响（审阅新提，REPORT 未覆盖）**：PLAN §3「腿 A' 空间侧」的 **B4（有名词/无名词指令对比：
  GL token vs CLIP vs GEM，用于论证 VLM 不可替代性）** 与 EXPERIMENTS_v3 §2.1 的
  **RO-X1（有名词/无名词分离）**，其前提是「GL token 在无名词半集上仍有结构」。
  G1 已证明 GL token 对**有没有名词、名词是什么**都不敏感 ⇒ **RO-X1 用 RO-9 当 VLM 代表这个设计已失效**，
  需改用 RO-3（全层全头扫描的最佳头）或 RO-5（训练出来的探针头）当 VLM 侧代表，否则跑出来的
  「VLM 系不崩塌」会是伪阳性（不崩是因为它压根不看指令，不是因为它懂语义）。**这是本审阅最重要的一条计划修改建议。**

### 腿 B（换读出口 + 渲染器）：**被打掉一个候选，方向不变，反而更聚焦**

- 腿 B 的论点是「读出口太窄，换一个就捞回信息」。G1 只是证明**RO-9 这个特定读出口是空的**，
  没有削弱「换读出口有用」这一命题——恰恰相反：**RO-9 是所有候选里最便宜、最诱人、最容易被
  审稿人当作「你为什么不直接用这个」的那一个，先把它明确排除，腿 B 的论证反而更干净。**
- 实质变化：零训练读出臂的希望从「原生 attention」转到 **RO-1（self-self）/ RO-3（全层全头扫描）/
  RO-2（logit lens）**，学习式读出（RO-5/RO-6）的相对权重上升。D-33 的 RO 优先级重排与此一致，审阅认可。
- **风险提示**：RO-1/RO-3/RO-4 都是 attention 系读出。G1 揭示的失败模式（attention 场是图像驱动的
  显著性、对指令不敏感）**有可能是 attention-as-readout 这一整类的通病**，而不是 GL token 独有。
  ⇒ 见 §六建议 R2：**RO-1/RO-3 必须在出 AUC 榜之前先过同一套区域对立 + 跨图错位对照**，
  否则会重演一次「AUC 0.75 很好看，其实与指令无关」。这一条比 REPORT 的 B3 更强：
  B3 说「必须带 Δ_shuffle 列」，审阅主张**把它设成前置闸门（先过负控制才允许上榜），不是报表里的一列**。

### 腿 C（落地 / 分区指标）：**基本无影响**

- 腿 C 依赖的是渲染器容量与分区评测（H4/H5、G2/G3、RD-* 臂），与 s 从哪来无关。
- 唯一影响：如果最终所有读出臂都拿不到指令条件的 s，腿 C 的「局部性」将只能由
  **w 决策 / 用户指令直接映射**承担，s 退化为图像先验。这是**降级叙事**而非崩塌，
  但需要在 W3 的双淘汰会上正式确认一次。

这是本审阅认为**最容易在论文里被写错、也最容易被审稿人抓住**的一点，故单列：

| | 陈述 | 状态 |
|---|---|---|
| ❌ **被证伪** | 「冻结 VLM 里 `<retouch_light>` special token 的 pre-softmax attention 场，是一张跟着指令走的空间寻址图」 | **已证伪**，n=214，0/214 达标，四种变体穷举 |
| ❌ **被证伪** | 「这个 SFT 涌现的 attention 场可以零训练直接当局部编辑的 mask / where 通路」 | **已证伪**（同上 + 跨图错位对照 + AUC 配对） |
| ⚠️ **未被证伪** | **H2：空间信息在 VLM 表征里，只是读出口没有承载通道** | **完全未被触及。** G1 测的是**一个特定读出口的输出**，不是表征内容。H2 的证伪条件（PLAN §0）写的是「**修复伪影后读出图仍与随机场无异**」——而 G1 的 s **不是随机场**（对 SAM3 主体掩膜 AUC 0.664，L20–22 段 0.825，远高于亮度基线 0.475）。**按 H2 自己的证伪条件，G1 非但没证伪 H2，反而给了它一点微弱的支持**：表征里确实有主体位置信息，只是没跟指令挂钩 |
| ⚠️ **未被证伪** | 「VLM 内部存在指令条件的空间信息，只是不在 attention logit 这个读法里」 | 未测。要由 RO-2（logit lens）/ RO-5（训练探针）/ PR-3（空间探针）回答 |
| ⚠️ **未被证伪** | 「SFT 让模型学到了 where」 | **只证伪了「学到的 where 写在了 GL token 的注意力里」**。PR-5（pre/post-SFT 对照）仍需跑：G1 实际上已经把 PR-5 的 post-SFT 侧做完了（指令条件性 = 0），**只差 base 侧**——若 base 同样是 0，说明 SFT 在这个通道上什么也没加；若 base 更差，说明有微弱贡献。成本已经减半，建议顺手做掉 |

## 五、作为论文 analysis 素材的价值（本审阅认为应单独成节）

### 为什么值得单独成节，而不是塞进 limitation 脚注

1. **它反驳的是一个正在流行的做法，不是我们自己的一个失败尝试。**
   「把 VLM / LMM 的 cross-attention 或 text→image attention 当作分割掩膜 / 编辑区域先验」
   是 training-free 定位与编辑一整类工作的公共基座（本项目自己的 RO-1/RO-3/RO-4、以及
   RO-X3 里当 baseline 的 SasP/MasP 都建立在这个假设上）。**一个带负控制的反例，价值高于又一个正例。**

2. **它的反例形态特别有教育意义：不是「attention 图很差」，而是「attention 图看起来很好，但好得与指令无关」。**
   - 图看着有空间结构 ✅（不是噪声：AUC 0.664，深层 0.83）
   - 同义指令下高度稳定 ✅（ρ_syn 0.867——文献里常被当作「读出可靠」的证据）
   - 不是亮度的马甲 ✅（|ρ_Y| 0.177）
   - **三个「体检项」全过，然而换成别的图的指令，图几乎不变（ρ_shuf 0.895）。**
   ⇒ 结论：**上述三项体检对「指令条件性」全都没有诊断力。** 这才是可迁移的方法论教训——
   任何声称 attention 能定位的工作，**如果没做跨条件负控制，其正例可能整个是图像显著性**。

3. **它有一张一眼就懂的图。** `viz/failure_instrblind_*`：同一张图，指令 A 说「调主体」、
   指令 B 说「调背景、主体保持不变」，两张 s 图肉眼几乎一样，而 **AUC(b) > AUC(a)**——
   说背景时反而更压主体。配上「48.6% 的源都是这个方向、Wilcoxon p=0.121」的群体数字，
   一图一表就能把一节撑起来。

4. **它对本文自身的方法论是加分项而不是减分项。** 我们**先**用它把最便宜的路线排除掉，再论证
   「所以需要一个显式训练的读出通道」——这正是腿 B 的动机来源。审稿人问「你为什么不直接用 attention」时，
   我们有 300 源 × 三种对照（同义 / 区域对立 / 跨图错位）的答案，而不是一句「效果不好」。

### 建议的成节写法（供论文起草参考）

- **标题方向**：*An emergent special token that looks spatial but is instruction-blind*
- **结构**：现象（SFT 后模型自发产出三个 retouch token，其注意力图有清晰空间结构）→
  三项常规体检全过 → **两个负控制（区域对立 / 跨图错位）双双击穿** → 配对 AUC 定量 →
  层与 token 的穷举排除（说明不是超参问题）→ 教训（负控制应是 attention-as-mask 类工作的标配）
- **必须同时报的三个数**：ρ_syn（正例侧）、ρ_shuf 或 ρ_region_opp（负控制侧）、AUC 与其亮度基线。
  只报第一个就是本实验中途差点犯的错。
- **不要写成**「VLM 里没有空间信息」（越界，见 §四）；**要写成**「这个读出口不承载指令条件的空间信息」。
