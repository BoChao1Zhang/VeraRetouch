## 任务 1：full 臂逐项隔离（9 个分层 LUT × 20 ep，同种子配对）

| 臂 | PSNR (dB) | Δ vs rec | 判定 |
|---|---|---|---|
| `rec` | 42.627 | — | 基线 |
| `hc`（+10·L_hc） | **31.901** | **−10.73** | **元凶** |
| `sparse`（+0.001·R_sparse） | 42.586 | −0.04 | 空操作（但把 opacity 全部锁死） |
| `mining`（hard mining） | **43.286** | **+0.66** | **有效**（论文 +0.34，同号同量级） |
| `full` | (running) | | |

**根因**（`analysis/lhc_grad_probe.json` / `analysis/opacity_trapdoor.json`）：
- **D2 主因·单位失配**：10·L_hc 的梯度范数 = L_rec 的 **229×**（收敛态）/ **869×**（init）。
  Adam 归一化后 L_rec 数值上不起作用。实证：`hc` 臂收敛时 L_rec = 0.0223（rec 臂 0.0054，
  **差 4.1×**），而 L_hc = 0.0026（rec 臂 0.0184，**好 7.0×**）——它把重建换成了色相。
- **D1 次因·chroma 奇点**：cos_h 的分母是**预测**彩度 C_p（下限 1e-3）。收敛态每 1024
  批约 1.33 个样本落在奇异区，批梯度 max/p50 = 5.19（加 chroma 下限后 1.61）；
  `hc` 臂 20 ep 出现 **11 次** >100× 中位数的尖峰（rec 臂 0 次）。
- **D3·opacity 单向陷门**：`raw+clamp` 使 opacity 越界后梯度永久为 0。rec 臂 400 步内
  87.5% 越界，20 ep 结束时 **87.2% 钉死在 1.0**。
- **D4·R_sparse 一步锁死**：熵梯度在 o=1 处是 **−14.8（推高）**，GLUT 把 opacity 初始化
  在 1.0，于是 **step 1 全部 N 个一起越界**。`sparse` 臂实测 opacity@1 = **1.000**。
  → 任务卡怀疑的「R_sparse 把 opacity 推向 0 导致原语塌缩」**不成立，方向相反**。

## 任务 2：rec 臂 −3.55 dB 缺口

- **(a) 表示能力 / 优化配方 → 否决**。E1 直接过拟合引擎（不同 init / σ 退火 / 密度控制 /
  bs 8192 / lr 5e-3 / 仅 0.59× 样本预算）在**同一批 75 个 LUT**上得 41.757 dB，
  与 A0 配方 41.918 dB 配对差 **−0.16 dB**（E1 在 33/75 上更好）。两条独立路径同一水平。
- **(b) 步数不足 → 成立，值 ≥1.5 dB**。9 LUT 配对：20 ep 42.627 → 40 ep 43.650(+1.02)
  → 60 ep **44.156(+1.53)**，仍在上升。**41.92 dB 是欠收敛数字**。
- **(c) 语料口径 → 成立，是剩余缺口的主因**。
  - 难度回归：`affine_psnr` 与实测 PSNR 的 Pearson r = **+0.815**（R²=0.664）；
    本语料 p50 → 预测 41.78（实测 41.92）；p90 → 预测 45.23 ≈ 锚点。
  - 参照点：NILUT LUT01（GLUT 自述 7-LUT 子集来源家族）位于我方语料
    `affine_psnr` 的 **98.7 百分位**、`curv_mean` 的 2.7 百分位，同一套代码实测 **49.02 dB**。
  - 容量曲线：本语料 N=32→41.76 / N=48→43.48 / **N=64→45.39**。
    **我方语料要 GLUT-64 才够到论文语料上 GLUT-32 的 45.47**——2× 容量差，
    曲线与论文平行（固定 N 下恒定 ~3 dB 偏移）。
