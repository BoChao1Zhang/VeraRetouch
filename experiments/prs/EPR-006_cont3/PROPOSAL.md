# EPR-006 · CONT3 续训（曲线未平，收敛判定）

> 主 agent 2026-08-12 批准，按裁定补全后提交 gpu1（主力补位）。

## 1. 目标指标与基线

- **目标指标**：headline **mIoU**（V_where local，normal-only，面积匹配 top-k）
- **基线值**：**0.7909**，出处
  `amort_P3prime_cont2_20260811/eval_final/metrics.json::.topk_iou_median_normal_only`
  （n=224，产出权重 = `.checkpoint_selection.selected == 3500`）
- 续训链实测：P3'(1200) **0.74172** → CONT(2541) **0.76224** → CONT2(3753) **0.79095**，
  配对 Δ 依次 **+0.0254**(p=1e-4)、**+0.0140**(p=1e-4)，**两次都是撞墙钟停的，不是收敛停的**。

## 2. 预注册数字（冻结）

| 门 | 数字 | 处置 |
|---|---|---|
| 仍在爬 | Δ ≥ **+0.008**（配对 p<0.05） | 续训仍是最便宜的推进手段，注入臂的门必须再次抬到新基线 |
| 见顶 | Δ < **+0.008** | 判定续训见顶，**注入是唯一剩下的路**，0.7909 成为稳定基线 |
| **收敛判定（主 agent 裁定）** | **连续 1000 步的在线 eval 增益 < 0.002 ⇒ 判平** | 与上面两条并列报告：Δ 看终点，本条看**曲线形状**，两者可能不一致（例如中途涨完、末段已平） |
| 退化守卫 | Δ ≤ −0.008 | 判过训练，回退到 CONT2 权重并记录步数上限 |
| 硬门 | 面积比 / 换主体 Δ / antonym 不变性三门全过 | 任一不过 ⇒ 该 checkpoint 不可选 |

**收敛判定的读法（预注册，防出数后挑口径）**：在线 eval 每 500 步一档，
取相邻两档跨度 1000 步的增益 `iou[t] − iou[t−1000]`；**最后一个满足跨度的窗口**判平与否为准，
不得在事后选择对结论有利的窗口。若全程不足 1000 步（墙钟过早截断）⇒ 报「不可判收敛」。

**本 EPR 的价值不对称**：涨了，所有注入臂的判据基线要跟着抬；不涨，才是真正的好消息
（它把「注入」从「和续训抢功劳」里解放出来）。**两个方向都必须如实报**。

## 3. 假设一句话

成功（无论涨或不涨）则能说：**P3' 这条曲线在 ~6000 步处是否已经收敛**；
失败（作业没跑完/硬门不过）则不能说 0.7909 是稳定基线，
也就不能安全解读 EPR-001/002/003 的 Δ。

## 4. 输入

- 训练：local train **42,752**（exclude_low）**全量**，与前三段续训逐字同配方
- 评测：V_where local 400 → normal-only **224**
- resume：`amort_P3prime_cont2_20260811/amort_step3500.pt`（**step 3500**，主 agent 裁定）
  —— 与 EPR-001/002/003 **同一份权重**，因此 CONT3 与三个注入臂共享**同一个 M0**，
  四条 Δ 可以直接相互比较（「注入买到多少」对「多训一段买到多少」）。
  代价：丢掉 CONT2 末段 253 步的进度（3753→3500），换来的是全部在途实验的基线严格同源。
  本 EPR 采纳裁定口径，并在此记录该取舍。

## 5. 与基线的唯一差异

**只改一件事：多训一段**。`--max-steps 2500 --max-hours 4.0`（墙钟 4h，主 agent 裁定），其余（loss 五项权重、lr 3e-4、
cosine、effective-batch 32、seed、上采样门控、三硬门）与 CONT2 逐字相同。
**不注入任何几何码**，`--geom-inject` 不出现。

## 6. 判据表（含运行时断言）

| 列 | 规则 | 运行时断言 |
